#      （如 `crates/engine/preference_learning/...`、蓝图里的「目标路径」）；
#   ② 文档本身就是**历史记录/归档卷宗**（按 `check_doc_caliber.py` 的
#      历史文档判据剔除：`docs/archive/` 等目录 + 历史横幅 + 日期/round 命名）。
