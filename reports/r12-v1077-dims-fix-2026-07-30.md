### 3.2 实现: `_measure_open_rubric_score()`

公式 (V36 HQB 4-dim 哲学版)：
```
SC  = answers_with_anchor / n_answers   (锚定自洽)
NR  = min(1.0, n_answers / 7)           (覆盖完整 = 7 问全答)
EV  = min(1.0, avg_answer_len / 200)    (答案深度)
CDT = min(1.0, avg_refs / 5)            (跨域迁移)
score = clamp01(0.25 * (SC + NR + EV + CDT))
```

关键代码 (1057 行新方法, 摘要)：
```python
def _measure_open_rubric_score(self, spec: DimensionSpec) -> Dict[str, Any]:
    from apeireth.v1003_v4_philosophy_full import V1003V4PhilosophyFull
    p = V1003V4PhilosophyFull()
    answers = p.all_answers()
    n = len(answers)
    if n == 0:
        return {"score": 0.0, ...}
    # SC: 答案 anchor 都非空 + 长度 >= 5 (主 22:33 真锚定)
    n_with_anchor = sum(1 for a in answers.values()
                       if a.anchor and len(a.anchor.strip()) >= 5)
    sc = n_with_anchor / n
    # NR: V4_PHILOSOPHY_FULL 是 dict, 7 key 天然唯一; coverage = n/7
    nr = min(1.0, n / 7.0)
    # EV: 平均 answer 长度 (200字 = 1.0)
    avg_len = sum(len(a.answer or "") for a in answers.values()) / n
    ev = min(1.0, avg_len / 200.0)
    # CDT: 平均 references 数 (5 个 = 1.0)
    avg_refs = sum(len(a.references or []) for a in answers.values()) / n
    cdt = min(1.0, avg_refs / 5.0)
    score = max(0.0, min(1.0, 0.25 * (sc + nr + ev + cdt)))
    return {"score": score, "raw": {
        "method": "v36_hqb_4dim_v1003_v4",
        "module_id": "V1003",
        "n_answers": n, "sc": sc, "nr": nr, "ev": ev, "cdt": cdt,
        "avg_answer_len": round(avg_len, 1),
        "avg_refs": round(avg_refs, 2),
        "n_with_anchor": n_with_anchor,
        "weights": {"sc": 0.25, "nr": 0.25, "ev": 0.25, "cdt": 0.25},
    }, "ts": time.time()}
```
