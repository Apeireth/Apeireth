## 5. 协议路由增强

### 5.1 X-Apeireth-Protocol header

| Header value | ProtocolKind | 用途 |
| --- | --- | --- |
| `openai` (默认) | OpenAiChat | 走 OpenAI Chat 协议 |
| `anthropic` | AnthropicMessages | 走 Anthropic Messages 协议 |
| `gemini` | Gemini | 走 Gemini GenerateContent 协议 |
| 其他 | None → 走 endpoint 默认 | K-1 强校验, 0 假装"任意字符串 OK" |

**用例**: 客户端调 `POST /v1/chat/completions` 但带 `X-Apeireth-Protocol: anthropic`,
daemon 走 Anthropic 协议 (用 base_url 配置的 provider, 跟 endpoint URL 解耦).

### 5.2 X-Apeireth-Force-Cache header

`X-Apeireth-Force-Cache: true` (或者 `1` / `yes`):
- cache 命中 → 返 cache 内容 (跟 1.0 行为一致)
- cache miss → **不**打上游, 返 `force cache miss: no cached response available` 错误

**debug 用**: 测 cache 是否生效, 不污染上游 LLM 流量.
