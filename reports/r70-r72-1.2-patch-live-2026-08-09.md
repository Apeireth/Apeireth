## R72: `crates/apeireth-mcp/src/subscriptions.rs` (NEW, 360 lines, +18 tests)

### 核心类型
- `Subscription { uri, client_id, created_at_unix_ms }` (per MCP spec §resources/subscribe)
- `SubscriptionManager` (Mutex<HashMap<URI, HashSet<client_id>>>)
- `handle_resources_subscribe(req) -> JsonRpcResponse`
- `handle_resources_unsubscribe(req) -> JsonRpcResponse`
- `build_resource_updated_notification(uri) -> JsonRpcRequest` (notifications/resources/updated, id = None)
- 错误码: SUBSCRIBE_INVALID_URI (-32020) / SUBSCRIBE_NOT_FOUND (-32021) / SUBSCRIBE_ALREADY_SUBSCRIBED (-32022)

### API 摘要
```rust
use apeireth_mcp::subscriptions::{
    Subscription, SubscriptionManager,
    handle_resources_subscribe, handle_resources_unsubscribe,
    build_resource_updated_notification,
};
let mgr = SubscriptionManager::new();
mgr.subscribe("file:///a.rs", "client-1").unwrap();
// ... 业务 ...
let subs = mgr.subscribers("file:///a.rs"); // -> ["client-1"]
let notification = build_resource_updated_notification("file:///a.rs");
// → 推送给所有 subscriber
```
