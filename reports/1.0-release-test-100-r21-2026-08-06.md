### 1.2 根因 (per 整合 #3 D-1)

| 失败测试 | 文件位置 | 失败 cmd | 根因 |
|---------|---------|---------|------|
| `lib_tests::lib_end_to_end_4_traits_via_registry` | `src/lib.rs:280-287` | `{"cmd": "echo e2e-ok"}` | Windows `echo` 是 cmd.exe 内置, 0 standalone echo.exe; `tokio::process::Command::new("echo")` 找不到 binary |
| `register::tests::register_all_tools_dispatch_via_tool_trait` | `src/register.rs:151-158` | `{"cmd": "echo via-registry"}` | 同上 |

**机制**: `ShellCodeExec::exec` (per `src/code_exec.rs:108`) 走 `shell_words::split(cmd)` 拆 argv 后**直接 fork**, 0 走 shell. 在 Windows 上, `echo` 是 `cmd.exe` 的 builtin, 没有 `echo.exe` 可执行文件, 所以 `Command::new("echo")` 失败.

**关键**: `tests/e2e.rs:105` 已经修了同款问题 (用 `cmd /c echo` on Windows). 整合 #3 C5 (eccb0609) 改了 8 个 tests/ 目录文件, 但**漏了** src/ 内 `#[cfg(test)] mod tests` 这 2 个 (因为 src/ 内 test code 不在 tests/ 目录, 整合 #3 守门未覆盖 → 标 D-1 R21 续).
