## ✅ 编译期 hardcode (主哲学锚 #6 工程铁律)

`src/lib.rs` 末尾的 `const _: () = { ... }` 块包含 7 项编译期断言:

| # | 断言 | 含义 |
|---|------|------|
| 1 | `PROTOCOL_COUNT == 4` | 4 协议总数, 加新协议必改 |
| 2 | `KEEP_ALIVE_KEEP_ALIVE` | 借鉴 VCP 必为 true |
| 3 | `KEEP_ALIVE_KEEP_ALIVE_MSECS >= 100` | TCP 探针间隔 |
| 4 | `KEEP_ALIVE_FREE_SOCKET_TIMEOUT >= 1000` | 8s 杀 zombie socket (VCP 真值 8000) |
| 5 | `KEEP_ALIVE_SCHEDULING_LIFO` | LIFO 优先复用最新鲜 (VCP 真值 'lifo') |
| 6 | `OPENAI_MAX_TEMPERATURE == 2.0` | OpenAI 协议规定 |
| 7 | `ANTHROPIC_MAX_TEMPERATURE < OPENAI_MAX_TEMPERATURE` | Anthropic [0,1] 比 OpenAI 严 |

**借鉴来源逐字段**: `KEEP_ALIVE_KEEP_ALIVE_MSECS = 1000` (VCP `keepAliveMsecs: 1000`),
`KEEP_ALIVE_FREE_SOCKET_TIMEOUT = 8000` (VCP `freeSocketTimeout: 8000`),
`KEEP_ALIVE_MAX_SOCKETS = 10000` (VCP `maxSockets: 10000`)。
