## §2. 核心实现: `log_replay.rs`

### 2.1 公开类型 (5 LogLevel + 3 ReplaySpeed + LogEntry + LogStats + LogReplay)

```rust
// 5 档日志级别 (per tracing 标准, 0 Critical)
pub enum LogLevel { Trace, Debug, Info, Warn, Error }

// 3 档回放速度
pub enum ReplaySpeed {
    RealTime,        // 按 timestamp 差 sleep (字段级 1:1 借鉴 VCP REPLAY_INTERVAL_MS)
    FastForward(u32),// N 倍速 (N=1 等价 RealTime, N=0 退化为 RealTime)
    Instant,         // 0 sleep 立刻全发
}

// 单条日志 (JSONL 1 行 = 1 LogEntry)
pub struct LogEntry {
    #[serde(with = "systemtime_ms")] pub timestamp: SystemTime,  // u64 ms since UNIX_EPOCH
    pub level: LogLevel,
    pub target: String,
    pub message: String,
    #[serde(default)] pub fields: BTreeMap<String, Value>,
}

// 统计 (字段级 1:1 借鉴 VCP getStats)
pub struct LogStats {
    pub total: usize,
    pub by_level: BTreeMap<LogLevel, usize>,   // 5 档全展示 (Trace/Debug 即使 0 也展示)
    pub by_target: BTreeMap<String, usize>,
    pub time_range: (SystemTime, SystemTime),  // 空时 = (UNIX_EPOCH, UNIX_EPOCH)
}

// 主结构 (字段级 1:1 借鉴 VCP cache + cursor)
pub struct LogReplay {
    entries: Vec<LogEntry>,  // ← VCP cache: []
    cursor: usize,           // ← VCP 内部 cache 索引
}
```
