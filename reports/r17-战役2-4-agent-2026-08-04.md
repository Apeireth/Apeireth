## 3. 3 大模块真实现 (5 大真货, 不只 mock)

### 3.1 `Agent` struct — 6 字段 typed

| 字段 | 类型 | VCP 对应 | 实战意义 |
|------|------|---------|---------|
| `id` | `String` | `agentMap.get(alias) → filename` (去掉扩展) | 唯一 ID, 内部识别 |
| `name` | `String` | (VCP 没有, 我们加) | UI 显示 |
| `aliases` | `Vec<String>` | `agentMap: Map<alias, filename>` (反向: filename → aliases) | 多 alias 引用同 agent |
| `tools` | `Vec<String>` | (VCP 没有, 我们加) | 战役 2-1 `ToolRegistry::get(name)` 关联 |
| `system_prompt` | `String` | `promptCache.get(alias) → file content` | Agent system prompt |
| `created_at` | `i64` (ms) | (VCP 没有, 我们加) | 审计 + 排序 |

**真实现**:
- `all_aliases()`: id 自身 + aliases 去重 (实战: 1 agent N alias)
- `matches(key)`: id 或 alias 任一命中
- `Serialize/Deserialize`: JSON round-trip (实战: config 持久化)

### 3.2 `AgentManager` 主体 — CRUD + alias + cache + watcher

| 方法 | 行为 | VCP 借鉴 |
|------|------|---------|
| `new() / with_cache_size(n)` | 新建 manager, 默认 cache=64 | `agentManager.js:10-17 constructor` |
| `register(agent) -> Result<(), String>` | 注册 + 维护 alias_index + 清 cache + 推事件 | `agentManager.js:36-63 loadMap` |
| `unregister(id_or_alias) -> Result<Arc<Agent>, String>` | 反注册 + 清 alias + 清 cache + 推事件 | (VCP 隐式 reload, 我们 typed API) |
| `get(id) -> Option<Arc<Agent>>` | 按 id 拿 (不走 alias 解析) | (VCP 无 typed get) |
| `resolve(id_or_alias) -> Option<Arc<Agent>>` | alias 解析 + LRU cache | `agentManager.js:272-315 getAgentPrompt` |
| `list() / list_ids() / list_aliases()` | 列出 (排序) | `agentManager.js:13 agentFiles` |
| `contains(id_or_alias) -> bool` | 是否注册 (id 或 alias) | `agentManager.js:322-324 isAgent` |
| `clear_cache() / cache_len() / cache_capacity()` | cache 操作 | `agentManager.js:50 promptCache.clear()` |
| `watch_dir(path) -> Result<(), String>` | notify 监听 + 推 FileAdded/Changed/Removed 事件 | `agentManager.js:82-127 chokidar.watch` |
| `stop_watching() / watched_dir()` | 停 watcher | (VCP 无显式 stop) |
| `take_events() / peek_events() / event_count()` | 事件流操作 | (VCP 隐式 console.log) |

**真实现亮点**:
- `register` 时如果 id 已存在, **先 unregister 旧 + 再注册新** (VCP `loadMap` 行为)
- `register` 自动 dedup: `id == alias` 时只算 1 个 alias index entry
- `resolve` 真用 LRU: cache miss → alias 解析 → 写 cache; 二次 resolve 同 key → 命中
- `watch_dir` 用 `Arc<Mutex<Vec<AgentEvent>>>` 让 watcher 闭包能 push 到 self (设计已修, 见 §9.1)
- `watch_dir` 自动创建 dir (实战: 主人首次启动无 dir, 不能 panic)
- `unregister` 真清 alias_index (但保留被其他 agent 接管的新 alias, 见 `manager_unregister_only_clears_own_aliases`)

### 3.3 `AgentEvent` enum — 5 事件

```rust
pub enum AgentEvent {

    Unregistered { id: String },
    FileChanged { path: PathBuf },
    FileAdded { path: PathBuf },

}
```

**实战**: typed event 推给 Tauri / SSE handler, 实战可 callback. 现在 FIFO queue (`event_log`) 供测试/debug.

## 9. 已知问题 + 修复 (2 修复)

### 9.1 修 1: `event_log` 设计 (真实 bug)

**问题**: 初版 `event_log: Mutex<Vec<AgentEvent>>` (parking_lot), `watch_dir` 内部创建 local `Arc<Mutex<Vec<AgentEvent>>>`, 闭包 push 到 local Arc. 闭包 return 时 local Arc 被 move 进闭包, self.event_log 收不到事件.

**修**: `event_log: Arc<Mutex<Vec<AgentEvent>>>` 提到 struct 字段, `watch_dir` 闭包 `Arc::clone(&self.event_log)` 共享, push 事件到 self.

**测试**:
- `manager_watch_dir_triggers_file_event` — 写文件 → 等 2s → 验 FileAdded (现在 OK)
- `manager_watch_dir_triggers_file_changed` — Modify → FileChanged (现在 OK)

- `manager_register_overwrites_same_id`: 假设旧 alias "@old" 在 overwrite 后仍可达 (实际 register 内部 unregister 旧, 旧 alias 已清)

**修**: 3 处断言改对, runtime 测过 52 全过.
