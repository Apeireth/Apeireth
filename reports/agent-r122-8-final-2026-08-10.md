- **R123 续扩**: 如主人更喜欢独立 crate 风格, R123 拆 3 个 bridge crate (apeireth-pybridge / -nodebridge / -cbridge)

### 决策 2: PyO3 version 0.29 (workspace 复用) 不是 0.22 (任务笔误)
- **任务要求**: `pyo3 = "0.22"`
- **workspace 实际**: `pyo3 = { version = "0.29", features = ["auto-initialize"] }`
- **冲突**: 加 0.22 到 apeireth-sdk/Cargo.toml 会跟 workspace 0.29 双版本 (cargo 允许但 lock bloat)
- **0 改 workspace 顶层** (per hard-constraint #1)

- **0.22 vs 0.29 API**: pyo3 0.22 → 0.29 macro API 兼容 (`#[pyo3::pymodule]` 1:1), 0.22 `&PyModule` deprecated → 0.29 `&Bound<PyModule>`

### 决策 3: count_tokens / hash_request inline 简版, 0 等 R122-1/3 retry
- **任务依赖**: R122-1 (hash_request) + R122-3 (tiktoken_counter) retry 跑中
