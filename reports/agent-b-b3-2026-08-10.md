## 1. 目标

任务 spec: 在 `protocol_handlers.rs` 加 `BackoffPolicy` enum (Aggressive / Default / Patient / Custom),
默认 = Patient (1s/3s/10s/30s/2m/10m), 4xx 不重试 (除 408/425/429), 5xx 全重试,
network error 全重试, 写 metrics `retry.count` / `retry.exhausted`, 20+ unit test.

  - 原 `dispatch` / `dispatch_cached` / `dispatch_inner` / `run_gemini` / `run_anthropic_minimaxi` / `send_and_decode` 1.0 行为 0 漂移 (调 _with_status + 丢 status)

### 2.3 决策点

详见 `reports/decision-log-2026-08-10.md` 决策 #2.

| 项 | 决策 |
| --- | --- |
| BackoffPolicy 4 档 | Aggressive (1s/3s/10s) / Default (1s/3s/10s/30s) / Patient (1s/3s/10s/30s/2m/10m) / Custom |
| 默认 | **Patient** (主人 6 锚 S-1: 可靠 > 快) |
| 4xx 重试白名单 | 408 / 425 / 429 (任务 spec 明确) |
| 5xx 重试 | 全重试 (500/502/503/504/...) |
| network error 重试 | 全重试 (status = 0 表示 reqwest send/read body 失败) |
