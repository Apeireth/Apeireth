### 3.3 fingerprint 计算方法 (per O-2 走在前人肩上, 跟 cosign 一致)

```python
import hashlib
from cryptography.hazmat.primitives.serialization import load_pem_public_key
from cryptography.hazmat.primitives import serialization

# 1. 读 PEM
pubkey_text = open("cosign.pub", "r", encoding="ascii").read()
# 2. 解码为 EC public key object
pubkey_obj = load_pem_public_key(pubkey_text.encode("ascii"))
# 3. 重新编码为 DER (SubjectPublicKeyInfo)
pubkey_der = pubkey_obj.public_bytes(
    encoding=serialization.Encoding.DER,
    format=serialization.PublicFormat.SubjectPublicKeyInfo,
)
# 4. sha256 of DER
fingerprint = hashlib.sha256(pubkey_der).hexdigest()
# 5. 输出
print(fingerprint)  # 0dbcaa9af6a9360d20baa45feba4cd4da9ff887a25226aaaf2ca24c8e01df761
```
