# apeireth-vector

> v2 port of v1.0-legacy/apeireth-vector (complete API surface preserved).

Vector store framework:
- Traits: Vector / VectorStore / ScoredId / SearchHit
- SqliteVecBackend (sqlite-based vector storage)
- QdrantClient (HTTP-compatible Qdrant client)
- Distance utilities (distance.rs)
- Error type: VectorError

Organ Kani proofs in organ_kani_proofs.rs.
