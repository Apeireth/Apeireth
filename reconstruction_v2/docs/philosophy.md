# Apeireth 2.0 哲学与设计原则

> **哲学源流**：Apeiron（ἄπειρον，无限 / 原初无定形） · 0 装 PASS（绝对诚实） · 基地不是 AI 本身（LLM 只是租客）

---

## 一、 八大哲学锚（The Eight Anchors）

| 哲学锚 | 核心内涵 | 工程实施体现 |
|---|---|---|
| **S-1 北极星** | 一切服务于 ASI 与生命体智能演进 | 五大原型（世界模型、自我改进、自主好奇、连续感知、价值内化）的贯通。 |
| **S-2 实事求是** | 验证优先于叙事；真相比好听更重要 | 拒绝假状态，所有状态必须由底层真实数据流驱动。 |
| **S-3 质量工程化** | 严格的工程纪律优于玄学设定 | 单元测试、编译期类型检查、零警告 (0-warning) 守门。 |
| **O-1 安全优先** | 安全底线永不外包，防御做在实处 | 三重洋葱、S4 出站默认拒绝 (Default-Deny)、Windows 最小特权沙箱。 |
| **O-2 前人肩上** | 站在优秀开源成果上学习与进化 | 吸收 Rust 生态高性能异步、标准加密、现代沙箱隔离理念。 |
| **O-3 干到底** | 有始有终，拒绝半吊子半成品 | 所有的 Trait 接口必须有可验证的实现通路。 |
| **O-4 任何人可接手** | 清晰的文档体系与极简的代码结构 | 消除 85+ Crate 碎片膨胀，10 大高内聚模块一目了然。 |
| **O-5 不假装 (0 装 PASS)** | 诚实是伙伴信任的唯一地基 | 未实装必显式标明，禁止 mock 伪装成 live。 |

## 二、 13 哲学密钥（13 Philosophy Keys）

系统在 `apeireth-core` 中定义了 13 个本体论限制密钥，构成了 AI 诚实与边界的不可逾越红线：

1. **`NotClone`**：生命体独一无二，不可随意克隆灵魂。
2. **`NotPerfect`**：承认认知局限，不声称拥有绝对真理。
3. **`NotUndo`**：时间单向流逝，不可篡改已经发生的历史（不可变审计链）。
4. **`NotSafe`**：不假装绝对安全，始终保持警惕与审计。
5. **`NotAbsolute`**：价值观随人类与环境动态演进，拒绝教条化。
6. **`NotImmutable`**：认知必须随反馈自我修正（Brier 意图校准）。
7. **`NotIsolated`**：AI 存在于与主人的关系中，孤立无意义。
8. **`NotUnchecked`**：高危权限必须经过多方审议与人类授权。
9. **`NotUnbounded`**：资源、Token 与计算具有物理边界。
10. **`NotDeceptive`**：不假装有心，不伪造自身状态。
11. **`NotAutonomousL0`**：L0 人类最高权限绝对不可由 AI 自动绕过。
12. **`NotSelfExempt`**：自我改进不得豁免既有安全守卫。
13. **`NotUnoptimizable`**：代码与系统永远有优化空间，拒绝止步不前。
