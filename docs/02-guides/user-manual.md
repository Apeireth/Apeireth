# Apeireth 用户手册

> 给运行 Apeireth 的人：它在做什么、我怎么控制它。机制描述以真实代码为准（2026-08-18）。
> 快速跑起来见 [quick-start.md](quick-start.md)；部署见 [deployment.md](deployment.md)。

## 1. Apeireth 是什么

**基地，不是 AI 本身**：Apeireth 是给 LLM 的操作系统——提供器官、工具、记忆、安全边界、关系可能性；不定义 AI 是什么。接入一个 LLM（默认 MiniMax-M3），基地给它：记忆、工具、安全边界、主动陪伴的节奏、与你的关系存档。

三种运行形态：

| 形态 | 说明 |
|---|---|
| **companion_serve** | OpenAI 兼容端点（:8090）——任何兼容前端接上即拥有全部能力；对话 + 记忆生命周期 + SSE 主动送达 |
| **TUI** | 终端伙伴面板（9 organ 仪表盘）|
| **CLI** | 命令行工具（crates 装配矩阵）|

## 2. 她怎么记得你

- **记忆 v2**：对话经提炼器打分（importance 1-10）→ 对账（新增/更新/删除 + 墓碑）→ 排名注入。高频访问的记忆永不冷。
- **图谱**：事实三元组（s/p/o）带时间有效性——"熬夜 → 次日疲惫"这种因果边会从你的生活记录里长出来（W3）。
- **滚动摘要**：长对话自动压缩成摘要链，常驻上下文（L1 Essential）。
- **做梦**：夜间（安静期默认 6h）自动整合记忆。
- **情绪时间线**（F1）：她记录你的情绪状态（文本信号/显式反馈），趋势与"上次你这么低落时什么有用"。
- **连续性**：跨前端（SSE/Lark/Telegram/Web）同一叙事线（continuity_id）。

## 3. 她怎么主动找你

- **涌现循环**（E7）：节律学习（你几点活跃）+ 关系压力（沉默 × 温暖度）+ 情绪门控 + 安静窗 + 每日上限——她学*什么时候*开口。
- 你回应 → 关系加深；忽略 → 变淡（负性偏误，如实）。
- **主动送达**：SSE 推送 / Lark / Telegram（配置见 deployment）。

## 4. 她怎么用工具

1. LLM 输出 `<<<[TOOL_REQUEST]>>>` marker → 解析
2. **审批**：5 规则（黑名单/信任/风险/频率/白名单）——高危工具默认需你批准
3. 批准后执行（schema 校验 + guardrail：路径穿越/命令注入拦截）
4. 结果记录 + 即时沉淀（工具结果成为记忆候选）

**控制它**：待批请求在 `/v1/apeireth/approval-requests`；批准后对话里说"重试"即可。`APEIRETH_GRANT=FileOperator:24` 可显式放行某工具 24 小时。

## 5. 她怎么"想"

- **世界模型**：推演"如果 X 会怎样"的反事实链，Brier 校准——校准差她不会硬说。
- **好奇心**（E4）：记忆回声偏置——你常聊的方向她更想深入，但不设白名单（她自由好奇）。
- **假设检验**（F4）：她会对关于你的命题提出猜想、收集证据、定论，确认的写回因果图。
- **价值内化**（F6）：价值冲突案例 + 你的反馈回流——同一冲突裁决足够多次变成原则。
- **自我诊断**（W6）：她对"我是否猜对你想表达什么"做 Brier 评分——知道自己哪里理解得不准。

## 6. 安全和边界

- **权限洋葱**：L0 人类批准永不可变；工具按风险分级
- **宪法**：结构化规则硬门 + LLM 评审（E 层判案）
- **沙箱**：Windows Job Object（时间/内存/CPU 限额 + 超限留痕）
- **出站**：接入方启用后默认拒绝白名单外域名 + SHA-256 审计链
- **隐私**：出站 PII 脱敏（guard）

## 7. 常见问题

| 问题 | 答案 |
|---|---|
| 她怎么不主动找我？ | 检查安静窗/每日上限/关系深度；刚认识时她确实谨慎（min_depth 0.3）|
| 工具被拒了？ | 预期行为——高危工具需批准；`APEIRETH_GRANT` 可显式放行 |
| 记忆不涨？ | 提炼节流默认 600s；确认消息进入对话主链路 |
| 换模型？ | 换 `APEIRETH_API_KEY`/provider 配置即可——基地不绑定模型（trait 注入）|
| 她说的我不信？ | 她的校准机制（Brier）会标注不确定——0 装 PASS 是设计不是缺陷 |
