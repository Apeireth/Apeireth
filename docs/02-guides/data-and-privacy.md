## 一、我们不承诺「完全不外流」，我们承诺「你不想外露的不会外流」

**红线是动态的，不是位置的。**

- ❌ 旧口径：「数据一律不离开这台机器」—— 这不成立：只要你用云端模型，
  上下文就一定会离开机器。要么诚实承认，要么骗人。
- ✅ 现口径：**「用户不想外露的数据不能外流」** —— 按**对象**（哪份数据）、
  按**用途**（给谁、干什么）、**可撤销**地控制。

三条边界在跑（不是口号）：

| 边界 | 谁在管 | 现在什么状态 |
|---|---|---|
| 工具出网（fetch 等） | 出网控制：域名/地址许可 + 策略档 | **PRODUCTION WIRED**（`sec.egress_control`） |
| 对象级越界（shell 读工作区外的对象） | 对象级判定：按对象域 × 主体判，越界即帧 | **PRODUCTION WIRED**（`sec.object_access`） |
| **模型上下文出境**（送给 provider 的那段话） | **出网闸**：检出敏感值 → 换成不可逆占位；闸不可用 → 拒绝出网 | **PRODUCTION WIRED，默认关**（`sec.egress_gate`，`APEIRETH_ENABLE_EGRESS_GATE=1`） |

> 口径说明：上表三行都是 `claims.yaml` 里的**能力声明**，可按声明里的
> `verify_cmd` 亲自复核。**默认关 = 未显式开启时不改变任何行为**，
> 这不是「更安全的默认值」而是「先接线、默认不动」。

## 二、我们保证什么 / 不保证什么

按 **R1–R4** 分级（你在我们的能力声明与承诺里都会看到这套编号）：

| | 承诺 | 状态 |
|---|---|---|
| **R1** | **停止未来外流** —— 你撤回授权后，之后不再出去 | ✅ **保证**（在自己控制范围内的部分） |
| **R2** | 撤回**已导出副本** | ❌ **不保证**（已经交出去的副本不在我们手里） |
| **R3** | **撤回本系统内派生结论** —— 基于旧事实得出的结论作废并可追溯 | ✅ **保证** |
| **R4** | 抹除**模型侧残留** | ❌ **不保证**（provider 侧行为不由我们决定） |

### 正确的说法是这一句

> **我们保证自己控制范围内的停止与撤回；对于外部副本和模型残留，我们不能保证删除，
> 但会明确记录已知流向、提供请求路径，并在发现影响时通知你。**

「不能控制」不是免责 —— 它被翻译成三项**具体义务**：

1. **记录流向**：每次出网都记下「什么对象、什么用途、去了哪」（只记指涉，不记内容原文）；
2. **提供请求路径**：需要第三方删除时，给你可执行的请求方式，而不是「我们尽力」；
3. **发现影响时通知**：一条被纠正的旧事实若曾影响过对外行动，会生成待办提醒你。

### 我们根本管不了的（如实说管不了）

- 你自己已经复制、转发出去的内容；
- 第三方系统的内部留存；
- 你根据建议**已经完成**的外部决策（买过、签过、发过、投过）—— 但我们会告诉你
  哪条建议被推翻了、影响过哪些行动，并给出补救路径。

## 三、provider 侧：我们不替别人承诺

你的上下文送到模型服务商那边之后，**那一段的处置由他们决定**。

**已取得官方原文的最硬口径**：Anthropic 商业 API 默认不训练、输入输出 30 天删除、可签 ZDR。

**OpenAI / Google Gemini / Mistral：本次未取得官方原文**（403/超时）—— 不知道就是不知道，
我们不替他们写「应该也是」。

**这意味着什么**：R2/R4 之所以不承诺，不是因为我们偷懒，而是因为**承诺了也兑现不了**。
兑现不了的承诺比不承诺更坏。

## 四、怎么查账（不只信我们）

| 想查什么 | 去哪查 |
|---|---|
| 某个能力到底接了没、默认开还是关 | [`docs/status/claims.yaml`](../status/claims.yaml)（唯一真源，26+ 条，每条带 `sources` / `tests` / `verify_cmd`） |
| 系统此刻自报什么 | 自述面（21 节冻结合同，**拿不到就写 `null` + 原因**，不编） |
| 发生过什么 | 审计哈希链（append-only，坏行读作不存在） |
| 有没有「实现了但没接电」的 | [未接线台账](../status/unwired-ledger.md) + `scripts/audit_unwired.py` |
| 出网记录 | 出域账本（只记指涉与用途，**零真值**） |

> **重要**：`claims.yaml` 是唯一真源，但**用户不会去读它**。
> 所以承诺的落点不止文档 —— 还要进自述面、进拒绝时的可读原因。

## 五、拒绝时你会看到什么

我们的一条硬纪律：**拒绝必须可读**。

不好：
```
error: denied
```

应该：
```
这次没有把内容发出去：检测到「个人身份信息」，而「发送给外部模型」
这一用途你还没授权。
下一步：在设置里对该用途授权，或改问不涉及这些内容的问题。
```

（这是我们要建的方向。**当前状态**：出网闸 **PRODUCTION WIRED**（默认关），可读拒绝原因的
统一形态仍在实施中 —— 未完成的按「0 装诚实」如实标注，不假装已有。）

## 六、一句话版本

> **Apeireth 不会替你把数据交出去。**
> 它本地跑、逐条可控、每一步留痕；
> 交出去之前会告诉你，交出去之后能撤回自己控制范围内的部分；
> 撤不回的（已经到别人手里的），它不假装能撤，
> 但会告诉你**已知流向**、**怎么去请求删除**、以及**哪条结论被推翻了、影响了什么**。
