> `Status: ✅ 随批 B 落地（2026-10-11）`

> 核对授权条款**。平台不分发、不托管、不生成派生任何第三方形象资产，许可责任
> 由使用者自担（装载前的免责确认与本文口径一致）。

---

## 1. 一分钟接入

1. 桌宠窗**右键 →「接入形象文件…」**；
2. 选一个**开放 3D 人形格式**的形象文件（`.vrm` / `.glb`，≤64MB）；
3. 阅读并确认免责文案（"我确认有权使用"）；
4. 完成——形象层自动切到「角色形象」，本机持久化，下次启动自动恢复。

移除：右键 →「移除形象文件」。换装不换契约：姿态/呼吸/口型/视线/眨眼的驱动
与内置形象完全一致。

## 2. 形象文件要求

| 项 | 要求 |
|---|---|
| 格式 | 开放 3D 人形格式容器（`.vrm` 优先；`.glb` 需含该格式扩展） |
| 体积 | ≤64MB（超限拒收，可先做减面/压纹理） |
| 结构 | 标准人形骨架（有头/脊/四肢标准骨位），表情声明含口型与眨眼更佳 |
| 许可 | **你须有权使用**（含展示与修改）；平台不审、不背书 |

- 形象文件**内嵌的许可声明**会被如实读出显示在右键菜单（"未声明"就是未声明，
  平台不替你解读）；
- 装载失败/格式不符会给出真实理由，回落默认形象（绝不空窗）。

## 3. 去哪里找形象（指路不背书）

| 生态类型 | 说明 | 入口示例 |
|---|---|---|
| 开放 3D 人形格式社区/目录 | 模型常内嵌机读许可声明（可商用/可再分发字段），优先看声明 | 格式官方站点与模型目录（如 vrm.dev 一系） |
| 创作共用素材库 | 逐件标注许可（CC0 / 署名类可商用；NC/ND 类不可商用） | 通用创作共用素材库（如 OpenGameArt 一系） |
| 独立素材工作室 | 整站单件许可清晰（如 CC0 一系） | 独立工作室站点（如 kenney.nl 一系） |
| 模型市场/转卖平台 | **逐件许可混杂**，常见"仅个人使用/禁改禁转"，购买前逐件核对 | 各类模型市场（不一一点名，自核为准） |

**三条铁律**：① "免费下载"≠可商用；② "仅供个人使用"的模型只能个人本地用，
不得随产品分发；③ 拿不准就换一个来源——形象千千万，合规第一条。

## 4. 平台侧边界（为什么这么设计）

- 平台**不随包分发任何第三方形象资产**：内置只有程序化"素体"与光态哨兵
  （零资产零许可面）；
- 平台只校验**格式合法性**（扩展名/体积/容器魔数），不审你的资产许可；
- 你自带的形象只存**你本机**（IndexedDB），不上传、不备份、不生成派生。
