## 0. 一句话总纲

Apeireth 的核心不是"接了大模型"——大模型谁都能接。核心是**围绕大模型的那圈"记忆与信任的机器"**：
记忆系统让它记得你（而且忘得符合人性、丢不了），治理系统让它的每个动作可审计可回滚，
调度系统让它不跑飞，沙箱让它伤不到你。**市面产品拼模型，我们拼模型外面这圈。**

## 1. 心脏：记忆系统（本产品的立身之本）

### 1.1 存 —— 为什么"丢不了"

- **Episode 流 + 追加写死**：每次对话、每个工具结果都以不可变事件入库；数据库层用
  `BEFORE UPDATE/DELETE` 触发器直接 `ABORT`——**想改历史，SQL 层面就做不到**。
- **Merkle 哈希链**：每条记忆带前序摘要，像区块链一样串起来——任何历史被悄悄改动，链就断。
- **双时态**（这是市面产品几乎都没有的）：每条事实带两个时间——"事情发生的时刻"和"我们记录它的时刻"。
  于是可以问"**去年三月我们以为的 X 是什么**"，而不仅是"X 现在是什么"。这对一个要陪你几十年的伙伴是本质能力：
  记忆不只是内容，还包括"我们当时怎么理解的"。
- **分区隔离**：每个人一个记忆分区（单主体 × N 分区），跨分区披露在治理层是 R4 级操作。

> **指导者要点**：追问任何记忆产品的三件事——历史可改吗（我们 SQL 级不可改）、有时间维度吗（我们双时态）、能证明没丢吗（我们 Merkle + 今日 TLA 机器证明"撤回不删版本/遗忘幂等/保护的永不忘"）。

### 1.2 取 —— 为什么"记得你随口说的话"

五层混合检索，每层解决一类失败：

| 层 | 解决什么 | 例子 |
|---|---|---|
| BM25 词法 | 精确字面匹配 | 名字、编号、菜名这种"一字不差"的 |
| 稠密向量 | 语义相似 | "他妈妈腌的萝卜干" ≈ "母亲做的咸菜" |
| RRF 融合 | 两边都不偏科 | 词法向量各说各话时的裁判 |
| ACT-R 激活 | 最近常用的自然浮起 | 昨天聊过的今天更容易想起（近因/频次衰减） |
| 三层渐进披露 | 控制上下文成本 | L0 身份常驻 → L1 工作集 → L2 长期库 |

**对比市面**：ChatGPT/Claude 的记忆本质是"事实清单 + 向量召回"一层皮；我们是**词法+语义+时间心理物理**的混合场。
体验差别：他们记得"你说过喜欢喝茶"；我们记得"三年前那个雨天你说想喝妈妈做的咸菜汤，因为那天你刚失去她"——**带情境、带时间、带原因**。

### 1.3 忘 —— 为什么会"淡"，但不会"错"（详解）

人类遗忘有三个性质，我们逐条实现：

**性质 1：遗忘是渐变，不是删除。** 艾宾浩斯衰减 $R(t)=(1+\alpha t)^{-\beta}$ 作用在"可及性权重"上——
时间越久、唤起越少，召回概率越低，但记忆本体仍在库。体验上：常聊的随口想起，半年前的细节要使劲问。
对比：ChatGPT memory 到条数上限硬砍最旧；向量库按相似度阈值截断（无时间物理）——前者残忍，后者无记忆规律。

**性质 2：重要的永不淡（机器证明）。** `protect` 记忆（里程碑/明示"记住这个"/核心身份事实）永不衰减、
永不被任何清理路径触碰。该性质由 TLA+ 模型 `ProtectForget.tla` **穷尽证明**（67 万态）：
① 保护记忆不可能被遗忘路径碰到（retention 例行清扫也绕行）；② 遗忘幂等（忘一次=忘十次，无幽灵状态）；
③ 被遗忘的不悄悄复活（粘滞）。这是穷尽证明，不是抽样测试。

**性质 3：纠错≠失忆（"不会错"的核心）。** 改错与删除分两条路：
- **撤回（withdraw）**：不删旧版本，插入新版本并标记旧版"已撤回"——双时态里"你曾经以为的"和"现在的真相"
  并存，各带时间戳（"去年我以为我在哪工作"两个答案都答得出）；
- **删除（forget）**：R3 治理门——留痕、可撤销、保护记忆碰不到。
于是**遗忘只降低召回概率、永不翻转事实；纠错只做加法、从不抹历史**。"你是怎么知道的"永远能摆出证据链
（撤回不删版本同样是机器证明的不变量之一）。

### 1.4 想 —— 会成长的部分（详解）

四段流水线，把"经历"变成"成长"：

1. **蒸馏**：episodes → 结构化认知（ADD/UPDATE/DELETE + 墓碑对账，像 Git 管理认知增删改，不覆盖）。
   确定性启发式优先，LLM 只在显式信号出现时参与。
2. **整合（consolidation）**：碎片 → 洞察。实测抓掉过"洞察自我增殖"级联 bug（蒸馏产物再被蒸馏出幽灵副本）；
   修法本质：**只从原始证据蒸馏，绝不从蒸馏产物再蒸馏** + 稳定 ID 幂等断言（引用引原文，不引综述的综述）。
3. **反思（reflexion）**：核心纪律——**Judge 显式非 Pass 判定才算失败，绝不从文本猜失败**。
   流程：行动结束 → 显式判定 → 沉淀 DecisionRejected → 规则批评家蒸馏成教训 → 下轮 TurnStart 注入。
   配套"反幻觉注入格式"：引用必须带证据编号，明令禁止无证据的"我记得我们以前聊过"。宁可漏记，不许记错。
4. **成长出口**：产物流入 原则（它信什么，修改走 R4 重治理）/ 羁绊（关系阶段随深度跃迁）/ 里程碑（自动 protect）。

产品哲学是**"慢记忆"**：宁可成长慢，不让一条错误污染一生。对比三问（市面产品均答不上）：
记忆能撤回而不失忆吗？成长有证据锚吗？遗忘受保护吗？

### 1.5 体验层的诚实说明

"它记得你"的**机制**已经成立（默认开）；"它**理解**你"的深度目前上限是**上下文工程 + 检索质量**，不是模型本身更聪明——
模型是外接的（DeepSeek/MiniMax/本地），我们的前沿在记忆与信任，不在基座模型。指导方向时请把这两件事分开评。

## 2. 骨架：治理与审批（"可信"从哪来）

- **R0-R4 风险矩阵**：硬门看风险（R3 不可逆=人工审批，R4 控制面=冷静期+辩证评审），审批者看场景（个人=你批，组织=多签）。
- **三洋葱**：原则根（它信什么）与权限根（它能干什么）两把独立锁并行，改任一都触发重治理。
- **审批状态机**：三条**机器证明**的不变量——①批准只产生一次副作用（不会"批一次干两次"）；②批准意图永不丢失（崩溃恢复不改判）；③效果不确定的操作强制走审批。
- **对比市面**：主流 agent 的安全是"提示词里嘱咐它别乱来"；我们是**状态机强制 + 审计链 + 人类最终护栏**。这是产品气质的分水岭：一个"听话的工具" vs 一个"被制度约束的行动者"。

---

## 3. 肌肉：配额调度（为什么不会"跑飞"或"跑破产"）

- 给每轮推理配**多维配额**（Token / 步数 / 花费 / 深度），用完即停——agent 无限循环、烧钱失控这类事故在结构上被切断。
- **优先级继承**（PIP）：高优先级被低优先级堵住时，低优先级"继承"优先级让路——今天 TLA 证明了"配额始终非负、耗尽粘滞、高优先级不被饿死"。
- **对比市面**：LangChain/AutoGPT 时代靠 `while True` 撞运气；我们是带会计的调度器。

---

## 4. 双手：工具与沙箱（"能做事"且"伤不到你"）

- **唯一进程执行边界**：所有 shell/文件/网络动作走同一个受控执行器——没有旁门。
- **路径沙箱**：`..` 穿越、NUL 注入、敏感目录、密钥文件模式——五类逃逸路径今天全部**机器证明不可逃逸**。
- **外发管控**：网络出口白名单制，密钥/PII 出站被拦截。
- **物理隔离**：Windows JobObject / AppContainer，进程级囚笼。

---

## 5. 脸：在场感（为什么"活的光"值钱）

Ember 微光按 $I(t)=I_0+A\sin^3(2\pi t/4)$ 呼吸——目前是 CSS 渐变实现（诚实标注，GPU 光效列入主题系统愿景）。
它的价值不在炫技，在**把"工具"变成"在场"**：一个呼吸的光点让"陪伴"有了物理质感。
这层的验收靠人工体验评审（四层验收的第③层），因为它无法用单测证明。

---

## 6. 架构本身：为什么这么拆

18 个 crate = **内核（机制）+ 装配（接线）** 分离：内核只认抽象接口，装配层负责把记忆/工具/器官接起来。
好处：①全仓只有一个 runtime（不存在两套逻辑各说各话）；②启动 fail-closed（缺后端直接拒启，不带病上岗）；
③替换任何零件（换向量库、换模型）不动上层。这层今天的证据是实况盘点里"入口链逐跳确认完整"。

---

## 7. 合理性总评（给指导者的定心丸与清醒剂）

**强的（可以放心押注）**：记忆的不可篡改与双时态、混合检索、治理状态机、调度会计、验证文化（25 条机器证明 + TLA 实跑）。
**弱的（知道就行）**：理解深度受基座模型制约；体验层（点击流）人工验证还欠账；部分子系统（SDK/感知）是"建成未接线"。
**风险（盯住）**：宣称与实现的对账必须持续（挂标制已立）；AppContainer 探针的环境抖动要硬化；默认值要随用户群演进。

---

## 8. 三把尺子（以后对比任何产品就用这三轴）

1. **记忆深度轴**：扁平事实 → 语义检索 → 双时态+衰减+守恒证明。我们在最右。
2. **信任可验证轴**：口头承诺 → 测试覆盖 → 状态机+机器证明+人类护栏。我们在最右。
3. **体验在场轴**：输入框 → 好看 UI → 会呼吸的在场+记住一生。我们在第二三之间（正补体验闭环）。

市面产品通常在一根轴上卷（ChatGPT 卷模型、Rewind 卷记录量、Character.AI 卷人设）；
我们的路线是**三轴都要**——这就是"前沿"的含义，也是为什么需要你按这三根轴来指导取舍。
