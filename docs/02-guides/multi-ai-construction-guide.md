## 〇、一句话总纲

**干漂亮的活，零技术债，不互相踩。** 三个词解释全文：**0 装**（不假装：没测过就说没测过）、**中性表述**（零第三方产品名）、**叠加不覆盖**（多人同树施工不踩人）。

## 一、进场第一课清单（开工前 10 分钟）

按顺序做完再动手：

1. **读两份宪章**：[ENGINEER-MANIFESTO.md](../04-internal/ENGINEER-MANIFESTO.md)（哲学锚与工程规范）+ [CONSTRUCTION-DISCIPLINE.md](../04-internal/backend-enhancement/CONSTRUCTION-DISCIPLINE.md)（施工纪律）。冲突时以它们为准；
2. **记住设计第一律：AI 先用、人后用**（宪章 §〇）：一切工具性能力的第一用户是 agent 自己——能力先做成**工具**（模型可调用、过治理、入名册），人类界面是同内核的**包装出口**（不另起炉灶、不两套逻辑）。硬判据：**删掉人类界面后，该能力对 agent 仍然完整可用**；
3. **0 装 PASS（诚实纪律）**：未接线写「未接线」，桩要显式断言，未实测写「未实测」；双向——也不许把"已实现未接线"说成没做。默认关闭的能力不得写成系统现状；
4. **中性表述**：代码/注释/提交零第三方产品名、零来源沿革类措辞；交付前跑 `scripts/check-neutral-terms.ps1` 必须零命中（豁免表只收真实路径这类结构性豁免，**命中先改表述，不先改豁免表**）；
5. **LOCKED 5 项 0 触碰**：9 哲学锚本体 / 13 键 / 3 不可变脊柱 / workspace 版本轴 / R11 baseline——版本轴仅 release authority 可改；
6. **声明你的战场**：写明本批的 `write_scope`（动哪些文件），见 §二；
7. **知道出口在哪**：每批交付要过门禁（§四），数字有口径（§五），半成品留遗嘱（§三）。

## 二、战场互斥与报备（多人/多 AI 同树施工不打架）

多人同时在一棵工作树上施工，事故几乎全来自"踩了别人的在途工作"。守则六条：

1. **叠加不覆盖**：edit 前先读后改；文件冲突后到者 rebase，**不覆盖他人在途工作**（宪章 §二.1）；
2. **战场不重叠**：批与批的文件范围预先声明（`write_scope`），同文件区施工必须排队（宪章 §二.2）；
3. **他人战场禁入**：门禁取证时撞见他线在途半成品（编译错误/格式不净），**零触碰零代改**——如实标红 + 明确归属线 + 报备待归口线自检收口，绝不"顺手帮它修好"；
4. **占位必报、补位必注**：为在途线留位要落**显式占位**（如 `None` + 原因 + 报备注释），占位要"可被识别并喊破"（配自报测试，不做假旋钮）；跨线补位（如编译断点）按**对方自己的口径**补最小面，机械空白与语义改动分开声明；真接线归口原线；
5. **接缝当合同写**：开工前互相报备接缝口径（谁供什么形状、谁消费），交付文档抬头写「接缝（X 并行线，已兑现其报备）」，接缝行为用测试钉死；
6. **顺手修三判**（宪章 §六.3）：确证级小债（挂名不跑/静默失效）**顺手清**；验收必经但不在战场内的面 = **最小改动 + 报备 + 理由**；超范围的重构念头**登记不实施**（登记到 [00-backlog.md](../04-internal/backend-enhancement/00-backlog.md) 债栏）。

另有一条机械纪律：**共享收敛点不手改**——`Cargo.lock` 这类由工具收敛的文件交给包管理器，用 `--locked` 门禁复验一致性。

## 三、接棒遗嘱模板（半成品不弃尸）

批不可能一次做完。中道停机必须留遗嘱，否则半成品就是弃尸（宪章 §二.3）。交付文档固定一节「接棒清单（未完）」，每条写清**四件**：

1. **落点文件**（真实路径）；
2. **注册条件**（开关/依赖/同源要求）；
3. **现成零件**（已备好的构造器/挂载点）；
4. **验收形状**（测试名/断言形状）。

**模板（直接套）**：

```markdown
N. **<接棒项名>**（<落点文件>，<并发注意事项>）：<注册条件>；
   现成零件 = <构造器/挂载点>；验收形状 = <测试名/断言>。
   → ✅ 已收口（<日期> <收口批名>）：<注册条件兑现说明>；测试 `<测试名>` <例数>。
```

**收口纪律**：接棒项完成后**就地标 ✅ 并注明收口批**，不留悬空的"未完"——接棒清单是活文档，任一时刻「未完」列表必须反映真实残余。（实形先例与四要素详解见 [04-methodology.md](../04-internal/engineering-experience/04-methodology.md) §二。）

## 四、门禁三级（本批 / 全量 / 权威）

一张门禁表混跑三级口径会两头误事。分工如下：

| 级 | 跑什么 | 何时 | 产出什么 |
|---|---|---|---|
| **本批门禁** | 本批新增/触碰的测试目标 + 相关 crate 定向测试 | 施工中随时（快速出口） | 本批增量事实，只对本批负责 |
| **全量门禁** | 宪章 §四全量命令：`cargo test --workspace --all-targets --locked --no-fail-fast -j 2` + clippy `-D warnings` + `cargo fmt --check` + 前端 `pnpm check`/`pnpm test` + 中性表述扫描 + secret-scan | 每批交付出口必跑 | 全量实测数字（命令+日期+工具链随行，log 留档可复算） |
| **权威门禁** | 口径权威对照：测试数字对 [test-baseline.md](../03-reference/test-baseline.md)（单一真源）；「已验证」对 [live-verification-ledger.md](../04-internal/live-verification-ledger.md)（验收权威） | 数字/结论**对外发布前** | 可对外的口径 |

**要点**：
- 本批门禁的绿**不能**当交付门禁用——共树在途的回归只有全量看得见；
- 全量出红**先定性再定罪**：瞬时红先隔离复跑，有并行扰动证据的按 flake 定性（如实标红 + 归属线 + 理由）；负载敏感的真 flake **不许用"复跑绿了"收账**，必须定根后以测试/提交钉住；
- 验证/构建输出**落文件再判**，不在管道末端判（管道截断会把上游的失败吃掉，产出假绿）；
- 门禁报告里豁免计数可见；"扫描零命中" = 0 命中 **且** 豁免仅限结构性。

## 五、口径纪律（数字与表述的单一真源）

1. **测试数字单一真源**：以 [test-baseline.md](../03-reference/test-baseline.md) 为准，其余文档**只引用不抄写**；不一致如实报「本批实测值 + 日期」，**不代改真源**；
2. **无脚本不发布数字**：每个数字可复核 = 命令 + 日期 + 工具链；无脚本的推算数（"应该有 N 个"）不写；未实测就写「未实测」；
3. **实测/推断/未验三分标注**：结论出门前打标签——实测（附命令）、推断（明写推断，不得升级为事实）、未验（明写未验）。发现推断错误立即纠正并留档，不悄悄改口；
4. **命名即承诺**：符号/开关/字段的名 = 它的全部权力。新增开关/旋钮三问：名称承诺 == 实际权力（含依赖主开关、fail-closed 子依赖）？生效时机（即效/重启）声明一致？名册按**实际注册条件**取值？（先例：[capability-switch-power-audit.md](capability-switch-power-audit.md) 开关权力审计表）；
5. **报能力先报级别**：`IMPLEMENTED（代码存在）≠ PRODUCTION WIRED（接生产主路径）≠ DEFAULT ENABLED（默认开）≠ HARDWARE VALIDATED（真机验证）`——写"可用/已实现"前先答在哪一级，✅ 必须能指回证据（测试名/台账行/真机记录）；
6. **历史不追溯改写**：带日期的历史记录保留原值，需要时加「历史口径（日期）」标注；
7. **错误即帧**：失败走正式通道报真因，不静默降级、不谎帧；对外文案只写已交付能力，未交付进路线图并标阶段。

## 六、常见死法与药方速查

多 AI 大规模并行施工里反复出现的死法，每种一行药方（解剖与防复发断言全文见 [02-failure-anatomy.md](../04-internal/engineering-experience/02-failure-anatomy.md)）：

| 死法 | 症状 | 一行药方 |
|---|---|---|
| 启动猝死 | 新会话/子代理刚启动就无声死亡，零遗言 | 骨架先行 + 读取预算 + 分波派工；预算耗尽走优雅降级留痕 |
| 内容过滤误伤 | 读入/复述外部素材被上游过滤器拦杀 | 源头净化是**工序**：触发词替换占位后才入上下文，取材口径注随抬头 |
| 上下文读爆 | 读完 README/巨文件后会话超限或变笨 | 剥装饰（徽章/横幅）+ 限读封顶 + 渐进落盘（做一段落一段） |
| 路径拼接/键分叉 | 路径双前缀、写后回填查无此人、本地不复现 CI 必现 | 路径归一只认一把尺；剥 verbatim 前缀；三轮理论不破即转示踪 |
| 批量替换静默吞 | 替换"成功"但 0 处生效 | 替换正则显式容行尾（`\r?$`）；**替换后断言命中数**（0 命中 = 失败） |
| shell/命令语法坑 | 命令只回显不执行、参数没生效 | 命令片段不裸放（引号转义）；参数写全称禁缩写；命令文本进文档前先实跑一次 |
| 解包不全 | 解压"成功"但内容只剩开头 | 解到流尾 + 尺寸/清单校验，校验不过不算交付 |
| 豁免表滥用 | 扫描命中后先加豁免让红变绿 | 命中先改表述/素材出库；豁免仅限真实字符串且计数公开 |
| 管道截断假绿 | 验证"通过"但实际失败 | 输出落文件再判，成败基于落盘输出文件 |
