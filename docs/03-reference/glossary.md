# Apeireth Glossary — 术语表

> 面向读者：新开发者/使用者。从归档 22 词条提炼 + 1.0 新术语（2026-08-18）。

## 品牌与哲学

| 术语 | 含义 |
|---|---|
| **Apeireth / 阿佩瑞斯** | 源自 Apeiron（ἄπειρον，"无定形/无限"）——火栖居的地方。品牌宣言见 [brand.md](../01-architecture/brand.md) |
| **Apeiron** | 古希腊第一本原：无限、无名、未分化的沉默；"没有"都还没有的状态 |
| **Entelecheia** | 亚里士多德：潜能成为现实——不是被制造，是"成为" |
| **Fable / Mythos** | 火睁眼看见的寓言 / 火闭眼看见的神话（生态命名）|
| **0 装 PASS（不假装）** | 未实现就标注，未测试就标明，错误诚实可行动——信任的地基 |
| **涌现优先于预定义** | 能力自己长，我们准备土壤 |

## 架构

| 术语 | 含义 |
|---|---|
| **基地（Base）** | LLM 的操作系统——器官/工具/记忆/安全/协议；模型是租客不是建筑 |
| **双洋葱（Double Onion）** | 原则洋葱（E/S/A/M/O）嵌入权限洋葱（L0-L5）；L0 人类批准永不可变 |
| **L0/L1 常驻** | 注入管线核心块：Identity 人格 + Essential Story，永不截断 |
| **器官（Organ）** | 记忆/意识/认知/感知/情绪/价值等——每个是真实 Rust crate + trait |
| **三层生态** | 模块（官方核心）/ 套件（官方积木）/ 插件（社区热插拔）|

## 记忆

| 术语 | 含义 |
|---|---|
| **记忆 v2** | importance 打分 + Mem0 式对账（ADD/UPDATE/DELETE+tomb）+ 排名注入 |
| **记忆图（memory_graph）** | 双时态事实图（valid_at/invalid_at）+ 带权链接 + crawl 检索 |
| **版本链** | 记忆变更 = 新 id + 同 chain + rev 单调递增（append-only）|
| **做梦（Dream）** | 夜间记忆整合（Cognitive-Dream 6 状态机）|
| **滚动摘要** | 长对话自动压缩成摘要链 |
| **连续性（continuity_id）** | 跨前端同一叙事线 |
| **渐进式披露** | 记忆目录（~800 token）常驻 + 按需展开 |

## 她本身（机制）

| 术语 | 含义 |
|---|---|
| **世界模型 W1/W2/W3** | 文本反事实推演（Brier 校准）/ 因果图 MCTS / 记忆时间线挖因果边 |
| **好奇心（E4）** | 记忆回声偏置采样 + 浅尝辄止 + 疑问路由 |
| **假设检验（F4）** | HypothesisStore 状态机 + 证据加权 + 对账写回因果图 |
| **情感记忆（F1）** | 主人的情绪时间线（valence/arousal + 趋势 + 按情绪检索）|
| **价值内化（F6）** | 案例库 + 裁决记录 + 反馈回流 → 原则候选 |
| **涌现循环（E7）** | 节律学习 + 关系压力 + 门控——"什么时候开口"从你的回应学 |
| **oracle / Brier** | 可证伪预测 + 校准评分；意外度高 = 世界没被理解 = 好奇信号 |
| **W6 自我诊断** | 对"是否猜对主人意图"做 Brier 评分 |

## 工具与安全

| 术语 | 含义 |
|---|---|
| **工具管线** | 注册 → 审批（5 规则）→ 执行（schema+guardrail）→ 记录 |
| **guardrail** | 调用前拦路径穿越/命令注入；调用后凭据泄漏 tripwire |
| **ApprovalBridge** | companion ↔ orchestrator 审批双向同步（silent 透传）|
| **出站策略（S4）** | 白名单默认拒绝 + SHA-256 审计链 + 预算钩子 |
| **Job Object 沙箱** | Windows 进程级隔离（时间/内存/CPU 限额 + 超限留痕）|
| **HASH-SQL** | 不可篡改审计时间线（arbitration）|
| **宪法（Constitution）** | 结构化规则硬门 + LLM 评审（E 层判案）|
