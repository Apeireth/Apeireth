## 1. 一句话

桌宠是 **presence 的第四个投影（常驻面）**：应用可以关，他还在桌面上。形象层
**双形态可插拔**——默认「光态哨兵」，主题包可换形象层；姿态/光色全部由
`presence_state` 真实帧推导，主动涌现受防唠叨纪律硬约束。

## 2. 形象层决策（2026-10-11 主人拍板）

| 决策点 | 拍板 | 落法 |
|---|---|---|
| 形象路线 | **双形态可插拔**（不锁死路线） | 契约层写成形象抽象接口（`pet-contract.ts` 的 `PetFrame`），默认光态哨兵，主题包可换形象层 |
| 首批范围 | **一次做到主动涌现** | 常驻窗壳 + 姿态机 + 交互闭环 + 主动气泡/抬头一瞥，本批全含 |
| 形象默认位 | **首启可选、双形态并存**（2026-10-11 二次拍板） | 首启向导/设置选形象：光态哨兵（省电默认）或角色形象包；T0 老机器自动回落光态 |
| 角色形象来源 | **平台先行，形象用户自备（BYO）**（2026-10-11 三次拍板） | 平台不随包分发第三方形象资产；用户自带形象自担许可责任（条款免责）；测试用开源白名单形象（不进发布物，CI 门禁）；官方自制形象后补 |
| 许可口径 | **允许商用 + 署名类**（2026-10-11 二次拍板） | 白名单：公有领域等价 + 署名类（随包附署名）；非商用/禁改/禁二销/许可不明一律拒 |

- **光态哨兵**（默认）：光核 + 一弯弧身 + 一颗眼神光。"光不长脸"纪律的字面
  形态——他由光显影，不由皮肤显影；与既有余烬点/光晕/场景同一套存在色。
- **微光简模**（回落/T0 廉价档）：单点余烬 + 光晕，纯 CSS。同时是"形象抽象
  接口确实可插"的活证据：两个内置实现共吃一份 `PetFrame`。
- **主题包形象层**（插口预留）：主题包目录携带 `avatar-manifest.json`，经
  `parseThemePackManifest` 严格校验后与内置层同表注册——换形象不换契约。

## 3. 同类做法调研（中性转译，取做法不取名字）

| 维度 | 同类公开做法 | 我们的取舍 |
|---|---|---|
| 窗口形态 | 透明无边框悬浮窗、常驻桌面、可拖拽、可鼠标穿透 | ✅ 全取（Tauri 第二窗口，右下常驻位） |
| 形象层 | 分层 2D 角色形象（网格变形驱动表情/口型/动作） | ⚠️ 路线张力 → 双形态可插拔化解：默认光态，形象层可换 |
| 行为 | 自主小动作、睡眠模式、状态气泡外显"正在干什么" | ✅ 四姿态身姿 + 事件气泡（只述事实） |
| 交互 | 点击=快捷对话、右键=菜单、流式对话、语音 | ✅ 点击/右键/拖拽本批落；语音口型列后续批 |
| 主动性 | 主动关怀/主动消息、长期记忆、人格、日记 | ✅ 主动涌现本批落（限频限量）；记忆/人格走既有卷宗，不另起炉灶 |
| 工程性 | 极低开销、一键安装、插件化、跨平台 | ✅ 零 WebGL、CSS 合成器动画、失焦停表；便携安装列后续批 |

## 4. 契约与数据流

```
gateway 事件总线 (SSE)                     presence_state 帧 / 生命周期事件
      │                                            │
      ├─ presence.ts（显影分级 + SIM 纪律）        │
      │        │                                   │
      │        ▼                                   ▼
      │   pet-contract.ts（PetFrame 形象抽象契约）◄── proactive.ts（主动涌现引擎）
      │        │                                       │  通报限频/开口预算/抬头一瞥
      ▼        ▼                                       ▼
   PetWindowView.svelte ── AvatarHost（形象层插拔）── 气泡层（只述真实事实）
```

- **姿态机**：四姿态枚举直通（`deep_coding_focus → corner_quiet` 角落安静 /
  `attentive_presence → head_up` 抬头 / `dreaming_consolidation → curled_asleep`
  蜷睡 / `empathetic_care → leaning_close` 靠近），见 00-PHILOSOPHY §5。
- **光参数同源**：四姿态光参数表（基亮/呼吸振幅/色温）与后端
  `ember_hud_driver.rs::synthesize_uniforms` 逐值镜像——四个投影显影同一份状态。
- **互斥礼让**：主窗前台 → 桌宠隐身；主窗收起 → 桌宠接管（壳层纯决策
  `pet_leeway`，可单测）。
- **右键卷宗入口**：菜单 → 壳层命令 `open_main_target` → 主窗 `shell-target`
  事件 → `shell-nav.ts` 目标表改道（与命令面板/旧深链同一张表，不另开口径）。

## 5. 防唠叨纪律（数值即契约）

| 参数 | 值 | 依据 |
|---|---|---|
| 抬头一瞥门槛 | 待签 90s | 待签久候用眼神提醒，不弹通知 |
| 抬头瞬时 / 重复间隔 | 2.5s / 5min | 抬头也是话语，限量 |
| 他开口每日预算 | ≤3 次/天 | 与后端 presence 预算器同数，超支一个字不说 |
| 通报限频 / 同文去重 | 45s / 120s | 审批连环来也不连环响 |
| 气泡上限 / 驻留 | 2 个 / 通报 6s·开口 12s | 话越少，每句越重 |
| 回合结束 / 后端就绪 | 不出气泡 | 低价值事件不配拥有台词 |

## 6. 诚实边界（0 装）

- `initiative`（他主动开口）是契约空间：帧解析与预算器已就位，**后端 v0 无
  生产者**——当前他不开口，接线一行即可点亮，不谎报现役能力。
- `empathetic_care` / `ritual` 姿态与显影档同样暂无生产者（契约空间保留）。
- 主题包形象层：清单校验与注册口已实装；动态装载点在 `AvatarHost`（本地主题
  包目录），首批未接主题包市场/远程装载。
- 断连 >30s 桌宠外显 `SIM` 等宽小字（本机中性回落，不编造情绪）。
