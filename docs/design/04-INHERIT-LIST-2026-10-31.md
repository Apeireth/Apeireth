> **纪律**：旧范式只作**素材库**，不追溯改写；本清单只提炼**可复用的设计手法/机制**，不搬运旧范式的具象视觉元素。
> **判据**：一条东西能不能进来，看它是否服务"工作空间让人完成事情 / 控制塔让人理解系统"，以及是否会给施工方造成"要复刻旧画面"的误解。

## §1 值得汲取（技术/机制层，按优先级）

| # | 可汲取的东西（旧范式出处） | 怎么用在新范式 | 不汲取什么 |
|---|---|---|---|
| 1 | **显影式状态表达**（00-PHILOSOPHY §2 / 01-DESIGN-SYSTEM §1：状态以呼吸/光强/渐显呈现，而非弹窗） | 工作画布的 AI 运行/保存/冲突状态用"渐显/弱化"表达；控制塔状态变化用光强与脉冲；**禁止再用无源动画** | 不继承"他"的情感叙事（那个中心已废弃） |
| 2 | **存在色梯度**（01-DESIGN-SYSTEM §2.1：whiteHot→gold→amber 三段金梯度） | 系统信号色的**三段梯度**（活跃/警示/静默三档），用于基地/遥测/告警；验收看对比度与唯一饱和色纪律 | 不继承"金=他"的专属语义 |
| 3 | **深色底 + 哑白实体卡**（§2.2/§2.3：近黑底 + 哑白面板比纯黑卡片更"实体"） | 控制塔暗色面板与工作空间亮色卡片的分层；哑白卡片可用于文档/审批等实体内容 | 不继承黑洞/深空底色的具体色值 |
| 4 | **时间线照明：双驱动 + 四时刻档位 + 长过渡**（§3：环境随本地时间 + 状态缓慢变化，过渡 ≥60s） | **环境层状态机**：环境随本地时间（昼/夜）与系统活动缓慢变化；过渡 >60s，不可指认 | 不继承"舰桥/星体"叙事与具体档位色温 |
| 5 | **机位系统**（§4.3：远眺/临渊/俯瞰 + 键盘 1/2/3 + 2.6s 过渡） | **控制塔全息基地的三预设视角**：全景/分区/节点，键盘切换，过渡 2.6s；用户可接管 | 不继承黑洞机位与具体参数 |
| 6 | **轨道式鼠标视差**（§4.4：鼠标只改视角、主体不动） | 控制塔基地的**微视差**（幅度小、可关，主体不动）；reduced-motion 关闭 | 不继承星野/场景视差资产 |
| 7 | **层深与性能梯队**（§4.5 三层视差 / §7.2 t0–t3 渲染梯队） | 基地层深（远/中/近）+ 降级梯队；**每档保持状态驱动**（降级降成本不降真实性） | 不继承星空资产与 shader 参数 |
| 8 | **排版：衬线体"被说出来"的节奏**（§6.1：大行高 2.1 / 字距 0.13em / 引语行宽） | 编辑终端/长文阅读面用衬线 + 大行高；文档画布的"引用/摘录"块 | 不继承"他的声音"语义与字号硬值 |
| 9 | **动效时间尺度分级**（§7.1：界面动作秒级、环境照明分钟级、机位 2.6s、状态趋近指数平滑） | 动效 token 分三级：**交互 120–300ms / 转场 0.6–2.6s / 环境 ≥60s**；禁止所有东西一个时长 | 不继承 2.8s 呼吸光环（那是 presence 专属） |
| 10 | **反白仪式色**（§2.5：全屏白底 + 黑图章，仅仪式时刻） | **审批/授权的"待签文书"**可用反白/高对比一刻（金色闸门开 + 文书浮起）；日常禁止大面积白底 | 不继承全屏过场与旧图章样式 |
| 11 | **"判断即仪式"**（00-PHILOSOPHY §6 原则 4：审批 = 停下来等你签字，浮起/被等待/可超时/可打断） | 审批交互：金边待签卡、可超时提醒、可 barge in；**每次介入有重量** | 不继承舰桥审批柜台形态 |
| 12 | **"一个入口"**（00-PHILOSOPHY §6 原则 3：Ctrl+K 是唯一需记忆的导航） | 全局命令面 + 快捷键；其余靠空间与召唤，不养"记地图"的侧栏 | — |
| 13 | **"空态即契约"**（00-PHILOSOPHY §6 原则 5） | 已继承：空态写数据契约，不写"暂无数据" | — |
| 14 | **"界面自己记得"**（00-PHILOSOPHY §6 原则 6：照明时间线/上次机位/未读审批在环境中有位置） | 状态记忆：上次视图/上次机位/未读标记保留；不要求用户重新找 | 不继承"环境光里放审批"的具象手法 |
| 15 | **骨骼长寿、华服可换**（00-PHILOSOPHY §2 / §5：契约薄且稳定，表现层可替换；PetFrame 抽象） | **基地形象层可替换**（语义槽固定，换壳只换造型）；后续新形象只换华服 | 不继承桌宠/形象层本身（另立项） |
| 16 | **性能梯队"只减排场不减功能"**（00-PHILOSOPHY §2/§8：T0–T2 每档功能不减） | 已继承：全息基地降级时保留状态色/选中/检查器；工作空间低配也完整可用 | — |
| 17 | **蒙太奇片头**（01-DESIGN-SYSTEM §9：首启品牌叙事） | 首启/空态可作为环境层的品牌叙事展示；**不常驻**，不抢工作画布 | 不继承具体镜头语言与素材 |
| 18 | **"电影感优先于信息密度"**（§1：任何一帧截图能当电影静帧看） | 只用于**控制塔与环境层**的构图纪律（景别/光影/留白）；工作空间以效率优先 | 不把它当全局准则（工作画布需要密度） |

## §2 明确不汲取（避免误解）

| 旧范式元素 | 处置 |
|---|---|
| "他"作为中央 AI / 情感中心 / 存在金专属 | 已废弃（P4：agent 是单位） |
| 星球 / 桥 / 深舱 / 星野 / 黑洞 / 舰桥场景 | 旧范式具象视觉元素，**不进入新范式** |
| 三调性全局开关 / 调性即会话属性 | 已被 per-agent 能力开关取代 |
| 桌宠/常驻形象 | 另立项；只保留"形象层可替换"的结构思路 |
| presence PAD / 四姿态 / 呼吸光环 | 情感叙事废弃；状态驱动保留为"系统状态"（非人格） |
| T0/T1/T2 沉浸梯队命名与阈值 | 只继承"分层降级、状态驱动"原则，不继承命名与参数 |

## §3 建议的采纳顺序（首轮/后续）

1. **首轮（K3.1）**：#2 信号色梯度、#3 暗/亮分层、#5 基地三视角、#7 层深与降级、#9 动效时间尺度、#11 判断即仪式、#13 空态契约；
2. **第二轮**：#1 显影式状态、#4 环境时间线、#6 微视差、#10 反白仪式、#14 状态记忆、#17 首启叙事、#18 构图纪律；
3. **不进首轮**：#8 衬线排版（等文档画布深化）、#15 换壳演示（D6 鼓励）、#16 性能梯队（引擎实现阶段）。

## §4 诚实边界

- 本清单为**手法提炼**，不复制旧范式文字/素材；旧范式文档保持原样（历史不追溯改写）。
- 旧范式里大量状态标注为 🟡/🔵 的部分是提案或远景，未实测；本清单只取"原则/机制"，不继承未验证的声称。
- 采纳与否由 owner 拍板；首轮范围以提示词 v2.2 为准。
