## 一、Auroraqua-UI 的礼物：**材质语言（Material）**

「冰态果冻」美学的可吸收要素（React/Tailwind 实现，MPL-2.0——**同 GPL 红线：设计语言可学、代码不碰**）：

| 要素 | 描述 | 落进 Apeireth 的形态 |
|---|---|---|
| 边角高光 | 卡片边缘一线高光（玻璃的"厚度感"） | 卡片/面板 `::after` 高光线（CSS 即可） |
| 玻璃模糊层 | 重阴影模糊+半透明叠层 | `backdrop-filter` 玻璃卡片（侧栏/弹层/浮窗） |
| 浮动组件 | 组件悬浮于层叠空间之上 | 弹层/命令面板/快捷助手的浮起层次强化 |
| 流动光效 | 光在材质里流动的活感 | 与 Ember 呼吸光合流（光域的"材质化"） |
| 多层堆叠深度 | 重阴影造空间纵深 | 面板层级阴影体系（三档阴影 token） |

## 二、搜索的礼物：**情绪自适应（Mood-Adaptive）**

玻璃拟态生态成熟（玻璃主题族、动态背景、响应式全标配）。其中**情绪自适应 UI** 概念与我们的 PAD 情绪光域天然咬合：

> **界面材质/色温随伙伴心境微动**——愉悦时玻璃透亮、沉静时色调收敛。开关可选，默认细微不打扰。
> （合规要点：这是"模拟读数的外化"，不宣称情感——与关系界面"两层光永不合成一颗心"同一宪法。）

## 三、设计体系四维架构（正交可叠加）

| 维度 | 取值 | 状态 |
|---|---|---|
| **主题**（配色氛围） | 雅致（默认）/ 深空（科幻） | 深空档在建 |
| **材质**（表面质感） | 纸面（默认）/ 果冻玻璃（边角高光+玻璃模糊+浮动层） | 本批吸收 |
| **分区**（调性治理） | 聊天=温度 / 工作台=SaaS 清晰 | 设计稿在写 |
| **响应式**（红线） | 900-3840px 全优雅 + 终端自适应 | 立为红线 |
| （第五候选）情绪自适应 | 色温随模拟心境微动（开关） | 愿景项 |

**原则**：四维正交——主题管色、材质管质、分区管调、响应式管尺寸；任意组合不打架，品牌锚（暖金/骨白/呼吸光/纸面恒纸面）永不让位。
