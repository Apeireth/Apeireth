## 1. 要什么

一个**官方角色形象**（"他"的默认华服）：开放 3D 人形格式、卡通渲染友好、
能被桌宠窗的契约直接驱动（姿态/呼吸/口型/眨眼/视线）。

## 2. 交付物清单

| 交付 | 要求 |
|---|---|
| 形象文件 | 开放 3D 人形格式（`.vrm`），≤64MB，标准人形骨架 |
| 源工程文件 | 分层/建模源文件一并交稿（后续改编、换装、减面都靠它） |
| 表情与口型 | 标准表情集 + 口型五档（闭/小/中/大/圆），眨眼可驱动 |
| 视线 | 眼部支持视线驱动（骨骼或参数任一，能被契约映射即可） |
| 四姿态适配 | 角落安静（收拢垂头）/ 抬头 / 蜷睡 / 靠近（前倾）能被骨骼变换表达 |
| 署名文案 | 一段随包展示与 NOTICE 入账用的署名文本 |

## 3. 许可与合同要点（红线，逐条进合同）

1. **交稿许可**：CC0 或 CC-BY-4.0 二选一（后者署名文案随稿）；
2. **改编权**：允许裁切/减面/重映射姿态参数/换色温光效；
3. **再分发权**：允许随产品分发（含安装包与更新）；
4. **链条干净**：成品内**不得嵌入任何第三方资产**（贴图/模型/骨骼全自制或
   授权链条可举证）；如用第三方工具生成，须确认工具产出物权属归委托方；
5. **排他性**：不买断画师的风格与技法，买断的是**这一形象的上述四项授权**；
   可约定"同款不再售予直接竞品"的软条款（价格另议）。
