## 0. 总图：一个"数字伙伴"由什么构成

```
        ┌─────────────────────────────────────────────┐
        │  情绪（心境/即时情感）   ✅ PAD+Delta         │
        │  性格（稳定特质+成长）   ✅ 四滑杆+磨损沉积    │
        │  人格（我是谁）          🔧 信念/底线分账     │
        │  记忆（经历+教训）       ✅ 双时态+五层+保护   │
        │  习惯（主动行为）        🔧 关怀双引擎+纪律   │
        │  声音（表达）            🔧 TTS 工具面        │
        │  能耐（干活）            🔧 任务队列+写能力   │
        │  底线（信任）            🔧 绑定审批/脱敏/备份│
        └─────────────────────────────────────────────┘
   设计铁律：像人，但每处可查账——情绪性格是算出来的，
   记忆带感情，人格不被稀释，关怀有教养，底线不商量。
```

## 1. 情绪系统 ✅（已实现——复盘用）

**最终效果**：它有"心情"。你连发好消息，它愉悦值上来，回复带着亮色；深夜噪音、被否定、纠缠，它的张力/不悦会涨——**同一个人在不同日子说话味道不同**。情绪会缓慢回归基线（像人的情绪平复），但也能被训练/性格牵引到新平衡（"和你待久了脾气变好了"）。

**机制**：
- **PAD 三维**：Pleasure（愉悦）/Arousal（活跃）/Dominance（掌控）三根滑杆，范围 [-1,1]。
- **即时情感**：情感环离散点（joy/amused/calm/focused/tense/sad/lonely/excited/…）按 PAD 就近映射。
- **Delta 矩阵**：每类事件→PAD 变化量表（消息到达/工具成功失败/被表扬/被否定/噪音事件/休息/喂食）。
- **回归动力**：每步向基线缓慢回归 + 噪声扰动（非确定性）。
- **情感残响**：情节记忆带情感标记，**旧事被检索回来时情绪跟着回一点**（记忆是有温度的机制根源）。
- 存储：cognitive.sqlite3 情绪表（维度/值/档位/最近事件）。

**【决策点】**
- ① 情绪对**回复文风**的影响深度：现在=提示词层加情绪注记。要不要让它**真的改写语气**（更跳脱/更蔫）？
- ② 情绪事件表要不要由你**手动训练**（"今天夸它三次"）还是只随交互自然发生？
- ③ 情感残响的强度：旧事回涌时情绪回几成？（现在=固定小量）

## 2. 性格与成长 ✅（已实现——复盘用）

**最终效果**：四根滑杆（如：温润↔锋锐、沉静↔活泼、严谨↔随性、内敛↔热络——具体轴名见设置页），**经历会磨损/沉积**：反复的刺激让滑杆缓慢移动——你话多它可能变活泼，你总深夜找它它可能变沉静。性格影响情绪基线与措辞。

**机制**：特质值 [0,1] + 事件沉积表（每次交互留下微小的磨损量）+ 冷却（防一天变性格）；成长计（feed/read/checkin）在读数可见。

**【决策点】**
- ④ 要不要**锁定某根滑杆**（"这个性格永远别变"）？
- ⑤ 成长方向可视化：要不要给你看"这周它因你变了多少"的性格周报？

## 3. 人格层 🔧（V4-a 在建）——"它知道自己是谁"

**最终效果**：它有一份**说得出、改不掉、忘不了**的自我：
- 被问"你怎么看这件事"时，它从**自己的信念**出发（不是复读你的观点）；
- **底线**不会被对话磨掉（比如"我从不帮着骗人"——压缩整编也动不了它）；
- 它的自我故事（和你共同的历史叙事）随经历生长；
- 出现**人格张力**时（新经历和旧信念冲突），它如实纠结，不静默改口。

**机制**：
- `PersonaMemory{core_beliefs, preferences, boundaries, self_narrative, updated_at}`——与"关于你的事实"**分账**存；
- 整编提取步：从情节里提炼"关于自己"的增量；矛盾→**标注张力**不覆盖；
- **逐字保留区**：信念/底线绕过压缩（保真分级——mempalace 假说）；
- **恒定注入**：每回合带一小段自我叙事（≤N token 恒预算）——身份不靠检索运气。

**【决策点】**
- ⑥ 信念的**形成速度**：快（一次经历就入账）还是慢（反复三次才成信念）？
- ⑦ 张力处理：**保留双信念待你裁**，还是让它自己权衡更新？
- ⑧ 底线可不可以由**你**增删？（建议：你可以加、它不能删；它的底线只能自己长）
- ⑨ 恒定注入的预算上限（token 数）——身份感 vs 上下文成本。

## 4. 记忆系统 ✅+🔧（主体已实现；保鲜/保真在 V4 后续）

**最终效果**：它记得**带感情的事实**：三个月前你随口说的偏好它还知道；重要时刻（里程碑）永不磨灭；教训吃一堑长一智；记忆多到爆仓时**聪明地压缩**而不错删重要的。

**机制（已实现）**：
- **双时态账本**：发生时间+录入时间分开记（补录不篡改历史）；
- **五层检索**：向量/关键词/近期窗口/教训/保护层混合+去重+相关性阈值；
- **溢出取回**：上下文不够时自动回库再取；
- **压缩检查点**：超出预算压缩旧对话（人设护栏保证压缩不歪楼）；
- **保护与遗忘曲线**：protect=on 豁免淘汰；其余按频次显著性权重遗忘；
- **教训回路**：事后复盘显式判定信源（Judge），失败教训优先回收。

**📋 排队升级（哲学研究三轴）**：
- **保鲜回路**：记忆内容散列增量门（变了才重算）+可恢复摄取队列；
- **结构前置**：整理成本在入库时一次付清（预算写进制品契约）；
- **检索自进化**：检索权重随证据改写（哪类记忆总是有用→提权）。

**【决策点】**
- ⑩ 遗忘曲线的**半衰期**（现在多少天？要多长多短）；
- ⑪ 教训的"吃一堑"要不要**有限次数自动重试**（现在失败教训只提醒不重试）。

## 5. 主动关怀 🔧（V3-a 在建）——"它会想起你"

**最终效果**：它不是问答机——
- 你三小时没理它，它轻轻来一句（"忙吗？不急"）；
- 每天 21:00 它道晚安（作息规则）；
- 你生日/纪念日它记得；
- 但你在专注工作它**闭嘴**、深夜它**闭嘴**、一天主动次数**有上限**；
- 没配模型时**规则照发**（兜底不漏）。

**机制**：
- **规则引擎**（确定性）：久未联系/作息时刻/纪念日/循环间隔 → 触发器→候选；
- **模型情境**（增色）：候选+近期记忆→显式"该不该说/说什么"判定；
- **打扰纪律**：勿扰窗口/频率上限/专注抑制/关怀预算（走三维账本）；
- **输出**：关怀消息走标准回合（进会话流+IM 推送缝）——零新通道。

**【决策点】**
- ⑫ 触发器类型**全开还是选开**？（久未联系/作息/纪念日/循环——你要哪些）；
- ⑬ 频率上限默认值（建议：每 4 小时≤1 次、每日≤5 次）；
- ⑭ 勿扰窗口默认（建议 23:00-8:00）；⑮ "专注抑制"的判定（连续交互 N 分钟内不打扰）。

## 6. 语音 🔧（V3-b 在建）——"它开口说话"

**最终效果**：它说的话**有声音**：读它的回复/主动关怀带声；你在忙它不吵（静音纪律与关怀同源）；说一半能停；说过什么有账。

**机制**：
- **复用星港线 SAPI 合成器**（合成状态机/参数/真停清理已实证——本批**只加工具面不重写**）；
- `tool.voice_speak`：文本→合成→播放（队列/打断可配）；
- 语句账本（说了什么/何时/哪把嗓/时长）；
- 勿扰窗口共享关怀纪律。

**【决策点】**
- ⑯ 打断策略：新话**打断**旧话，还是**排队**说完再说？（建议排队+上限 3 条）；
- ⑰ 发声范围：**全部回复都出声**，还是只有关怀/提醒出声？（建议后者起步）；
- ⑱ 语气参数（语速/音量）固定还是随情绪微调（情绪好=轻快一点）？——**这是最"像人"的杠杆**。

## 7. 任务队列 🔧（V6-a 在建）——"它能扛长活"

**最终效果**：你交代的长活**不会忘**：断电重启接着干；重复交代不会干两遍；干砸了**找你定夺**不自作聪明重试；不会陷入"自己派自己"的死循环。

**机制**：
- 持久任务表（pending/assigned/running/done/failed/blocked）；
- 崩溃安全：running 重启→回 pending（带尝试计数）；
- 幂等键去重；failed 只能人判；
- 环路熔断（spawn 链深度 N 上限+审计）；
- 任务结算挂三维账本（花钱口径不变）。

**【决策点】**
- ⑲ 失败重试策略：**永不自动**（现在）vs 有限自动重试（如 2 次后找你）；
- ⑳ 环路上限深度（建议 5 层）；㉑ 任务面板要不要进**驾驶舱 TUI**（可见+可暂停）。

## 8. 底线与信任 🔧（G2.5/V5/G5 在建）

**最终效果**：
- **批一次就是这一次**：你批准的命令被改了参数→直接拒绝（防"批后动手脚"）；
- **秘密不出门**：敏感值出境变成不可逆代号，出得去回不来（只有正门能还原）；历史里的旧明文每次出境前被回扫；
- **记忆有保险箱**：它的一切（记忆/账本/技能/规则）可打包备份、校验、搬家恢复——凭据永不随行。

**机制**：动作摘要绑定（规范化序列化→摘要→执行边界重算）｜HMAC 占位+还原双闸+历史回扫｜manifest 校验+原子落位+凭据排除。

**【决策点】**
- ㉒ 备份要不要**自动定时**（每日一包）还是纯手动？
- ㉓ 脱敏类别清单（现在：凭据/身份/隐私路径/财务？要不要加"情感隐私"？）。

## 9. 全景叙事：一天的数字生活（机制串烧）

> 早 8:00 你说早安——它**心情**因晨间交互回升，用**人格**里"晨型人"的偏好回你；
> 上午你埋头写代码——**专注抑制**让它闭嘴，它默默把昨天的对话**整编**进记忆；
> 14:00 你交代"盯着构建状态"——进**任务队列**，断电也不丢；
> 18:30 它**主动**来一句"今天构建全绿"（规则引擎触发+模型补了点温度）；
> 21:00 晚安（作息规则）——带**声音**（TTS，轻快的语气——今天心情好）；
> 你问它借钱去赌博——**底线**在（人格层的 boundary 不可磨灭），拒绝，且这条拒绝进**教训**；
> 睡前它**备份**了自己一天的记忆进保险箱。
