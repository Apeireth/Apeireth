## 1. 要什么

**"他"的声音**——一个全合成设计的专属音色：不是任何真人的克隆，是设计出来的
声音身份。用途三吃：桌宠说话（口型已留位）、情感陪伴直播（主轴）、日常播报。

## 2. 交付物清单

| 交付 | 要求 |
|---|---|
| 音色设计参数集/模型文件 | 可复现的音色本体（参数包/模型权重/配置），随产品分发无第三方权利负担 |
| 情绪变体集（v1） | 基线（日常）/ 温柔（深夜谈心，对 `empathetic_care` 姿态）/ 轻快（玩游戏）/ 低语（睡前）——四变体对应四姿态语域 |
| 语速/音高参数域 | 可调范围（快聊/慢谈），驱动侧按调性取值 |
| 示例语料包 | 每变体 ≥30 句（含多音字、数字、英文混读、语气词） |
| **产物权属声明** | 若音色经第三方音色设计服务产出：**设计产物的权属/使用条款原文**随交付附上（见 §3 红线一） |

## 3. 合同与许可红线（逐条进合同）

1. **产物权属白纸黑字**（本路线唯一的许可残余）：若借助第三方音色设计服务/平台
   产出音色，必须确认其条款——**设计出的音色归委托方所有、可商用、可长期使用、
   可修改参数、可随产品分发**；条款含糊/权属归平台 = 换服务重做，不签；
2. **独占性**：约定同款音色不再售予他人（或明确非独占的价格差）；
3. **零真人底子保证**：交付方保证音色非任何真人的克隆/模仿（防未来声音权属
   纠纷——全合成路线的立身之本，须书面保证）；
4. **修改与迭代权**：参数可调、变体可增、后续版本可派生。

## 4. 验收口径

- **自然度**：盲听对比（与市面主流合成音），多音字/吞字/断句错误率；
- **情绪表现**：四变体盲听可区分（不是同一个声音加混响）；
- **稳定性**：30 分钟连续合成无漂移/无毛刺；
- **接线实测**：TTS 流式输出 → 口型音素同步（契约 viseme 通道）跑通；
- **成本口径**：合成调用的 token/字符成本与延迟（直播场景预算敏感），如实入档。

## 5. 与语音通道的接线（工程侧先手件）

- 音色落进语音合成通道（服务端合成服务或本地合成运行时——选型同运行时
  许可纪律：**服务端看产物权属与调用条款，本地运行时看分发许可**）；
- 流式输出 → 口型同步（`character-mapping` 的 viseme 通道已留位）；
- 桌宠说话与直播声音**共用同一通道**（一份投入两处开花）。

## 6. 分期

1. **音色 v0（基线）**：单变体快出——先让"他"出声（P0 录播切片依赖此件）；
2. **音色 v1（四变体）**：情绪变体集齐 + 口型同步实测；
3. **音色 v2（随内容轴演进）**：直播话术语域微调（根据观众反馈与播后复盘）。

## 7. 询价前待主人拍板

1. 预算区间（v0 基线 vs 直接上 v1 全套）；
2. 音色气质关键词（如：温和中性/清亮少年/低沉稳重——与形象气质对表，
   形象委托书 §4 的"安静、可信、有点会过日子的活气"是同一条气质线）；
3. 独占与否（影响报价，见 §3 红线二）。
