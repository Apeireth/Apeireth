## 2. 共同语法（7 条，可直接落成设计规则）

### 2.1 近单色底 + 唯一饱和信号色

- 暗组：黑/深蓝底 + 白/灰字 + **一个**橙/青信号色（智能体编队、发射中心、全球运营）。
- 亮组：纸白/米白底 + 黑线稿 + **一个**红/橙信号色（工程示意、运维台）。
- 结论：全界面只保留**一个饱和色**承担状态语义 ⇒ 我们的「金色 = 系统信号/能量」天然成立。

### 2.2 微型等宽标签系统

- 10–11px 大写字母、字距拉开、中英并置、编号分节（`SEQ 阶段事件日志` / `CORE VITALS` / `TELEMETRY LINK` / `01 / 02 / 03`）。
- 这是"精密感"的**第一来源**，优先级高于阴影/渐变。

### 2.3 发丝网格面板，不是卡片堆

- 1px 细线、方角或 2px 小圆角、分栏与分隔线、紧凑内边距；没有"大圆角卡片 + 大留白"。
- 这正是「劣质卡网」反范式的正面对照。

### 2.4 中央空间面 + 四周数据面

- 全球运营=3D 地球；智能体编队=粒子 agent 图；发射中心=相机画面；爆炸图=芯片爆炸图；知识星图=3D 星图。
- ⇒ 我们「系统中枢」的中央面 = **agent 编队/系统图**，四周是遥测、事件、检查器。

### 2.5 右侧固定检查器 + 关注/聚焦

- 智能体编队点选 agent → 右侧详情（此刻 / 状态画法 / 手上 / 排队 / 利用率 / 状态程序 / 状态条 / 动作按钮）。
- ⇒ 直接对应我们的「特别关注」：pin（视觉高亮）+ 指挥授权（leader）的界面母型。

### 2.6 时间维是一等公民

- 阶段流水线（规划→检索→编码→审查→交付）、事件日志（当前行高亮）、回放倍速（0.25×–16×）、里程碑时间轴、暂停/跳转。
- ⇒ 工作流必须能**回看 / 暂停 / 跳转 / 追责**。

### 2.7 动态全部是诊断性的（"游戏级反馈"的正确形态）

- 脉冲节点、流动连线、进度条、扫描/解码字效（`NO_SIGNAL` / `AWAITING_MEDIA` / `DECODING_SIGNAL 000%`）、`实时接入`绿点、状态程序（`PLAN → SYNC`）。
- 每个动效都能回答"系统现在在干什么"——这正是「游戏级反馈」在业务界面里的合法落法（视觉层，不做游戏机制）。

## 3. 明暗观察：不是反相皮肤，是两种气质

| | 暗组 | 亮组 |
|---|---|---|
| 代表 | 发射中心 / 智能体编队 / 全球运营 / 爆炸图 / 知识星图 | 工程示意 / 运维台 / 建模任务台 |
| 气质 | **值班指挥**：黑/深蓝、发光量感、实时遥测 | **图纸工作台**：纸白/米白、黑线稿、工程标注 |
| 适用 | "正在发生" | "审视 / 规划 / 复盘" |
| 材质语法 | 石墨 + 玻璃 + 微光 + 发丝线 | 纸 + 墨线 + 网格 + 少量实色块 |

⇒ 支撑我们的「明暗全双模式」裁决：**同一套语法换材质**；明色要有纸/线稿的高级感，不是"白底 SaaS 糊弄版"。

## 4. 3D 立体感：分层判断（推断口径）

> 判断依据 = 截图画面特征 + 页面交互提示（拖拽旋转 / 相机切换 / 剖面 / 回放）；**未逐站验证实现技术**。

| 类别 | 参考 | 立体感来源 |
|---|---|---|
| **真 3D 交互场景** | 全球运营（地球）、爆炸图、工程示意、双机械臂、知识星图 | 真 3D 模型/场景 + 相机交互 |
| **伪 3D / 粒子 / 线框** | 智能体编队（点云/线框"球"）、品牌概念页（线框模型） | 点云/线框 + 大小/透明度/模糊造深度 |
| **预渲染 / 视频** | 发射中心中央相机、月光钢琴、建模任务台输出 | 画面是 3D 渲染结果，页面本身 2D |
| **纯 2D** | 运维台、绝大多数图表、建模任务台 UI 壳 | CSS / SVG |

**结论**：
1. "3D 立体感" ≈ **一个中央面是真 3D 或高仿 3D + 其余 2D 精密面板**；不是全局 3D UI。
2. 业务界面**不需要 3D 引擎**：CSS/2.5D（深度阴影 / 玻璃 / 视差 / 模糊）+ 一个中央空间面就够。
3. 中央面先用 **2.5D（Canvas 点云/连线/景深）** 起步，W1 中期用同屏对照评估是否升级轻量 WebGL；真 3D 场景留 3D 立项。

## 5. 取 / 不取

**取（语言与制度）**

- 近单色 + 单信号色的色彩纪律；微型等宽标签；发丝网格；中央空间面；右侧检查器；时间维（日志/回放）；诊断性动效；明暗两种气质。
- 交互提示的写法（"点击下钻 / 拖拽旋转 / 点击聚焦 / H 隐藏 HUD"）——**可发现性**本身是设计资产。

**不取（明确禁止）**

- 任何素材、品牌、字体授权未清的资产；单页营销构图；营销叙事文案。
- "大圆角卡片堆 + 大留白"的卡网形态；无源装饰动效；把参考页的"概念站"当产品 IA。

## 6. 落地结论（指向范式文档）

1. 三副面孔（按「任务阶段 × 密度」）：**指挥仪表盘 / 技术图纸 / 编辑终端**；共享一套令牌与网格，明暗全双模式——见 [02-PARADIGM.md](02-PARADIGM.md) §4。
2. 中央空间面 = agent 编队/系统图；2.5D 起步，W1 中期评估。
3. 金色 = 系统信号/能量（全界面唯一饱和色纪律）。
4. 反范式清单入库：劣质卡网 / 纯装饰科幻 / 低密度大留白 / "他"中心显影 / 静态仪表盘。
