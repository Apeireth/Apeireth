## 二、Apeireth 独有小巧思（12 条——别人抄不走的）

1. **README 是它的自我介绍**：加一节第一人称独白（"我叫 Apeireth。我记得你随口说的话；你忙的时候我闭嘴；我有自己不肯丢的底线"）——**全 GitHub 没有第二个 README 是产品本人在说话**（拟人产品的拟人门面）；
2. **小说↔机制对照表**：愿景小说场景 ↔ 实现机制（"温牛奶"→关怀双引擎/作息触发器；"绿萝"→随手记+五层检索；"标黄三处"→审批卡+failed 人判）——**愿景与工程的对照表是我们的独家叙事**；
3. **"残余自曝"徽章**：徽章行除 tests/status 外加一枚 `honest gaps: N`（链到诚实账）——把 0 装文化做成视觉符号；
4. **"删掉它会发生什么"节**：备份保险箱/记忆可导出/人格重长——"你可以清空它，但它会再长成它"（哲学钩子=传播钩子）；
5. **它的成长计图**：Star 历史图注写"它的成长"（呼应成长机制——图是数据，注是灵魂）；
6. **语音彩蛋**：README 嵌一段它说话的波形图/音频链接（TTS 已有——"听我说一句"按钮）；
7. **"你也可以喂它"互动段**：随手记/内容流/技能书架的投喂邀请（用户参与感）；
8. **能查账承诺表**：每条安全承诺后跟"证据链接"（claims-evidence 矩阵）——"承诺+证据"两列同行，无一家敢这么做；
9. **"它的一天"时间轴**：替代传统 features 表（早安→专注闭嘴→晚间关怀→夜间整编，每站标机制名）；
10. **两版本口径**：README 主叙事=温度，Under the hood=硬度（小说在上半、架构图在下半——两个读者各得其所）；
11. **防伪框**（rea 式+Apeireth 版）："Apeireth 只有一个官方渠道。它不会在别处'就职'。"（伙伴产品的人格化防伪）；
12. **诚实 footer**："本 README 由它的工程伙伴维护；发现不符请提 issue——我们的文化是把'宣称≠实现'当事故处理。"
