## 目标与范围

从上游主干当前版本逐条复核安全审计，在独立工作树交付可验证的后端防护。保留在途桌面的接口合同。桌面宿主、客户端存储及打包变更由前端施工线负责。

## 批次与验收

| 批次 | 范围 | 验收条件 |
|---|---|---|
| A | 出站与外部工具 | 统一可控地址判定、外部端点不能通过跳转扩大授权、本地外部工具进程按最小权限启动。 |
| B | 账户删除与记忆 | 遗忘失败或结果不完整时保留重试入口，删除结果如实反映各存储的状态。 |
| C | 凭据与接入 | 更换供应商端点时防止无声转交现有凭据，验证桌面托管网关的认证约束。 |
| D | 仓库与发布 | 移除已知敏感值和豁免，堵住工作流的不可信输入和产物来源缺口，按发布锁文件检查依赖。 |
| E | 数据生命周期 | 核实默认加密与外发策略，设计存量数据迁移、删除和恢复验证。 |

各批先复核基线，随后跑目标用例和严格格式检查。对新增安全断言记录负控结果。合并前运行仓库门禁，逐条回填受影响的状态声明。

## 存量数据迁移验收

- 将后端会话、记忆、审计、备份及桌面快照逐项登记。持久化密钥与数据分开管理，启动、升级、恢复和轮换均验证实际密钥可用性。
- 使用合成存量资料验证迁移可中断、可恢复以及坏密钥时拒开。逐项核对主库、日志、临时文件和备份中敏感值是否仍然存在，记录旧副本的保存与处置权限。
- 账号删除先缩小写入范围，再检查各存储的删除回执。用可重试任务承接部分完成、进程崩溃和失败恢复。对外部数据只报告已有可核实的处理状态。
- 将模型出境开关与图像能力、检测范围及供应商规则一起验证。默认策略调整后补跑在途桌面接口与兼容用例。
