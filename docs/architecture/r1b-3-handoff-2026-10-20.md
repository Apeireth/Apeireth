## 3. 硬约束

1. 新信号**只在"生产者 + 订阅者同批"时加**（ADR-0009 §8 收窄原则）；只加 enum 变体不算完成。
2. 生产者必须在原开关关闭时不 publish（默认关零变化）；不新增 env/开关/crate/外部 dep。
3. 不把 runtime→assembly 的方向反转：runtime 侧不为总线新增依赖；assembly 侧可依赖 runtime 类型。
4. `NervousSignal` 仍是内部私有（不挂公共 ABI、不登记 extension_points）；schema v2 属 R1b-4，本批不动
   `nervous_system` 输出形状。
5. 台账 3 条校验单测必须继续绿；新增信号行不得出现"无 reason 的 NotWired"或"无装配根的 PW"。
