## 3. 硬约束

1. 新信号**只在"生产者 + 订阅者同批"时加**（ADR-0009 §8 收窄原则）；只加 enum 变体不算完成。
2. 生产者必须在原开关关闭时不 publish（默认关零变化）；不新增 env/开关/crate/外部 dep。
3. 不把 runtime→assembly 的方向反转：runtime 侧不为总线新增依赖；assembly 侧可依赖 runtime 类型。
4. `NervousSignal` 仍是内部私有（不挂公共 ABI、不登记 extension_points）；schema v2 属 R1b-4，本批不动
   `nervous_system` 输出形状。
5. 台账 3 条校验单测必须继续绿；新增信号行不得出现"无 reason 的 NotWired"或"无装配根的 PW"。

## 4. 验收清单（架构线复核）

- [ ] 每个定性为"接"的信号：生产 publish 点（集成测试断言 `published_count(kind)` 增长）+ 订阅者收到并产生可断言效果
- [ ] 每个定性为"不接"的信号：台账 `NotWired` + 具体 reason（不是"未接"三个字）；本文对应行更新结论
- [ ] 默认关零变化：全关时无 publish 计数、总线 `is_idle()` 恒真、既有 bio 测试不变
- [ ] `cargo check/test -p apeireth-runtime-assembly --all-targets --locked` exit 0；clippy `-D warnings`；fmt `--check`
- [ ] `python scripts/arch_guard.py --report` VIOLATIONS 0（EXC-0002 仍唯一活跃例外）
- [ ] `python scripts/docs_truth.py --verify --check` exit 0；`python scripts/wiring_report.py --verify` exit 0
