# R1b-2 交接单 — 机制订阅迁移（架构线 → 生物线）

> 依据：ADR-0009 §4（R1b-2）、r1b-inventory-2026-10-20.md §8/§11、`6837d9b7`（R1b-1b 交付后实况）。
> 日期：2026-10-20。状态：**待生物线开工**（前置：生物线当前 WIP 提交 + 全量绿）。
> 本文是交接包与验收口径，不是第二份 spec；冲突时以 ADR-0009 为准。

## 1. 背景与目标

R1b-1a/1b 已交付（`10ec68ae` / `6837d9b7`）：

- 运行时内部私有同步总线 `NervousBus`（`crates/engine/runtime-assembly/src/canonical/nervous_bus.rs`）：
  `subscribe(kind, Arc<dyn Fn(&NervousSignal) + Send + Sync>) -> usize` / `publish(&NervousSignal) -> usize` /
  `subscriber_count` / `published_count` / `delivered_total` / `is_idle` / `snapshot()`；
  信号面当前只有 2 个事实信号 `NervousSignalKind::{ToolOutcome, ErrorObserved}`。
- 唯一钩子桥 `NervousBridgeModule`（`nervous_bridge.rs`，模块 id `nervous.bridge`）：注册为模块表**首位**，
  `AfterToolResult → ToolOutcome`、`OnError → ErrorObserved`，恒 `ModuleOutcome::continue_()`。
- 开关单入口 `NervousSwitchboard`（`nervous_switchboard.rs`）：9 开关 + 1 参数一次解析，fail-closed 只认 `"1"`；
  全关 = 不注册桥 = 零行为变化。
- 装配根（`production.rs`）已持有 `Arc<NervousBus>` 并提供 `ProductionModules::nervous_bus()` 只读句柄；
  四个生物安装函数已改收 `&NervousSwitchboard`/显式 bool（R1b-1b）。

R1b-2 目标：让生物机制从"各自在 `on_hook` 里挑钩子"改为"订阅总线信号"，使**观测面只有一处**
（桥），机制只消费事实信号；同时注册 lifecycle probe、把审批面反馈改为 publish。
**默认关零行为变化**是硬约束。

## 2. 前置条件（交接闸口）

1. 生物线当前 WIP（`canonical.rs` / `bio_production_wiring.rs` / `production.rs` / `permission_preset.rs`
   等在途改动）已提交，且其全量门禁绿（其线广播的 test-baseline 口径）；
2. `git status` 中上述共享文件无其他线在途 M（本线交接时 architecture-line 不再碰装配根）;
3. 基线：`arch_guard --report` 当前 VIOLATIONS 0（`EXC-0002` 抑制 cognitive.rs 尺寸增长，weight=1，
   expires_wave=6）；生物线不得让该计数恶化。

## 3. 范围（R1b-2 三批，每批独立 commit、可独立 revert）

### R1b-2a 订阅面：bio_tone（最独立，先做）

- 现状锚：`crates/engine/runtime-assembly/src/canonical/bio_tone.rs`
  - `BehaviorModule::on_hook`（:487）→ `tone_feedback_from_hook`（:220）→ `ToneState::apply_feedback`（:295）；
    `AfterToolResult` 成功/失败 + 首次工具名 Novelty、`OnError` → TaskFailure（:226/:233/:457/:460）。
- 迁移：装配处（`production.rs` 构造 `bio_tone` 状态后）订阅 `ToolOutcome` 与 `ErrorObserved`，
  在回调里重建同样的 `ToneFeedbackKind` 映射（成功/失败/Novelty 首见集仍由模块自带状态维护），
  然后**删除 `on_hook` 里对这两个钩子的映射分支**（保留 TurnStart 等只读装配分支）。
- 等价性注意：桥在模块表首位、同步发布，回调在桥的 `on_hook` 内执行——整轮钩子派发结束时
  tone 状态与迁移前一致；新增测试断言"同一 hook 序列结束态相同"。
- 验收：`bio_tone_wiring.rs` 等现有测试不变绿 + 新增 1 条"仅订阅也能得到相同 tone 状态"集成测试。

### R1b-2b 订阅面：bio_lifecycle（+ probe 注册）

- 现状锚：`bio_lifecycle.rs` `on_hook`（:701；`AfterToolResult` :710 / `AfterTurn` :713）；
  模块头 :11-24 已列信号源 1/3。
- 迁移：`AfterToolResult` 部分改订阅 `ToolOutcome`；`AfterTurn` 是回合收口评估，**保留 on_hook**
  （总线当前不发回合边界信号，R1b-3 再议）。
- lifecycle probe：`bio_production_wiring.rs` 的 install 路径当前注册 8/14 格；补
  `BioMechanismKind::Lifecycle` probe 注册（`bio_mechanism_probes.rs`），并把台账 SG-26 缺口文本
  从"最多 8/14"改为实况 9/14。
- 验收：`tests/bio_lifecycle_persistence.rs` 全绿 + 新断言 probe 计数 + 台账行更新。

### R1b-2c 审批面 publish（新信号，同批生产者+消费者）

- 现状锚：`crates/adapters/cli/src/canonical_approval.rs:36` `apply_approval_social_feedback(...)`
  直接写 `Arc<ToneState>`；映射在 `approval_social_feedback`。
- 迁移：新增 `NervousSignalKind::ApprovalSocial`（事实信号：approve/reject/expired 三态 + 来源 label），
  CLI 审批路径改 `bus.publish(...)`；bio_tone 侧订阅映射到 `SocialPositive/SocialNegative`，
  再走 `ToneState::apply_feedback`。生产者与订阅者必须**同批 additive**（ADR-0009 §8 收窄原则）。
- 兼容：旧直写 `apply_approval_social_feedback` 在批内保留（双写会让测试重复计分，需在批内
  二选一：推荐 publish 单路径 + 迁移旧测试）；不得出现两套真源。
- 验收：审批集成测试（approve/reject/expired 三态）绿 + 总线 `published_count(ApprovalSocial)` 断言。

## 4. 本批**不做**（边界，如实）

- 不新增开关、不新增 crate、不改默认值；新信号只在"生产者 + 订阅者同批"时加。
- 不迁移 `care_heartbeat` / `bio_circadian` / `play` / `quorum` 的消费面（它们依赖 R1b-3 的信号源
  `RitualDone/Skip`、`SleepPressure`、`ScarLearn`、`SessionEvent`；R1b-3 再动）。
- 不动 CLI 侧 care/pain/circadian 的 env 读取点（R1b-3 收敛）。
- 不把总线升为扩展点/公共 ABI（需新 ADR）；不让适配器反向依赖 runtime-assembly 内部模块（只用
  已有的 `nervous_bus` getter 或装配根注入句柄）。
- 不改 `docs/03-reference/test-baseline.md`（数字真源归全量门禁执行线，由生物线广播）。

## 6. 回滚

- 每批独立 commit：`git revert <commit>` 即可回到 R1b-1 状态；回调注册与 `on_hook` 分支删除在同一
  commit 内，回滚一步还原；台账行随批回滚。
