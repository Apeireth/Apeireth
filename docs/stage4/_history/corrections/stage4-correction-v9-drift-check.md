```
    └─ 是否需要主人拍板
  ↓
  team_leader 立即与主人沟通（用 START-HERE.md §入口路由）→
    ├─ 提交漂移报告：`reports/drift-<阶段>-<§>-<日期>.md`
    ├─ 主人拍板（继续 LOCKED / 修 LOCKED / 修后续阶段 / 接受漂移）
    └─ 按主人拍板执行
  ↓
  漂移解决 → 报告 commit + 更新漂移检查清单
```
