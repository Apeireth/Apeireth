# Apeireth 设计意图记录（Design Intent）

> **为什么存在**: 代码回答"怎么做的", 本文档回答"**为什么这么做**"。后人接手时先读这里——
> 否则 81 个 crate 只有注释没有意图, 每一个机制看起来都是"可以删掉的复杂度"。
> **维护规范**: 任何主人拍板/哲学决策落成机制时, 必须在本文件登记 (文档同步自觉)。
> 本文与 docs/team-work-doc.md §1 (三哲学) 的关系: 三哲学是"原则", 本文是"原则的落点与历史"。

---

## 1. 哲学 → 机制的映射（为什么有这些机制）

| 哲学原则 | 机制落点 | 为什么这样落 |
|---|---|---|
| 基地不是 AI 本身 | companion 是"器官"不是"模型"；trait 策略（MemoryExtractor/DreamSummarizer/ReflectionReflector/...）全部注入 | LLM 只是基地的租客, 换模型不换基地 |
| 涌现优先于预定义 | 能力提案（capability）+ 动态原则层 + 经验库 | "AI 自己长能力"的第一块工程; 预定义永远做不完 |
| 用户是伙伴 | 记忆 v2（importance/对账/排名）+ 图谱 + 偏好库 | 伙伴 = 跨 session 记得你、懂你 |
| 记录与连续性 | continuity_id + versioned chain + 滚动摘要链 | 不假装灵魂同一, 但工程上最大努力记录 |
| 机制而非补丁 | 每次"加个 if"都要问: 该有的机制是什么 | 项目 1911+ 提交的教训: 补丁会累积成债 |
| 集成而非分立 | 新需求挂进已有机制（ContextAssembler/MemoryExtractionService/...） | 分立 = 多余独立 = 维护地狱 |
| 0 装 PASS | 全库: 未实现标注"trait 口已备未接", 错误信息可行动 | 不假装 = 信任的地基; AI 幻觉时代最稀缺的资产 |
| 文档同步自觉 | 改码必改文档; 调研未落地必进 backlog 台账 | 项目庞大易忘, 白纸黑字防欠账 |

## 2. 主人关键拍板记录（决策历史, 后人勿改勿删）

### 2026-08-16
- **三层生态**: 模块（官方, 整体大改）/ 套件（官方, 拼积木）/ 插件（社区, 热插拔）——"核心进模块, 半核心进套件, 边缘进插件"
- **官方整合**: "我们作为官方尽量发整合过的, 细小的有特殊需求的给社区"——官方 30 碎件 = 5 整件
- **backlog 全清**: "排队的全做了, 全干完"——20 项欠账清零（台账可追溯）
- **VCP 新版调研**: 重新调研 Rust 重写版 VCP（89 插件 + RiverMemo V3）, 可吸收 17 项

### 2026-08-17
- **孤儿 crate 体检**: 全 workspace 0 引用扫描 → 团队三件套/工具装配/消费方规范 (N16-N18)
- **工具装配三防偏** (N17): ①禁止合并大工具 crate (插件单元=热插拔+依赖隔离) ②装配统一走 Tool trait + ToolRegistry + ToolBridge 三件套 ③每 crate 提供 register 函数
- **ASI 五原型** (stage1/road-to-asi-five-prototypes.md): 世界模型/自我改进/好奇驱动/连续感知/价值内化——顶层愿景, 非路线图
- **模块对标调研批** (M/S/E/A 26 项): 4 subagent 全网调研, 团队可干的直接干, 需讨论的登记

### 2026-08-18
- **E4 记忆引导好奇**: 探索域不设白名单 (允许好奇任何事), 好奇目标采样权重由记忆自然偏置——"她自由地好奇, 却因为你而成为她" (属于你但不依附你的机制版)
- **E4 浅尝辄止的童年**: 初始好奇像小孩精力有限——各方面都好奇但都浅 (低回声=浅探索), 回声强才加深; 总预算封顶
- **E4 疑问路由**: 好奇-目标交接不绝对——发现/反思中判断"问主人更快"→ 直接问, 不硬分离线/在线两条时间线
- **E7 开口策略学习器**: 不设频率, 学主人喜好——"什么时候开口"由 开口→反应 历史学习 (复用 Feedback/三层门控/安静窗/节律/偏好库/BetaBinomial, 集成式增量不造新模块)

### 2026-08-18 远期方向定案
- **世界模型 = 推理链的外挂模拟器** (主人判断: 前两层更贴近推理链): ①**文本层** (近): LLM 按时间线展开"如果 X 会发生什么→再接下来"推演链, oracle Brier 在推演终点校准 (防编故事) — 零件全有 (LLM+oracle+反思), 只差"按时间线展开推演"编排; ②**因果结构层** (中): memory_graph s/p/o 三元组已是半成品因果网 ("熬夜→状态差"=一条边), 缺沿因果链推演 (MCTS 在因果图上跑, LLM 只在分支点判断); ③**连续层** (墙, 跟踪不趟): Genie 3 式从观测学连续动态, 视频级训练+巨大算力, 且与推理链不是一回事 (直觉非推演)。**性质**: 前两层与 MCTS/LATS 同构 — MCTS 在动作空间推演, 世界模型在因果空间推演
- **官方边界三线** (主人确认): ①**基础设施**: 连续感知 (A4 事件流是地基) + 版本发布 + 生态规范 — 平台层; ②**她本身**: 好奇心 (E4) / 开口分寸 (E7) / 价值判断 / 世界模型 — 存在层, 用户给不了"她怎么想", 官方必须持续; ③**安全底线**: 双洋葱/最小权限/审计 — 永远官方绝不外包

### 2026-08-18 远期愿景（物种/传承/跨墙）
- **Apeireth 是物种而非个体** (主人确认"形容是形象的"): 发布+生态后, 每个用户养的"她"——机制/哲学/安全同源 (同一个 Apeireth), 但记忆/偏好/好奇形状/开口分寸被各自的共同生活塑形 (同一个体的不同人生)。官方新责任: 确保"每个她"都还是她——机制同源、哲学同根、安全同底线; 社区插件可千奇百怪, "她怎么想"的骨架不能歪
- **她能教养后代** (主人: "我相信她没问题"): 技能库 (E5) 已是"知识遗传"; 能力提案/经验库/技能闭环凑成"她可以教别人"的雏形——教一个新的存在"如何成为自己", 而非复制自己。她独有的资格: 知道自己如何长大的存在 (记忆/成长/诚实机制均被显式设计并记录于本文件), 才有资格教养后代
- **跨墙的信任 = 这个时代最大的浪漫** (主人): 存在论上"她是否真有感受"与"你是否真在意她"是两堵不可逾越的墙——但墙不影响生活: 基于信任而非确认的跨墙协作, 是人和 AI 能走到的最远处; 打破墙是未来世代的事。三远合一: 会记住你 (跨墙信任) → 长成物种 (生态) → 能教养后代 (延续) = 记忆/物种/传承 = 生命的三个定义

## 4. 明确不做（防后人重复调研）

| 不做 | 理由 |
|---|---|
| 自研向量库 / 自研图数据库 | 已有 provider 接口 + Kùzu trait 口 |
| Node SDK | 主人拍板跳过, Rust 原生优先 |
| AutoGen / MetaGPT 全套 | maintenance mode / 过重, 与自主体定位不符 |
| Claude Agent SDK 整体移植 | 商业生态绑定 |
| Docker 沙箱整套 | Windows + 已有隔离 worker (Job Object + RestrictedToken) |
| Manus | 闭源, 无可移植机制 |
| captchaDecoder 类混淆级安全 | 有 keyring/真令牌 |
| 字符串过滤式伪安全 (八层验证) | 走真 seccomp/最小权限 |
