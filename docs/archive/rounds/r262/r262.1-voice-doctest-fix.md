# R262.1: voice doctest scope 修复

**日期**: 2026-08-14
**作者**: 楚零
**目的**: 修 `apeireth-voice/src/minimax_live.rs` 第 2 个 doctest 编译失败 (未 use `MiniMaxLive`)

---

## §1 问题

`cargo test --doc -p apeireth-voice` 失败:
```
error[E0425]: cannot find type `MiniMaxLive` in this scope
  --> crates/apeireth-voice/src/minimax_live.rs:238:27
   |
238 | async fn tts_demo(client: MiniMaxLive) -> Result<(), Box<dyn std::error::Error>> {
   |                       ^^^^^^^^^^^ not found in this scope
```

每个 doctest block 是独立编译单元, 第 1 个 `from_env()` doctest 用了
`use apeireth_voice::minimax_live::MiniMaxLive;`, 第 2 个 `tts_demo`
doctest 必须重复声明.

---

## §2 修复

在第 2 个 doctest block 开头加隐藏行 `/// # use`:

```rust
/// ## TTS 真接 (R172 LIVE 验证过, 122KB MP3 ID3 header 确认)
///
/// ```no_run
/// # use apeireth_voice::minimax_live::MiniMaxLive;
/// # async fn tts_demo(client: MiniMaxLive) -> Result<(), Box<dyn std::error::Error>> {
/// let audio = client.text_to_speech(
///     "hello apeireth this is a LIVE MiniMax TTS test",
///     None,  // use default model (speech-2.6-hd)
///     None,  // use default voice (male-qn-qingse)
/// ).await?;
/// std::fs::write("test_output.mp3", audio)?;
/// # Ok(()) }
/// ```
```

`#` 开头的行在 doctest 中是隐藏的 (不渲染到文档), 但编译期参与 scope 解析.

---
