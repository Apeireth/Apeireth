## §2 release-1.0.0.yml 5 个 job

### §2.1 `build-packages` (10 组合 matrix)

8 包 × 多架构 = 10 矩阵组合 (per D-06 主人 8 包同时拍板):

- **deb** × 2 (linux/amd64 + linux/arm64)
- **rpm** × 1 (linux/amd64 起步)
- **brew** × 1 (macos-13 universal)
- **scoop** × 1 (windows-2022 x64)
- **tarball** × 2 (linux/amd64 + linux/arm64)
- **msi** × 1 (windows-2022 x64)
- **docker** × 2 (linux/amd64 + linux/arm64)

每个组合跑 `cargo build --release --workspace --locked` + `packaging/<target>/build.{sh,ps1}`, 产物上传 artifact.

### §2.2 `docker-multi-arch` (linux/amd64 + linux/arm64 一次 push)

依赖 `build-packages` 全部 success. 走 `docker/setup-buildx-action` + `docker/login-action` 推 GHCR `ghcr.io/apeireth/apeireth:1.0.0`.

### §2.3 `security` (cargo audit + cargo deny + 5 守门实查)

- `cargo audit --deny warnings` (RustSec advisory db)
- `cargo deny check` (4 类: bans + licenses + sources + advisories)
- 5 守门实查 (non-root USER / API key 不入 image / audit append-only / 鉴权限流 / 内部网络隔离)

### §2.4 `perf` (cargo bench baseline 1.0.0)

`cargo bench --workspace -- --save-baseline 1.0.0`, 产物上传 artifact (90 天 retention). 给 `benchmark-tracking.yml` 做 baseline 来源.

### §2.5 `release-checklist` (12 项 dry-run)

3 个脚本 dry-run:
- `scripts/release-1.0-checklist.sh` (12 项全跑)
- `scripts/upgrade/v2.0.0-alpha-to-v1.0.0.sh --dry-run` (D-07 一次性迁移)
- `scripts/uninstall/uninstall.sh --dry-run` (8 包 0 残留)

任何 P0 fail 阻塞 release tag.

### §2.6 `release-gate` (5/5 success 终极守门)

最后一步: 5 job 全部 success 才算 1.0 release green. 任一 fail → exit 1, 阻塞 tag.

## §3 dependabot-upgrade.yml 守门

| 规则 | 行为 |
|------|------|
| 仅 patch / minor | 自动 squash merge |
| major | **不** auto-merge, 留 `::notice::` 给主人复核 |
| 触碰 `crates/apeireth-*/src/*.rs` | exit 1 (24 LOCKED 守门) |
| 触碰 root `Cargo.toml` | `::warning::` (verify workspace version 严守) |

---

## §4 benchmark-tracking.yml 性能回归守门

| 阈值 | 状态 |
|------|------|
| Δ < 10% | ✅ OK |
| 10% < Δ ≤ 25% | `::warning::` 警告 (不阻塞) |
| Δ > 25% | `::error::` 阻塞 PR |

> 跑法: `cargo bench --workspace -- --save-baseline pr-<N>`, 跟 artifact `bench-baseline-1.0.0` 对比.

| 场景 | 触发 workflow | 期望结果 |
|------|--------------|----------|

| 主人手动 dispatch | `release-1.0.0.yml` (workflow_dispatch) | 可选 skip security/perf |

## §6 排查指南

### Q1: `release-1.0.0.yml` 跑挂了

1. 看 `build-packages` 哪个 matrix fail → 跑本地 `packaging/<target>/build.{sh,ps1}` 复现
2. `security` fail → 看是 `cargo audit` (新 CVE) 还是 `cargo deny` (license/source) 还是 5 守门实查 (non-root / API key 漏配)
3. `perf` fail → 跑本地 `cargo bench --workspace` 看是不是回归

### Q2: `dependabot-upgrade.yml` 没自动 merge

- 看是 major bump → 留给主人手动 merge
- 看是不是触 LOCKED → 修了 PR 改的 src/ 文件

### Q3: `benchmark-tracking.yml` 报 perf regression

- 看是哪个 bench + Δ% 多少
- < 10% 不阻塞, 主人看看
- > 25% 阻塞, 必须找出 perf 退化点 (per `r-measure-verification-design-2026-08-05.md` §3 决策清单)
