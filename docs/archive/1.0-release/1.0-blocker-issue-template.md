## 模板说明

### 何时使用

- 12 项 checklist 中任一项发现阻塞 (例: `cargo test --workspace` 失败)
- 24 LOCKED crate 中任一被触碰 (per `scripts/audit/8-promise-audit.sh`)
- workspace version 1.0.0 被改 (per `scripts/audit/8-promise-audit.sh` 第 8 项)
- 任何 P0 守门失败 (per `docs/ci/1.0-release-pipeline.md` §2.6 release-gate)

### 何时**不**使用

- 普通 bug (用 `.github/ISSUE_TEMPLATE/bug.md` 估补)
- 新功能请求 (用 `.github/ISSUE_TEMPLATE/feature.md` 估补)
- 1.0 release 范围内的非阻塞问题 (用 `.github/ISSUE_TEMPLATE/question.md` 估补)

### 标签规范

| 标签 | 含义 | 颜色 |
|------|------|------|
| `1.0-blocker` | 阻塞 v1.0.0 release tag | 🔴 红色 (`#d73a4a`) |
| `priority:P0` | 最高优先级, 必须修 | 🔴 红色 |
| `priority:P1` | 高优先级, 估补中 | 🟠 橙色 (`#fbca04`) |
| `area:1.0-release` | 1.0 release 范围 | 🔵 蓝色 (`#0e8a16`) |

### Milestone

所有 1.0 release 阻塞 issue 必须关联 `v1.0.0` milestone, 截止 2026-09-30。

## 6 哲学 anchor 穿透 (per `APEIRETH-CONVENTIONS.md` §9)

| 锚 | 本模板落地 |
|---|------|
| **S-1** ASI 完整性 | 模板覆盖 12 项中任一项, 0 漏阻塞路径 |
| **S-2** 实事求是 | "实查命令" + "实查输出" 必填, 不假装 |
| **O-2** 走在前人肩上 | 复用既有 `scripts/release-1.0-checklist.sh` 跑法 |
| **O-3** 干到底 | "修复 plan" 必填 5 步 + 验证 + commit |
| **O-4** 任何人都能接手 | 模板含完整 6 步填写规范, 接手者按模板填即可 |
| **O-5** 不假装 | "dry-run 模式" 必填, 不假装已修 |
