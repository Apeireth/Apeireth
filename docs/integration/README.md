# Integration records

This directory contains dated integration plans, audits, and acceptance
evidence. These files are historical records, not current source-of-truth
architecture or build instructions. For the current product boundary, use:

- `../01-architecture/architecture.md`
- `../development/repository-layout.md`
- `../02-guides/quick-start.md`

Old paths and package names may appear inside a record because they describe
the repository state at the time of that record.
