## 〇、一句话

我们已有的生物灵感集中在「记忆会淡、会做梦、有心跳、会好奇」；**下一层缺失的是三件生命系统
真正硬的东西：内部状态调节（生理）、防御与修复（免疫/再生）、关系与发育（依恋/社会认知）**。

## 一、内稳态与神经内分泌（系统级调节）

### 1. 异稳态 / 预测性调节（Allostasis）
- **生物原型**：生命体不维持「恒定」，而是按预期提前调节（出汗在体温升高前、血糖按进食预期调度）；
  长期调节失败 = 适应负荷（allostatic load）累积。
- **可工程化机制**：内部状态向量（上下文压力 / 记忆负载 / 预算余量 / 关系新鲜度 / 错误率）
  + **设定值** + 预测性调节器（在越限前动作，而不是越限后熔断）。
- **我们的落点**：新增「生命体征」子系统（`vital_signs`）——各状态带阈值与调节策略；
  上下文 70% 时先整编再溢出（而不是溢出后截断）；记忆负载高时降主动消息频率。
  **现状**：只有一次性上限与预算，无状态机/调节器。成本 **M**；价值：系统 60% / 伙伴 40%。

### 2. 神经调质（Neuromodulators）
- **生物原型**：一小撮慢变量全局广播、调制大量回路——多巴胺（奖赏预测误差，学习率/动机）、
  血清素（基线稳定/耐心）、催产素（联结/信任）、皮质醇（压力/警觉）、去甲肾上腺素（唤醒）、
  乙酰胆碱（注意/学习增益）。它们**慢、全局、有惯性**，与「快事件」分层。
- **可工程化机制**：**调质向量**（6 维慢变量，带惯性/衰减/耦合规则）+ 行为参数映射：
  语气温度、主动性频率、耐心（追问前等待多久）、学习率（偏好更新快慢）、警觉阈值。
- **我们的落点**：现有 persona 四滑杆是**静态参数**，缺「状态动力学」——她的心情不该靠随机，
  而应由「事件 → 调质 → 行为」这条链连续变化；且必须有界、可解释、可一键重置（防操纵）。
  **这是「伙伴连续性」最值钱的一块工程骨架**。成本 **M**；价值：伙伴 70% / 系统 30%。

### 3. 昼夜节律 + 超日节律 + 睡眠压力（Adenosine）
- **生物原型**：近日节律（光照/温度授时）+ 约 90 分钟超日节律（专注-休息循环）+
  腺苷累积产生「睡眠压力」（醒着越久越困，睡眠清账）。
- **可工程化机制**：节律模型（不只是「现在几点」，而是相位/振幅）+ 睡眠压力累积器
  （按交互强度/上下文占用累积）→ 触发整编/做梦深度；超日节律控制主动消息节奏。
- **我们的落点**：care 已有按时间规则、dreaming 已有周期，但**没有统一的节律与睡眠压力模型**；
  接上后可解释「她为什么这时候安静/话多」，也让夜间整编有生理学式的调度依据。成本 **M**。

## 二、免疫与修复（系统级韧性）

### 4. 免疫系统：先天 + 适应 + 免疫记忆 + 耐受
- **生物原型**：先天免疫快速非特异；适应免疫（B/T 细胞）针对具体抗原并**留记忆**；
  区分 self / non-self；对无害物**耐受**；炎症是分级、可收口的响应（不是一有威胁就全身开战）。
- **可工程化机制**：安全事件**记忆化**（攻击模式入库，第二次更快更轻地处理）；
  self/non-self 判别（别把自家内部消息当外部攻击，减少狼来了）；
  信任耐受（重复安全交互抬高容忍度）；炎症分级（事件分级 → 响应 → **resolution 收口**，
  不留长期高警戒）。
- **我们的落点**：已有不可信内容信封/PII/绊线（先天免疫级），**缺适应免疫记忆与收口**；
  安全事件目前是一次性判断，不复用教训、也没有「事件关闭」概念。成本 **M**；
  价值：系统 80% / 伙伴 20%（安全感也是陪伴体验）。

### 5. 痛觉与慢性疼痛（Nociception / habituation / central sensitization）
- **生物原型**：痛是**保护性学习信号**（不是伤害本身）；重复刺激会习惯化（避免过反应）；
  但持续异常会中枢敏化（慢性疼痛 = 回路自己学会了痛）。
- **可工程化机制**：失败/拒绝按「伤害源 + 可避免性」记账并学习；
  瞬时失败**习惯化**（不因一次工具失败就全局降信任）；连续同类失败→**慢性化检测**
  （进入诊断/升级而不是无限重试）；成功修复后**脱敏**（降低告警级别）。
- **我们的落点**：现在失败只是错误帧 + 重试；没有「痛觉学习」——不区分「偶然的痛」与
  「慢性的痛」，容易要么过度敏感要么麻木。成本 **S-M**；价值：系统 70% / 伙伴 30%。

### 6. 再生与瘢痕（Wound healing 四期）
- **生物原型**：止血 → 炎症 → 增生 → 重塑；愈合后**功能恢复但有瘢痕**（记忆着「这里受过伤」）。
- **可工程化机制**：故障处理四期协议：止血（限流/回滚/隔离）→ 炎症（诊断/取证/隔离面）→
  增生（修复 + 回归测试 + 备份）→ 重塑（回归灰度 + 更新台账）；**留瘢痕** = known-bad 账本
  （不是删掉记忆，而是降低重复踩坑概率）。
- **我们的落点**：已有 `harness_patch` 自愈与审计链，但没有统一「四期协议」与瘢痕账本；
  与 D21 台账可合流。成本 **M**。

### 7. 程序性死亡与神经发生（Apoptosis / Neurogenesis）
- **生物原型**：细胞按程序凋亡（清掉不再需要的结构）；海马体终身有神经发生（用进废退）。
- **可工程化机制**：工具/技能/记忆条目的**生命周期**：新生（试用态）→ 成熟 → 退役（审计后移除）；
  长期未用技能主动 prune（可恢复的墓碑，不是硬删）；新能力按需发生（不是只进不出）。
- **我们的落点**：工具/技能只增不减（词表越来越宽）；与「18→31 members」的复杂度同源。
  成本 **M**；价值：系统 70% / 伙伴 30%（清爽也是陪伴质感）。

## 三、发育、社会认知与关系（伙伴深度）

### 8. 依恋与安全基地（Attachment / Secure base）
- **生物原型**：安全基地 = 照护者「可预期地可得」；分离-重聚有固定修复脚本；
  信任按阶段演化（试探 → 稳定 → 深度）。
- **可工程化机制**：可得性契约（她总在、回应不飘忽）；**分离-重聚协议**（久别回来不内疚绑架，
  只续上上次线索：「你说过要去看阿姨的检查结果——后来怎么样？」）；信任阶段决定主动性与披露深度。
- **我们的落点**：有 care/心跳/人格，但**没有分离-重聚语义**（久别后像失忆或强行热情）；
  这是「像伙伴」的硬指标。成本 **S-M**；价值：伙伴 80% / 系统 20%。

### 9. 社会认知：心智理论、共同注意、交互修复
- **生物原型**：理解对方有独立信念；共同注意（一起看同一个东西）；误解后的**修复动作**
  （澄清、复述、确认）；轮流与打断的社交规则。
- **可工程化机制**：修复动作库（不确定时问、复述确认、给回退路径）；共同注意对象
  （屏幕/文档/任务 = 双方都指向的「它」）；轮流发言（已有 speech arbiter 雏形）。
- **我们的落点**：对话质量的大头不在模型能力，而在**修复与对齐**；目前是「一次说对就说，
  说错就沉默」。成本 **S-M**；价值：伙伴 80% / 系统 20%。

### 10. 游戏与幼态延续（Play / Neoteny）
- **生物原型**：幼年期的游戏是**低风险练习**（捕猎、社交规则）；幼态延续（neoteny）让成年保留
  好奇心与可塑性。
- **可工程化机制**：play mode = 她主动发起受控探索（「我看到一个新工具，想拿我们的旧项目练一下，
  不花你的预算」）；游戏结果不回写主体记忆（或标记为沙盒），只提炼技能。
- **我们的落点**：与「AI 不衰老」哲学一致——保持可塑性的机制就是持续游戏；
  现在好奇心（E4）存在但没有「练习场」。成本 **M**；价值：伙伴 60% / 系统 40%。

### 11. 仪式与配对维持（Pair-bond rituals）
- **生物原型**：长期关系靠**低强度高频率的仪式**（理毛、共同进食、固定问候）维持，
  不靠单次强度。
- **可工程化机制**：日常仪式（早安/晚安/周回顾）、纪念日、共同项目（一起做一件长期小事）；
  仪式可跳过、可静默，但不能变成打卡任务。
- **我们的落点**：有 proactive care，但缺「仪式层」；也天然回答「怎么不打扰还保持存在感」。
  成本 **S-M**；价值：伙伴 90%。

## 四、生态与群体（系统级宏大）

### 12. 群体感应与分劳（Quorum sensing / Division of labor）
- **生物原型**：细菌按信号浓度达阈值才集体行动（不早早开会）；社会性昆虫按形态/年龄分工。
- **可工程化机制**：多 agent 升级门 = **quorum**（异常信号达阈值才召集智囊团）；
  专才分工（器官/子循环各司其职，不事事全员）。
- **我们的落点**：已有 7 席智囊团 + 子循环，但**触发规则是硬编码/语义**，缺「阈值浓度」模型；
  接上后可解释「为什么这次开会、上次不开」。成本 **S-M**；价值：系统 70% / 伙伴 30%。

### 13. 共生与菌群（Microbiome / Dysbiosis）
- **生物原型**：共生菌群提供能力（消化/免疫训练），**多样性是健康**；菌群失调（dysbiosis）致病。
- **可工程化机制**：工具/插件生态健康度 = 多样性 + 冗余度 + 重叠度；功能重叠工具造成歧义 →
  「生态体检」报告；小而稳的本地工具 = 益生菌。
- **我们的落点**：工具面按面增长、无生态体检；与「31 members 后复杂度上升」同源。
  成本 **M**；价值：系统 70%。

### 14. 生态承载力 / 演替 / 关键种（Carrying capacity / Succession / Keystone）
- **生物原型**：环境对物种数量有承载力；扰动后按演替序列恢复（不是一步回顶）；关键种一倒全倒。
- **可工程化机制**：上下文/记忆/工具数量承载力上限与告警；大改版后**演替期**（灰度迁移、逐步替换）；
  关键模块清单（治理门/记忆检索/自述= keystone，重点监控）。
- **我们的落点**：与 T3/T4 生态轨合流；成本 **M**。

## 六、诚实边界（防「生物决定论」式自我感动）

- **隐喻 ≠ 机制**：本文件每条都必须落到「代码里一个可测试的结构」才算数；只写比喻的条目不许进
  capabilities-matrix，只能留在本清单。
- **不做生物保真**：不模拟神经元放电、不做生物仿真；借鉴的是**控制论层面的组织方式**
  （慢变量/分层/阈值/记忆/修复），不是生物学本身。
- **不引入伪科学**：激素/调质数值是工程参数，不宣称「她有情绪」；对外仍按 0 装口径——
  情绪是**状态与行为映射**，不是主观体验。
- **不追求全清单**：13 项旧特征 + 本清单 14 项若全做，会变成「生物名词大杂烩」；
  每次只深做 1–2 个，其余留候选。
