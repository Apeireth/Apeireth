## 1. Project-N-E-K-O/N.E.K.O（五维记忆）

**卡1｜五维记忆分层（工作/近期/事实/反思/人格）**
- 解决：单一上下文窗口无法同时兼顾即时连贯、长期事实与人格一致。
- 设计：按时间尺度×抽象层级切五层——工作记忆（当下上下文）、近期记忆（近日对话）、事实记忆（提炼的稳定知识）、反思记忆（对经历的再加工）、人格记忆（自我叙事）；回忆时逐层组装进提示词。
- 哲学：记忆不是日志而是分层加工产物——同一事件在不同层以不同形态并存，越深越抽象、越慢、越稳。
- 取舍：分层换取召回精准与人格稳定，代价是写入侧分流策略与整编成本，层间边界要人工定义。
- 我们现状→进步空间：我们已有双时态+五层检索+整编+教训，但"人格记忆"未独立成层——把"我是谁"从"用户是谁"里拆出来单独整编。

**卡2｜主动陪伴多源感知面（屏幕/热搜/动态/音乐）**
- 解决：伴侣只能被动应答就是问答机，谈不上陪伴。
- 设计：多路外部信号（屏幕理解、社媒热搜、个人动态、正在听的音乐）持续流入素材池，经兴趣匹配挑料，再由发起意愿决定开口时机；专注时变猫 = 打扰抑制。
- 哲学：主动性 = 感知面宽度 × 发起意愿，两者独立演化、缺一不可。
- 取舍：信号源越多越鲜活，隐私暴露面与打扰概率同步上升，必须配静默/专注态。
- 我们现状→进步空间：我们 initiative 语义已在，缺多源素材管道——把"何时说"与"说什么"拆成两条独立流水线。

**卡3｜身份与呈现解耦（跨场景同一个"她"）**
- 解决：多端多形态下记忆孤岛、人格漂移。
- 设计：桌面/移动/游戏/硬件共享同一份记忆与人格核心；Live2D/VRM/MMD/PNGTuber/桌宠五形态只是可替换外壳，动作捕捉只驱动外壳。
- 哲学："她"是数据不是进程——身份=记忆+人格，呈现=形态+设备，二者彻底解耦。
- 取舍：统一身份换一致性，代价是同步冲突消解与存储中心化依赖。
- 我们现状→进步空间：我们记忆随库走、桌宠骨架在建——把人格/记忆序列化为可携带"身份核"，渲染端即插即用。

## 2. AIRI（moeru-ai/airi）——"数字生命可拥有"的工程化

**卡1｜Web 技术原生的双栈运行时**
- 设计：图形/布局/动画走 Web 系（WebGPU/WebAudio/Web Workers/WASM），重推理走原生（CUDA/Metal 本地推理），浏览器版是能力探针而非全量依赖——同一核心、两种宿主。
- 哲学：用 Web 生态换开发速度与跨端覆盖，把性能关键路径留给原生层。取舍：双栈维护成本换四端（浏览器/PWA/桌面/移动）同源。
- 我们现状→进步：桌面壳+web 双出口已有 → **计算密集面与呈现面的双栈边界**要像它一样画清。

**卡2｜插件化实验区（"开个子目录放你想试的功能"）**
- 哲学：扩展性优先于完成度，生态贡献门槛压到目录级。取舍：插件质量不齐换生态速度。
- 我们现状→进步：MCP+工具注册面已有 → **子目录级实验区**（skill/岛机制雏形）吸收"贡献门槛=一个目录"的组织学。

**卡3｜能力按宿主裁剪并如实标注**
- 设计：Web 端砍 TCP 类能力、桌面端全开，缺什么如实说。
- 哲学：能力边界=宿主事实，不假装。
- 我们现状→进步：web/desktop 双构建+令牌三源 → 能力面按宿主**自动降级的声明式清单**。

## 3. 溪语 AI（dimang01/xiyu-ai）——陪伴三件套

**卡1｜人格即数据面**：人格不是提示词模板而是可持久状态（人格档案+记忆分层），风格漂移被数据约束而非靠模型自觉。哲学：把"它是谁"从 prompt 升格为**状态**。
- 我们现状→进步：四滑杆+人设+learning log → 人格数据面与记忆面**同库分级**（性格事件也是记忆）。

**卡2｜主动消息**：按场景/时间/事件触发的主动触达。哲学：陪伴的温度=主动性。
- 我们现状→进步：initiative+IM 推送面已有 → **主动消息产品化**（触发器/安静时段/频率上限——打扰纪律先立）。

**卡3｜聊天隐喻外壳**：用用户最熟的交互习惯降低学习成本。哲学：界面即习惯。
- 我们现状→进步：IM 审批卡+桌面聊天窗 → 移动端聊天外壳（IM 桥是地基）。

## 4. Firefly 流萤（ff-ai/firefly-companion）——双引擎主动关怀

**卡1｜双引擎关怀**：规则式时间关怀（作息/纪念日/久未联系）+ 模型式情境关怀并行互兜底。哲学：关怀不能只靠模型"想起来"，**规则兜底保证不漏**。
- 我们现状→进步：initiative+organ → 关怀的**双轨制**（规则引擎与模型引擎分立）。

**卡2｜原声语音+工具链**：声音即身份 + 工具可调用。哲学：感官与能力并进。
- 我们现状→进步：voice 输入侧+工具全链 → TTS 输出闭环（通用嗓先行，专属音色=资产活）。

## 5. Alife（BDFFZI/Alife）——桌宠的克制工程学

**卡1｜极低开销架构**：常驻=资源纪律（进程轻、渲染省、闲置静默）。哲学：陪伴的分量不等于资源的重量——**常驻软件的第一美德是不打扰你的电脑**。
- 我们现状→进步：待机 17.5MB+呼吸光 idle → **空闲预算档**（CPU/GPU/IO 三面限速，桌宠活动有预算闸）。

**卡2｜AI 自主插件开发**：让 agent 自己写插件扩展自己。哲学：进化的入口是插件位。
- 我们现状→进步：apply_patch/worktree+技能卡在建 → **"它给自己写技能"的受控回路**（写卡→试用→留痕，走审批链）。

**卡3｜形象即入口**：桌宠形象本身是产品说明书（看见即拥有）。哲学：形象即说明书。
- 我们现状→进步：桌宠骨架在建 → 形象的**情绪反馈语义**（呼吸光已是雏形——光即它的表情）。
