# L 轴 · 会话经验沉淀（工程经验 → 项目资产）

> `Status: 📋 待办（2026-10-15 立；owner 裁定：系统性总结吸收，后续专批执行）`
> 矿脉规模：单会话 431 轮 / 1695 步 / **104 个子智能体**——多 AI 大规模并行施工的完整实战记录。

## 一、为什么挖

- 这是一场**多 AI 协同工程**的完整样本：宪章在 10+ 并行线上的真实效力、冲突与自愈、死亡与接棒——
  业界几乎没有这种规模的可复盘记录；
- 经验若不沉淀，会随会话蒸发；沉淀进项目资产 = **后来的协作者（人与 AI）少踩每一个坑**。

## 二、挖什么（五个矿脉）

1. **协同模式矿**：叠加不覆盖的实战边界、跨线报备/补位/占位互保、协调者归并节奏、
   "见债必还"顺手修的尺度、同文件并行的呼吸与瞬断自愈；
2. **死亡解剖矿**：启动猝死×N、内容过滤误伤（安全词/擦边词触发）、上下文读爆（README 徽章墙/巨文件）、
   路径拼接陷阱、CRLF 吃替换、PS 语法坑（`@{u}`/引号/`-i` 歧义）——**每种死法配防复发药方**；
3. **设计裁定矿**：口径裁决集（命名让位家族一致性/族集授权不绑目标+补偿/迁移生效/构造式断言/
   保守下界不冒充规格书/绝不编价/空态"—"语义）——裁定背后的推理链；
4. **方法论矿**：已验证配方（剥装饰取材/渐进落盘/单项目粒度/源头净化防过滤）、
   接棒制遗嘱格式、门禁分层（本批门禁 vs 全量门禁 vs 隔离复跑定性 flake）、
   "无脚本不发布数字"的执行细则；
5. **产品洞察矿**：内测用户的判词价值（"开关不均匀生效""工具在清单≠能产出结果"）、
   模型的实测精神、"AI 先用、人后用"第一律的诞生现场。

## 三、怎么沉淀（产出物）
