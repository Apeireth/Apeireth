# B. 性能极致

> `Status: 📋 想法细节（隶属 00-backlog #B）`

## 现状（实测基线见 reports/benchmark-reproduction.md）
- 微内核冷启动 **22ms（目标 10ms，红行 2.2×）**——剩余大头=真冷口径的库文件创建/DDL 系统开销；
- 待机内存 17.5MB ✅、检索 3.65ms ✅、配额调度 0.81µs ✅、沙箱 spawn 12.8ms ✅；
- 已有工具：基准脚本（一键复跑）、cache_trace 诊断钩子、-j 2 链接口径。

## 想法（"找写得不好的开刀"）
1. **冷启动红行**：建库/迁移/连接的分段剖析 → 库预置/懒 DDL/迁移合并（前期已做一轮，再深一层）；
2. **热点二轮**：记忆检索（图遍历/融合排序）、事件折叠（fold_surface）、锁竞争（file_lock flake 说明锁设计可再看）；
3. **并行度**：并行工具调用（CallScheduler 失败关闭的骨架可开）、流式管线的背压；
4. **构建性能**：target 目录治理（380GB 事件）、增量编译策略、CI 时长。

## 缺口

## 分期
P1 冷启动冲刺（10ms 红行清零）→ P2 热点二轮 → P3 并行工具。

## 验收
