# F. 服务端形态（T2 中枢）

> `Status: 📋 想法细节（隶属 00-backlog #F）`

## 架构定案（2026-10-02）

**星群为骨、共享为翼**：多户各持独立伙伴实例（记忆/性格/配额硬隔离），中枢统一调度并选择性共享匿名化经验（教训/技能，不出记忆原文）。

## 现状
- 网关已是 headless 可跑（`gateway serve`）、IM 桥/审批卡已通、TUI 驾驶舱可连、SDK 面向集成；
- daemon 化已落地（W2-①：服务/计划任务脚本 + 常驻占位 + 优雅停机收尾）；
- **远程访问认证面已收口（W2-②，P3 主体）**：全 API 面令牌门（三态沿用，仅 `/health` 探活豁免）+
  每客户端令牌表（name→token，审计带客户端名）+ 非回环绑定强制令牌（fail-closed 拒启动）+
  `APEIRETH_LISTEN` 绑定旋钮（缺省仅本机）——见 [W2-2-remote-access-auth-delivery.md](W2-2-remote-access-auth-delivery.md)；
- **多客户端会话复用已落地（W2-③，P2 会话面）**：并发会话路由（每客户端独立订阅 +
  同会话事件扇出多端，`/v1/apeireth/events?session=`）+ 同会话并发写语义（**排队 + 审计**，
  会话账本零交叠写）+ 会话归属面（`gateway.session_client` 审计行 + name↔token 绑定校验）+
  面板读快照一致性 —— 见 [W2-3-multi-client-session-reuse.md](W2-3-multi-client-session-reuse.md)；
- **跨户数据隔离·数据面已落地（W3-①，星群地基）**：用户域模型（`users/<id>/` 每户一域，
  冻结角色词表同 W3-②）+ **单户兼容采用**（默认域原位标记，零迁移零丢失）+ 三面
  （会话/记忆/配额账本）按域分库 + 跨域拒绝即帧（404/403 语义，不泄露他域存在）+
  域上下文传递（请求→身份→user_id 域解析→会话面按域路由）+ 自述域节
  —— 见 [W3-1-multi-user-data-isolation.md](W3-1-multi-user-data-isolation.md)；
- 仍缺：**TLS 真接线**（现为接口桩，`APEIRETH_TLS_CERT/KEY` 显式未接线）、
  星群**每户伙伴实例**（逐域运行时/记忆人格；数据面已隔离，回合面待接）、
  部署形态（P4）。
  每客户端**权限**分级已立（W3-②：用户模型 + 冻结角色词表 owner/member/guest + role 权限矩阵 +
  令牌→用户→角色链 + 角色门 + `apeireth user` 管理命令 + `gateway.user_action` 审计——见
  [W3-2-user-identity-roles.md](W3-2-user-identity-roles.md)）。

## 想法（目标画像：服务器跑核心，手机指挥）
1. **daemon 化**：Windows 服务/计划任务 + Linux systemd 单元；崩溃自拉起；
2. **多客户端复用**：桌面/TUI/IM/web 同时在线（会话路由、事件分发已有租约语义可站）
   → 会话面已落地（W2-③）；
3. **远程访问**：TLS + token 认证 + 每客户端权限（E 轴多用户的前置）；默认仅本机（fail-closed）；
   → token 认证 + 默认仅本机 + 远程绑定 fail-closed **已落地（W2-②）**；TLS 面接口桩未接线；
   每客户端权限分级**已落地（W3-② 角色门）**；
4. **部署形态**：容器化/一键安装脚本、数据目录规范、升级通道（热替换脚本已有雏形）。
