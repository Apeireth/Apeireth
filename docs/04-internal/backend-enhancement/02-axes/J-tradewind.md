## 要点

1. **多源订阅路由**：信息源插件化（视频平台、资讯、动态），统一「条目流」抽象；
2. **摘要与陪看**：智能体预筛/摘要/陪看点评，省时间而非抢时间；
3. **注意力纪律**：配额真接口（想法 A）联动——刷流时长/烧钱闸数值化，防沉迷是产品底线；
4. **隐私**：观看画像只进本地记忆，不外发（星群共享只走匿名化经验）。
