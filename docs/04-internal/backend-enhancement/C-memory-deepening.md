# C. 记忆深化

> `Status: 📋 想法细节（隶属 00-backlog #C）`

## 现状
- 记忆主体已强：双时态、追加写死、五层检索、溢出取回、保护/遗忘曲线（TLA+ 验证）；
- 浅接/待产：consolidation（固化整编）、reflexion（反思教训）、self_tuning（自调校）、形态召回、吸收洞察——开关在、深度浅；
- 图谱/向量：amem_graph/语义轴在库，embedding 生产接线缺（无 embeddings 端点口径在案）。

## 想法
让记忆从"记得对"到"记得聪明"：
1. **夜间整编**：consolidation 生产化（会话→长期记忆的固化策略、重复合并、图谱建边）；
2. **教训回路**：reflexion 教训喂回行为（教训→提示词/工具选择的实证回路）；
3. **自调校闭环**：self_tuning 的信号面扩（不只记忆召回挂靠），调参实证化（A/B 或离线评估）；
4. **图谱/向量生产**：embedding 端点接线（provider 适配）、图谱查询进检索融合（真权重）。

## 缺口
- 效果度量：记忆质量的离线评估集（回答准确率/召回命中）——没有度量就没有"更聪明"。

## 分期
P1 效果评估集 → P2 夜间整编 → P3 教训回路 → P4 图谱向量生产。

## 验收
每项深化带效果对比（评估集数字），不许"感觉更聪明"。
