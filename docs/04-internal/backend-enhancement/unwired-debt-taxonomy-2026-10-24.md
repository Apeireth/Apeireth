## 1. 为什么要分类

`audit_unwired.py` 只能回答「**这个符号在生产代码里被引用了吗**」，
它**不能**回答「**该不该**被引用」。把两者混为一谈会产生两种错误：

- 把**公开 API 表面**当债 ⇒ 越「还」越把库搞残缺；
- 把**真缺陷**当合理 ⇒ 债永远还不完。

所以基线必须分组，否则「155」这个数字没有管理价值。

## 2. 六组（按「为什么零引用」分）

| 组 | 条数 | 是什么 | 该做什么 |
|---|---|---|---|
| **G1** | 4 | 集成测试辅助 API（`*_for_test`） | 保留。**不能**加 `#[cfg(test)]`（`tests/` 目录直接调用，加了集成测试编译失败） |
| **G2** | 9 | **W1 IM 通道**（owner 2026-10-23 裁定暂缓） | **有意不接**。等「Apeireth 在社交软件里自由聊天」专项 |
| **G3** | 70 | 生物机制 / 认知 / 编排的**观测与查询 API** | 生物族默认关 ⇒ 打开前查询路径不会被走到，属预期。打开后由自述面/宿主使用 |
| **G4** | 11 | **注入点 / 探测口**（`with_*`） | 生产装配走 `install_*` 路径，不经这些方法。多为集成测试注入点或宿主 API |
| **G5** | **47** | **待判** | **还债从这里开始** —— 逐条要人回答「真没人调，还是判据看不见」 |
| **G6** | 14 | **公开 API 表面**（装配入口 / 文件生成 / 合成器） | **预期的库表面**，不是债。供宿主或外部调用，本仓内部只由单元测试用 |

> 合计 4+9+70+11+47+14 = **155**

## 3. G5 的 47 条：怎么判

判断一条属于哪种，问三个问题：

1. **它有生产调用者吗？** —— 没有（这是它进基线的原因）。
2. **有宿主/外部调用它的可能吗？** —— 有 ⇒ 移到 G6，写清「宿主 API」。
3. **它的设计意图还在吗？** —— 意图已消失（被别的路径取代）⇒ **删**；
   意图还在但没人接 ⇒ **接线**。

### 3.1 本轮已按此规则处理的样例

| 符号 | 判断 | 处理 |
|---|---|---|
| `replaced_any`（egress_gate） | 我上轮加的死代码，且名字说「本次判定」实际读**全局**登记簿计数（名不符实） | **删** |
| `loop_config_mut_for_test`（orchestrator） | 零调用，**连集成测试都不用** | **删** |
| `egress_gate_from_env`（egress_gate） | 公开 API 表面：生产走 `egress_gate_from_env_with_ledgers`（要传账本路径），无参版是**宿主入口** | 移到 G6 |
| `build_production_governance(_from_env)` | 被 `tests/` 直接调用 ⇒ 集成测试辅助 | 移到 G1 |
| `dispatch_gateway_serve` | 公开 API 表面：`main.rs` 走 `dispatch_gateway_serve_with`（要传 bind + pid 文件），单参版是便捷入口 | 移到 G6 |

**本轮净减 2 条（157 → 155）**，全是真删，不是改判据。

## 4. 还债纪律（沿用仓库既有做法）

1. **只减不增**：CI 棘轮拦住新增（`.github/workflows/unwired-ratchet.yml`）；
2. **每还一条就缩一行**：接线/删除后 `--update` 一次，让数字真实下降；
3. **不靠改判据缩表**：判据改严必须同时说明「旧判据错在哪」——
   本仓 2026-10-24 有过这样的正当改严（五个 bug 修复，见脚本 docstring）；
4. **每条债要有结论**：接线 / 删除 / 移到某组并写理由。**不能只是留在 G5**。

## 5. 已知的判据盲区（都导致假阳性，方向安全）

- **宏展开生成的调用**看不到（`routes![]` 这类）；
- **按名字字符串动态查找**（反射式注册）看不到；
- **`tests/` 目录的调用**看不到 ⇒ `test-only` 与 `orphan` 的区分不可靠
  （两类都表示「生产零引用」，这是唯一可靠的结论）。

⇒ 所以本工具是**发现器**，不是法官。它的正确用法是：
**「它说零引用 ⇒ 值得看一眼」，不是「它说零引用 ⇒ 就是没接电」。**
