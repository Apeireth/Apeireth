# 施工纪律（多 AI 共同施工宪章）

> `Status: 🔒 生效中（2026-10-02 立，适用于后端增强全部工程）`
> 这份文件是给**每一位进场施工者**（含外部协作 AI）的第一课。目标：活儿干漂亮，**零技术债**。

## 一、不许留债（零债纪律）

1. **不新造债**：不写"临时实现"、不留 TODO 无主、不注释掉代码当备忘（要么删要么完成）；
2. **见债必还**：碰到既有债（编译警告/陈旧断言/孤儿代码）顺手清或明确登记到 `00-backlog.md` 的债栏，不许"路过就算"；
3. **命名即承诺**：符号/开关/字段的名 = 它的全部权力（名实相符，见 capability-switch-power-audit 先例）；
4. **测试即证据**：没有测试钉住的实现等于没做；测试要钉**行为**不钉字面（演进断言时注明理由）。

## 二、叠加不覆盖（多人并发纪律）

1. **edit 前先读后改**；文件冲突时后到者 rebase，不覆盖他人在途工作；
2. **战场不重叠**：批与批的文件范围预先声明（write_scope），同文件区施工必须排队；
3. **半成品不弃尸**：中道停机必须回报"已完成/未完清单"（接棒制的遗嘱）；
4. **他人文件不乱动**：跨范围的顺手修 = 报备 + 最小改动 + 说明。

## 三、口径与诚实（不假装纪律）

1. **无脚本不发布数字**；未达标标红；"暂无接口"就写"暂无接口"（零假旋钮）；
2. **口径唯一**：crate 数/测试数/版本轴/术语全库一致（口径统一批先例）；带日期的历史档案不动；
3. **错误即帧**：失败走正式通道报真因，不静默降级、不"applied 0"式谎帧；
4. **中性表述**：代码/注释/commit 零第三方产品名、零"移植/借鉴"措辞（真实路径与研究引注走豁免表）。

## 四、工程门禁（每批交付的出口）

1. `cargo test --workspace --locked -j 2` 全绿（链接器内存口径；负载 flake 隔离复跑定性）；
2. `cargo clippy --workspace --all-targets --locked -j 2 -- -D warnings` 零警告；
3. `cargo fmt --all -- --check` 干净；前端 `pnpm check` + `pnpm test` 全绿；
4. `scripts/check-neutral-terms.ps1` 零命中；secret-scan 过；
5. 文档随行：影响口径/接口/行为的改动同步文档（含审计表/契约文档）。

## 五、验证与证明（与验证面硬化线合力）

1. 治理/安全语义改动 → 补对抗测试（绕过尝试用例）；核心不变量尽量上证明面（Kani/TLA 口径）；
2. 破坏性/不可逆语义 → 默认拒绝，人工审批链兜底；
3. 性能改动 → 基准前后对比（脚本可复跑），不许改口径粉饰。
