## 与相邻轴的边界

- **随手记（Quick Capture）**：入口面已随 C 轴交付（[quick-capture-delivery.md](quick-capture-delivery.md)，
  未整理原料入记忆流）——按候选池登记归 C 轴分期，本轴不重复施工；
- **C 轴（记忆深化）**：夜间整编/教训沉淀是技能卡的上游原料之一；技能库**不**替代记忆流
  （记忆=经历与人，技能=可调用的方法），互不越界；
- **船坞（生态分发面）**：I4 的技能包市场面对接位，届时按其注册表契约接入，本轴不预建空壳。

## 铁律（随期验收）

- 上下文预算纪律：技能卡进模型上下文只有 **L2 封套披露**一条路（检索式注入），
  绝不无差别全量注入；
- 治理档诚实：沉淀是写文件面（file_write 总闸族 + 每次人批），检索是只读档（零审批零写盘）；
- 拒开语义：技能库坏卡拒开并如实计数，不「读坏用默认」；重复名拒绝，版本演进留旧版审计；
- 每期过门禁：workspace 测试/clippy/fmt/中性词（校验带 `-j 2`）。
