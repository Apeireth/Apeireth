## 一、为什么挖这批

2026-10-20 → 2026-11-08 这段战役的主线**不是功能，是度量与声明的自我治理**：

- 声明真源（`claims.yaml`）扩到 **51 条**，并在合并后被**三轮重盖**；
- 棘轮（尺寸 / 依赖边 / env 预算 / 孤儿面）反复被顶格与收紧；
- 新量具（能力可达率）、新守卫（族级双判据）、新通道（凭据形状绊线）陆续落地；
- 本仓**最大的一次合并**（分叉 **1414 文件 / +21.7 万行**）与 **14 笔收口批次**。

⇒ 这些经验的共同病灶只有一个：**数字与状态会悄悄变成散文** ⇒ 与 L 轴第一战役的「协同 / 死法 / 裁定 / 活法 / 洞察」
**不重叠** ⇒ ⇒ 值得另开两矿。
