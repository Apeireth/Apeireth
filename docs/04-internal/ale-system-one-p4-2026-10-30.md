The optional portable MeshModule implements real fixed-peer loopback UDP under the existing module lifecycle, Internal execution gate and message transport. It is software evidence only. No external device/LAN/NAT, encryption, cryptographic peer authentication, discovery, durable recovery or live selected supervisor model has been validated. The module is absent from default production composition. Existing Shell and Memory opt-in contracts continue to use their original executors/AgentInstances; compatibility C01/C02 remains open, so universal/default protection is not claimed.

Real path: Host registers MeshModule with bounded immutable peer configuration -> PluginManager creates a real generation and ModuleTaskScope -> lifecycle starts one worker with a pre-acquired owned lease -> wait for existing AgentRuntime binding -> own ModuleMessages.invoke_internal -> explicit standing route and ModuleAgentGrant -> existing private mailbox AgentInstance/Session -> original Dispatcher and deterministic scope/schema/Governance/budget/cancel checks -> System One review/audit acknowledgement -> matching execution receipt -> fixed-policy UDP bind/send/receive -> private outcome -> typed status. Each heartbeat is reviewed independently. No raw network helper, extra Provider loop or Main forwarding is used. The existing pure protocol codec is untouched and is not reinterpreted as secure networking.

Public mesh.connect(device) acknowledges interest in the already Host-scheduled configured peer task. It immediately returns Accepted + a TaskId/ModuleInstanceId handle; it does not wait for the socket, add a peer, promise connection success, or borrow Host authority for a new caller-delegated request. Other devices are refused. Arbitrary user-delegated network connection is not implemented. mesh.status accepts an optional exact current task handle and projects only state, online_peers, network_health and pending_operations. A stale generation/handle is refused. Degraded status remains truthful after denied/unavailable transport. These public methods do not perform protected I/O themselves.

The native exchange is a registered Internal surface, hidden from models and cross-module public addressing. Raw invoke/invoke_frozen refuse execution. FrozenInvocation binds endpoint, private packet and fresh token; the display shows only the logical peer and operation. The deterministic executor revalidates exact immutable configuration and loopback address and accepts only an exact source/token/packet reply. Socket acquisition/send/receive occur only after review. The protocol is plaintext local correlation, not authentication against a hostile local process. A failed/aborted request never implies rollback of an already-sent datagram. Review Allow is not a fabricated completed-effect fact.

Optional status publication sends an explicitly authorized PublicStatus Event to another registered module with the typed whitelist. No raw packets, internal prompts, keys, endpoint or receiver business result are injected into Main. Failed publication stays private and retries on a later bounded heartbeat. A single sequential worker and existing mailbox/native limits prevent an unbounded task/queue buildup. Existing Host budgets are not enlarged; exhaustion fails closed and requires explicit Host capacity/recovery planning.

Lifecycle evidence includes stopping Main while standing work continues, cancelling a socket awaiting reply, actual module unregister/drain, stopped status, no future datagrams after return, re-registration with a new generation and old-handle refusal. The scope lease is acquired before spawn and released after the scoped worker ends; no detached native blocking operation escapes drain.
