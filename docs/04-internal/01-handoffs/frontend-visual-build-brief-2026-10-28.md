## §1 项目一句话

**Apeireth 是一个 AI 工作系统（AI 操作系统）。旧前端被 owner 判定「整体不行」，现在要推倒重建全部视觉方案。**

本阶段目标：

1. 把新视觉语言做出来（一套可复用设计系统）；
2. 用高保真、可交互原型证明它（三空间 × 明暗 + 全息基地）；
3. 让 owner 第一眼说"行"，并让后续引擎实现有据可依。

> 交付物是**设计原型与规范**：真数据/后端/引擎实现是后续另一条线的事。请不要接后端、不要动生产仓库。

## §3 试金石（owner 会拿这句验收）

> **任意一屏，3 秒内回答三问**：我在做什么工作？下一步做什么？系统是否正常？
>
> **看一眼就像在操作一台强大的机器**——不是浏览网页，也不是参观监控中心。

- **首屏落点 = 工作画布**；空间化视觉不抢戏。
- **控制塔落点 = 全息基地**；但它不承担"开始工作"。

## §4 视觉方向（给感觉，不给死规格）

**像什么**：好的工作台 + 精密仪表；现代 SaaS 的清晰纪律 + 科幻、高信息密度、动态、高级感。

**三空间的语言分工**：

| 空间 | 默认模式 | 语言要点 |
|---|---|---|
| **工作空间**（首屏） | 亮 | 工作画布为主：强排版、清晰层级、低对比环境背景；AI 协作栏半透明压边；命令条常驻 |
| **应用空间** | 随应用 | 应用 chrome 极简；共享工作上下文（文件/选区/版本）；工具栏克制 |
| **控制塔**（主动进入） | 暗 | 全息基地（城式基地 + 三层环）、遥测、轨迹视图、审批、事件日志；发丝网格 + 微标签 |

**环境层（2026-10-31 修正：只约束功能，不预写画面）**：视觉身份元素只在环境与身份层使用——空屏/首启/控制塔可展示；工作空间低对比背景；编辑时自动降低存在感。**不预写具体视觉元素**：旧范式的具象视觉元素不进入新范式；环境的具体语言（光/雾/材质/地面/纵深）由施工方创造，这里只给功能约束：低对比、有纵深、不抢内容。**空间化视觉负责灵魂，工作画布负责完成事情。**

**参考**：owner 会给一组外部参考页（运营指挥中心、任务控制中心、智能体编队、工程仪表盘、爆炸图工作台、3D 空间叙事等）。请研究其语言，不复制素材/品牌/单页构图。共同语法：近单色底 + 唯一饱和信号色；微型等宽标签；发丝网格不是卡片堆；中央空间面 + 四周数据面；右侧检查器；时间维一等公民；动态全部是诊断性的。**这些语法主要用在控制塔与环境层，不要硬搬到工作空间首屏。**

**反范式**：劣质卡网 / 纯装饰科幻 / 低密度大留白 / "他"中心显影 / 静态仪表盘 / 首屏场景秀 / 把工作画布做成聊天窗口复制品。

### §4.5 动效纪律（六条；每条都来自一次"被打回"）

1. **有因有果**：观众要看到"原因"（点击/状态变化/数据到达），不能只看到结果；
2. **连续，不替换**：状态 A→B 之间必须有元素存活并移动/形变；
3. **不要节拍器**：不要匀速旋转/呼吸；有停顿、冲刺、漂移；静止段让爆发成立；
4. **环境层动效是底噪**：只在任务运行/状态变化时点亮，平时让位工作画布；
5. **token 化**：时长/缓动来自令牌；`prefers-reduced-motion` 有完整降级；
6. **可追责**：D5 列动效清单（谁触发/状态/时长缓动/降级）。

### §4.6 全息基地（控制塔，单独一页，一次交互进入）

- 形态 D：城式基地 + 三层轨道环（记忆/编排/能力）+ 治理闸门环；基地不转、环不均匀旋转；形象层可替换。
- 解剖：中央光核塔 / 三区街区 / 街道高架（数据流）/ 泊位（agent）/ 三层环 / 闸门环 / 外围微面板。
- 状态映射：负载=街区亮度密度；健康=颜色；队列=街道排队光点；吞吐=流光速度；治理=闸门环；异常=局部脉冲+日志行。
- 环境：由施工方创造（低对比、有纵深、明暗两套；基地是画面唯一亮物）；不沿用旧范式具象元素。
- 交互：只"看 + 选"（点选/双击/拖视角/滚轮/右键菜单）；写操作走控制塔固定面。
- 降级：reduced-motion/低性能 → 静态 2.5D 侧视图；再低 → 平面分区图。

### §4.7 轨迹视图（控制塔内，时间视图）

事件账本（按轮次分组/状态/摘要）+ 时间概览（真实时间×耗时投影、拖选过滤、缩放）+ 记录检查器（token/耗时/输入输出/计时/图片）。流式跟随尾部、向上滚暂停；长历史虚拟化。

## §5 要做的界面（三空间 × 明暗 + 全息基地 = 8 张）

### 屏 1 · 工作空间（默认首屏）

- 左栏：新建/最近工作/文件/项目/应用空间入口/收藏。
- 中央：**可变工作画布**（首轮 3 种：对话/文档/图像；数据/代码/任务流给结构说明）。
  - **文档画布**：单人和他的 agent 一起改一份工作——AI 修改→变更列表→差异→[接受][拒绝][回退]；建议锚定选区/段落；版本节点可见；不做多人协作。
  - **图像画布**：画布/图层/选区 + AI 建议说明（改哪层/影响哪/工具/未变/是否批准）+ 操作差异与版本节点。
- 右栏：**AI 协作栏**（当前目标/正在处理的文件/AI 正在做什么/建议/待确认/已完成/版本与差异/撤销回退/权限范围）。
- 底部：命令输入条 + 轻量状态。
- 空态：开始一个工作（输入/拖入），不铺假数据。

### 屏 2 · 应用空间

- 工作内应用空间（**C = 完整工作流**）：文档（工具栏/样式/表格/版本节点 + AI 修改→差异→接受/拒绝/回退）、图像（画布/图层/选区/画笔/调色/滤镜 + AI 建议卡 + before/after + 版本节点）、浏览器（页面视图 + 引用到当前工作 + 资料夹）、终端（命令输入 + 输出流 + 多标签）；四者共享同一工作上下文（选区/文件/版本）。
- **边界**：这是界面与交互形状的完整设计（状态齐全、可演示），不是真实文件引擎；工具行为可 mock 并显式标注（0 装）。
- 应用 chrome 极简；环境层最低。

### 屏 3 · 控制塔

- 进入：**A+B（owner 2026-10-31 拍板）**——右上角低存在感入口（有告警时金点亮）+ 0.6s 转场 + `Esc` 返回 + `Ctrl/Cmd+Shift+T` + 首次一次性引导；退出回工作空间原视图位置。
- 中央：全息基地（单独一页/子视图）；左：Agent/任务；右：agent 检查器 + 告警；底部：事件日志 + 轨迹入口 + LIVE；顶部：遥测。
- 轨迹视图、审批（金色闸门 + 待签文书卡）、系统状态（Provider/资源/Trace/后台任务/错误/文件锁）。

### 每屏状态

默认 / 选中 / 告警 / 空态 / 加载 / 错误 / 权限不足（至少前 5 种）；mock 显式标注；工作画布的 AI 建议有"锚点/差异/接受拒绝"的形状。

## §7 硬约束（是底线，不是能力上限）

1. **首屏 = 工作空间**；控制塔不是首屏，必须一次用户交互进入。
2. **无预设"他"**；明暗两套都精细、独立成立。
3. **0 装**：mock 显式标注；动效有状态来源；空态写数据契约；AI 建议可追溯（锚点/差异）。
4. 不做游戏机制（等级/成就/积分），只做视觉层密度与动态。
5. 不做营销落地页 / 单页概念站。
6. **可读性优先**；工作画布是焦点，环境层不抢戏。
7. **无障碍基线**：对比度、键盘可达、`prefers-reduced-motion`。
8. **版权**：参考页只取语言；不复制素材/Logo/品牌字体；自产或可商用素材并署名。
9. **性能**：交互流畅（目标 60fps）；重效果要有降级。
10. **范围**：不接后端、不接生产仓库；交付物交给 owner。
11. **令牌按语义**；**一个主题一个真源**（禁硬编码 hex/px/ms）；**交互件八状态**。
12. **全界面唯一饱和信号色**（金 = 系统信号/能量）。
13. **反 slop 清单**：等重卡片横排/全居中/重复左文右图；标题只是加粗正文；每个盒子都投影；纯黑 on 纯白；emoji 当图标；单侧彩色边框；营销填充词与假标签；lorem/Placeholder/"No data"。
14. **内容经得起压力**：长字符串、空列表、一条、四十条、九位数、缺图；错误态给修复。
15. **决策层级**：用户需求 > 无障碍 > 一致性 > 美学 > 开发体验。
16. **观察与操作分离**：基地只看 + 选；写操作走固定面（命令条/检查器/待签卡/工作画布）。
17. **底栏（控制塔）不常驻时间轴**：事件日志 + 轨迹入口 + LIVE。
18. **环境层纪律**：只约束功能（低对比、有纵深、不抢内容、明暗两套）；具体视觉语言由施工方创造；旧范式具象元素不进入新范式。
19. **指挥授权**：leader 默认全部权限（改任务/代批/治理链），权限可在设置里预设/收回；检查器显示权限范围。
20. **接入**：provider 模板与当前运行环境目录一致（含任意 OpenAI 兼容本地端点）；提供商行 + API Key + 模型列表。
21. **信号色**：具体值由施工方定；验收看对比度与"唯一饱和色"纪律。
22. **桌面优先、完全响应式**：1280/1440/1920 三档 + 窄窗重排；不要求移动端 UI。
23. **应用空间 = C**：文档/图像/浏览器/终端四个工作流的界面形状完整；工具行为可 mock 但需显式标注（0 装）。
24. **控制塔进入 = A+B**：常驻入口 + 0.6s 转场 + `Esc` + `Ctrl/Cmd+Shift+T` + 首次引导；控制塔即此前设计的"系统中枢"屏。
25. **旧范式一律不汲取**：新范式不继承旧范式手法；旧清单仅作未采纳记录。
