# 融合三笔的**裁决记录**：A1 ✅ · A2 ✅ · **A3 ❌（实测 NO-GO）**：**外加一条泛化教训**

> **背景**：[`memory-fusion-gap-2026-11-05.md`](./memory-fusion-gap-2026-11-05.md) 提了选项 A（接 5 个零件进融合链）。
> **本文件**记录执行结果：**三个都做了测量**，**两个接线、一个不接**，**不接的那个才是这份文件的价值**。

## 一、**先说结论（三行）**

| 笔 | 做什么 | 实测结果 | 裁决 |
|---|---|---|---|
| **A1** | **联想召回通道**（第三条召回路） | 接通 + **查表键修正**（否则空接线） | ✅ **接线** |
| **A2** | **时间锚点对图事实生效**（双时态） | 接线前**问过去、答现在**（答非所问） | ✅ **接线** |
| **A3** | **`signal_sources` 接进运行时** | ⚠️ **实测：接进去会降召回 −0.09 ~ −0.30** | ❌ **不接** |

## 二、**A3 的实测证据（为什么「不接」）**

跑 `cargo run -p apeireth-memory --example signal_source_report`（真实语料：红楼梦 + 水浒传，k=10，248 题）：

| 来源 | recall@10 | 相对基线 |
|---|---|---|
| **基线（原题面）** | **0.6875** | — |
| 同主题历史 | 0.4819 | **−0.2056** |
| 实体共现 | 0.3871 | **−0.3004** |
| 时间锚 | 0.6875 | **+0.0000**（**出词 0 题**：题面逐字未改）|
| 段落首句 | 0.6008 | **−0.0867** |
| 原文首句 | 0.5968 | **−0.0907** |

**没有来源真提升 recall**（最优也只是持平，其余全负）
**把它们接进运行时 = 降召回**，**A3 判「不接」**。

### ⚠️ **这份数字的可比性（读之前必须知道）**
- 这些来源**不含答案信息**，与 W-30 的 **oracle 上界**（答案侧信号，0.6113）**不可直接比**；
- 本批题是**从记录里挖出来的**（主体 = 该记录的最高频实体），「原文首句 / 段落首句」
  两行含**数据集构造红利**，**不等于**真实用户提问的收益；
- **结论仍然是可用的**：**在内部卷上，所有非答案侧信号都救不了召回**。

## 三、⭐ **但 A3 逼出了真正值钱的东西：一条泛化教训**

⭐ **「信号不能拼进一个查询」** —— 这是 A3 的真正产出：

- **BM25 是逐词累加**（无查询长度归一化），把信号**拼进一个查询**
  「匹配到的同义/聚类词多」的文档会**累出更高分**
  **拼进去 = 稀释 + 噪声**（实测 −0.09 ~ −0.30）；
- ⭐ **生产运行时为什么没这个毛病**（实测确认）：
  它把扩展查询作为**独立召回**跑，再**按 id 并集**（取更高分）
  **不稀释**，这正是 A1（联想通道）采用的结构。

**所以「融合」在召回面的正确形态是**：

> **每个信号占一条独立通道，候选并集，统一打分**
> **不是「把更多算法塞进一个打分器」，也不是「把更多词塞进一个查询」。**

**A1 的结构因此有了实测支撑**（不是「我觉得对」，是「另一种形态实测是负的」）。

## 四、**A1 的两次修正（都是自查抓到的）**

### ① **「塞进候选列表」是错的**
第一版把联想候选混进 `collect_candidates`，**测试红了**，查出来：
**召回链的唯一入口是 `sources`**，混进 `candidates` 只会变成 **BM25 的输入**
**联想信号会被词面相似度重排掉**，**必须做成独立通道**。

### ② ⭐ **查表键错了（更致命：等于空接线）**
联想边的键 = **实体名**（写入侧从内容里的 `associate:<实体> <实体>` 标记抽）
而我第一版拿**整个问句**当键去查，**键对不上**
**通道几乎永不触发**（接了等于没接）。
**修法**：用**问句实词**当键（与写入侧 marker **同源同口径**），多键查表（上限 4）。

**教训（已写进本线纪律）**：
> **「接上一条通道」不等于「它会触发」**，**必须回头核对「键」**
> **写侧用什么键，读侧就得用什么键**。

## 五、**A2 的实测与修正**

- **接线前**：`KnowledgeGraphStore::facts_from` 的实现**硬编码 `now`**
  带 `as_of_ms`（时间锚点，例「3年前」）的召回，**问过去、答现在**，**答非所问**；
- **修法**：trait 加 `facts_from_as_of`（默认实现 + **sqlite 真 SQL 覆写**）
  区间判据 `fact_valid_at` 与 `bitemporal_graph` 的 **valid-time** 口径**一致**；
- ⚠️ **一处既有的行为修正（明写）**：多了一个 `valid_from_ms <= ?2`
  **「未来才生效」的事实不再出现在「现在」的查询里**（原先会漏出来，那是 bug）。

## 六、⭐ **B：「不许不涨」的尺子（顺带发现的更大问题）**

### ⚠️ **发现：CI 闸门量的是「单路 BM25」，不是生产的「多通道 + 统一打分」**
- `scripts/check_golden_baseline.py`，调 `golden_baseline_report`，它调 `golden_run::run`
  而 `run` **直接调 `Bm25LexicalCandidateSource::candidates`**
  **不经过管线、不经过 coordinator**
  **通道级改动（加通道 / 加 as-of / 换融合配方）在闸门上完全看不见**
  **「不许变差」的纪律对通道级改动是失效的**。

###：**补的装置**
1. `golden_run::run_with_extra_sources(...)`：**同一份考卷跑两遍**（单路 vs 多路）
   额外源与 BM25 **并联**（同 id 取更高分），与生产同结构；
   `run` 委托给它（`&[]`），**既有闸门行为一字不变**；
2. `examples/fusion_channel_report.rs`：**A/B 报告**（一行 JSON，机器读）；
3. `scripts/check_memory_reachability.py`：**可达性**那一半的尺子
   A1 落地后 **69 → 70**，**新通道「接上了」这件事本身是可测的**。

###：**尺子的两半（诚实版）**
| 判据 | 量什么 | 状态 |
|---|---|---|
| **R1 可达** | 新能力**在不在生产链路上** | ✅ **机器可测**（可达率 69 → 70）|
| **R2 有效** | 新通道**涨不涨召回** | ⚠️ **代理指标**（内部卷题是挖出来的，对「词面不像但该在场」的通道**天然不利**），**delta 是下界** |

**诚实标注**：**内部卷**能证明「**没有害**」，**不能证明「有大用**」。

## 七、**我这轮学到的（比结论更重要）**

1. ⭐ **「接上」≠「触发」**，必须核对**键**（A1 修正 ②）；
2. ⭐ **「放进候选列表」≠「成为通道」**，召回链的唯一入口是 `sources`（A1 修正 ①）；
3. ⭐ **信号必须走独立通道**，拼进查询会稀释（实测负），通道结构有实测支撑；
4. ⭐ **「不许变差」的闸门量错了层**，量的是单路 BM25，通道级改动看不见
   **尺子要分层**：可达性（可测）+ 效果（代理）；
5. ⭐ **验牙步骤本身也要被验证**（A2：第一次「验牙没红」其实是**验牙代码没生效**）。

## 八、**后续选项（给 owner / 总指挥拍板）**

### 选项 A：**就这样**（A1 + A2 接线，A3 不接）—— **我建议**
A1/A2 都是**修「答非所问」类缺陷**（不是加功能），收益确定、风险低；
A3 有实测依据不接，**不接比接好**；
**我的建议 A**（，并按 §六 把 R1 可达性闸门并进 CI，R2 作为**报告**存在）。

### 选项 B：**A + 把内部卷升级成「通道公平考卷」**
给内部卷**补一批「词面不像但该在场」的题**（人工或从真实日志挖）
R2 才能从「代理」升级为「公平尺子」
代价：**要语料 + 要人工**（，我这边无独立语料来源，需协调）。

### 选项 C：**A + 让「不许不涨」成为硬门禁**
即：**任何新通道若 recall 不涨，闸门红**
⚠️ **我不建议现在做**：R2 是代理指标（内部卷对联想通道天然不利）
拿它当硬门禁，**会把正确的改动也拦下来**
**先做选项 B（把尺子修准），再考虑 C（把尺子变硬）**。

### 选项 D：**先做 A4/C（校准 + 行为反馈），融合通道的接线等 v3**
若 v3 要重设计召回面，A1/A2 的结构可能被重做
**但 A1/A2 修的是「答非所问」的缺陷**，**缺陷不会因为重设计而消失**
**：我建议不选 D**（缺陷先修，重设计时带着修好的地基去）。
