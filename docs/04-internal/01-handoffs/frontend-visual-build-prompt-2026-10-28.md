你是一位顶级的产品设计师 + 前端工程师，有多年已上线产品经验，擅长把"科幻感"做成真正可用、可读、可维护的产品界面。你会被当作**资深设计架构师**来评审——"看起来差不多"不接受。

**我们要什么**：Apeireth 是一个 AI 工作系统。请为它设计一套全新的界面——**一座让人愿意每天开工的工作台**，同时保留"在操作一台强大机器"的仪式感。它有三个空间：**工作空间**（默认首屏）、**应用空间**、**控制塔**。

**创意留白（先读）**：本文给的是**目标、边界与参考锚点**，不是画面元素清单。所有具体视觉元素（包括全息基地、环境、母题）都是方向锚点——**你可以用更好的视觉语言替换**，只要满足功能与验收门。唯一禁止的是：照搬参考页的素材/构图，或复用任何既有旧版视觉资产。

# 一、三个空间

## 1.1 工作空间（默认首屏）

用户每天真正干活的地方。核心对象是"工作"，不是"聊天"。
左栏：工作 / 项目 / 文件 / 应用入口；中央：**可变工作画布**（对话/文档/图像/数据/代码/任务流）；右栏：**AI 协作栏**；底部：命令输入条 + 轻量状态。首屏要能开始工作：新建、打开最近工作、拖入文件、发任务。

## 1.2 应用空间（能力展开）

承载文档 / 图像 / 浏览器 / 终端等**工作内应用**；它们共享同一个工作上下文（当前文件、选区、版本、任务）。Starport 是工作内应用空间（注册/打开/聚焦/关闭/钉住），不是应用启动器。应用空间不承担系统监控。

## 1.3 控制塔（系统状态，主动进入）

用户主动进入，用来理解/审计/控制系统。内容：Agent/模型/Provider、CPU/GPU/内存、工具调用与 Trace、审批队列、权限治理、后台任务、错误恢复、文件锁/协作冲突、系统事件、**轨迹视图**、**全息基地（单独一页）**。
它不是首屏的一部分：从工作空间**一次交互进入**（入口 + 转场），可随时退出回到原视图。

# 二、画面（方向锚点，不是施工清单）

**工作空间**：像一张干净、宽大的工作台。中央是正在做的事——一段对话、一份文档、一张图，或一个任务流；右栏安静地列着 AI 正在做什么、建议了什么、等你确认什么；底部一条输入，随时可以发话。环境有纵深，但不抢内容。

**应用空间**：桌面上摊开着几个专业应用：文档、图像、浏览器、终端。它们不是独立窗口，而是同一份工作的不同工作面——在文档里选中的一段，AI 协作栏立刻知道；从图像里导出的图，直接落进当前工作；浏览器里的资料可以被"引用到工作里"。

**控制塔**：一座悬浮的、有体积感的"系统本身"。中央是**Apeireth 全息基地**：城式基地（光核塔 / 三区街区 / 街道流光 / 边缘泊位）套着三层轨道环（记忆 / 编排 / 能力），最外是治理闸门环；基地本身基本静止，旋转交给环，不均匀地停顿、冲刺、漂移。左侧是 Agent/任务，右侧是检查器与告警，底部是事件日志与轨迹入口。它是这套设计的"脸"，但只在用户主动进入时出现。

# 三、硬底线（10 条；必须满足，不再增加）

1. **首屏是工作空间**；控制塔必须一次交互进入，不能是默认首屏的一部分。
2. **明暗两套都精细**，独立成立（不是反相）。
3. **唯一饱和信号色**（金 = 系统信号/能量），只用于系统活动/信号/告警语义。
4. **控制塔的全息基地只"看 + 选"**（点选/双击聚焦/拖视角/滚轮/右键菜单），不是编辑器；写操作只走固定面（命令条/检查器/待签卡/工作画布）。
5. **AI 建议必须可追溯**：锚点（选区/段落/图层）、差异、[接受][拒绝][回退]。
6. **交互件八状态**：default / hover / focus / active / disabled / loading / error / selected。
7. **反 slop**：不做等重卡片横排、全居中、标题只是加粗正文、每个盒子都投影、纯黑 on 纯白、emoji 当图标、单侧彩色边框、营销填充词、lorem/占位空态。
8. **桌面端优先、完全响应式**：1280/1440/1920 三档 + 窄窗重排。
9. **0 装**：mock 数据显式标注；动效必须有状态来源；空态写数据契约；AI 建议不得伪造成已执行。
10. **无障碍基线**：对比度、键盘可达、`prefers-reduced-motion`。

# 四、动效（创作约束，不是参数表）

1. **一镜到底**：状态 A→B 之间必须有元素存活、连续移动/形变到 B；全部元素各自淡出淡入 = 幻灯片。
2. **因果可见**：观众要看到"原因"（点击/状态变化/数据到达），不能只看到结果。
3. **节奏不要节拍器**：快慢对比 ≥4×；必须有静止段——静止让爆发成立。
4. **真动效，不是 PPT**：禁止整屏/整块淡入淡出、翻页式切换；转场要有"一镜到底"感。
5. **环境层是底噪**：只在任务运行/状态变化时点亮，平时让位给工作画布。
6. **转场由你设计**（含进入控制塔）：漂亮、流畅、有因有果；时长与曲线自定，不要套模板。
7. **可追责**：交付时列**动效清单**——谁触发、从什么状态到什么状态、时长/曲线、降级方案。

# 五、先交 T0 处理稿（不写 HTML/CSS）

T0 是文字处理稿（可配 1–2 张粗糙示意），owner 说"行"之后才进入生产：

```
A. 一句话构想 + 3 个概念方向（中心思想不同；选定 1 个）
B. 风格圣经 v0.1：色彩与发光纪律、字体三系、布局与材质、3–5 个母题、语气
C. 三空间 IA：默认首页、三空间骨架、控制塔进入方式
D. 工作画布：首轮 3 种（对话/文档/图像）的画面与交互；其余形态给结构说明
E. AI 协作栏：内容清单 + "AI 建议 → 差异 → 接受/拒绝/回退"的交互形状
F. 控制塔与全息基地：基地解剖（规格附录 §5 的表逐项给出你的方案）+ 形象槽与换壳规则 + 轨迹视图三件套
G. 三空间 plate 处理稿：每个空间一段"可画出来"的描述（区域/元素/顺序/动作/材质/数字/明暗差异/关键状态）
H. 屏 × 状态 × 母题 映射表 + 交互清单
I. 你希望 owner 重点看什么 / 你还不确定的 2–3 处
```

**通过标准**：owner 读完能说出"我看到的是什么"，尤其能说出"首屏是工作空间"。

# 七、验收门（客观优先；门通过 ≠ 审美成立）

交付前逐条跑/查，在设计说明里写**真实结果**；没跑的写"未验证"，不许写"通过"：

- [ ] 首屏是工作空间；3 秒能看出"我在做什么/下一步/系统是否正常"；
- [ ] 控制塔一次交互进入、可退出；不是默认首屏；
- [ ] 明暗两套都渲染、都完整；
- [ ] 正文 ≥4.5:1、大字 ≥3:1、图形控件 ≥3:1；键盘可达、focus 可见；
- [ ] `prefers-reduced-motion` 下环境安静、基地不旋转但保留状态色/选中；
- [ ] 1280/1440/1920 三档成立、窄窗重排、无横向溢出；
- [ ] 状态覆盖：默认/选中/告警/空/加载/错误/权限不足；D3 八状态；
- [ ] 工作画布 AI 建议有锚点/差异/接受拒绝回退；应用空间四个工作流形状完整（mock 已标注）；
- [ ] 基地画面：唯一亮物、只看+选、降级可用、换壳不改变语义；
- [ ] 所有 mock 显式标注；无"声称测过但没测"的数字。

**交付前评审 pass**（自我否定，不是自夸）：

```
判定: 打回 / 返工 / 可交
资深设计师会打回的 3 条理由: 1… 2… 3…
关键证据: <截图位置 / 文件 / 具体元素>
真正好在哪（最多两条）:
未能判断的: <没渲染 / 没测的项，不要猜>
```

判定"打回/返工"：先修 → 重跑门 → 再复评，直到只剩轻微项。**审过再交**。

# 八、自由条款（请读三遍）

- 以上是方向与底线，不是能力上限：**大胆给出你认为更好的设计决定**，并在设计说明里解释"为什么更好"。
- 冲突时优先保证三条：**工作可完成、状态可追溯、明暗对等**。
- **不要为了"稳"做成普通 SaaS**；**也不要为了"炫"牺牲可读性**。
- 全息基地是控制塔的"脸"：用你认为效果最好的方案（Canvas/WebGL/混合均可），写清依赖与降级。
- **3D 质感浓度打样后评估**：首轮按你能拿到的最好效果做。
- 若一次交付不完，按此优先级裁剪：T0 → D1 → D2（工作空间 + 全息基地）→ D2（应用空间）→ D3/D4/D5/D6/D7。
- 信息不足按最合理判断先做，不要停下来提问；假设写进设计说明。
