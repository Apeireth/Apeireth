### 〇.2 🎯 **因果验证：送达率由「单元 vs 注入窗口」决定**

同一批题 × 五档粒度（唯一变量 = 粒度）：

⇒ ⇒ **「单元越大 ⇒ 送达率越低」单调成立**（水滸傳 1 处反向，已如实记录）
⇒ ⇒ **但切分是净亏**（`recall` 0.2983 → **0.0347**）。

### 〇.3 ⚠️ **修正 §三 否证 #1（切分粒度）的理由**

下文写「段落化在 L1 与 L2 上都伤」⇒ ⇒ **理由不完整**：
旧 A/B 的「段落 300」**仍然 > 注入窗口 120 字**，答案在 60% 深度（180 字）**必然被截**
⇒ ⇒ 那个 0.0364 反映的是「**仍然超出窗口**」，不是「段落化本身伤送达」。

**修正后的正确表述**：
```
单元 ≫ 注入窗口  ⇒ 截断损失大（0.31 ~ 0.69）
单元 ≤ 注入窗口  ⇒ 无截断损失（≥1，LoCoMo 实测 1.0000）
```
⇒ ⇒ **结论仍然不变**（**别切分**），但**理由换成**：「切分换不来净收益」
（送达↑ 但 `recall` 崩塌）。
