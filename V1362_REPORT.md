## What V1362 ships

### 1. `apeireth/v1362_pole_star_history.py` (~18 KB)

A self-contained module that supports CLI execution:

```
# CLI subcommands
python -m apeireth.v1362_pole_star_history record [--tag <label>]
python -m apeireth.v1362_pole_star_history show [--limit N]
python -m apeireth.v1362_pole_star_history trend [--window N]
python -m apeireth.v1362_pole_star_history self-test [--verbose]
python -m apeireth.v1362_pole_star_history version
```

**Storage:** `pole_star_history.jsonl` at repo root (append-only).
Each line is a complete record with: `measured_at`, `pole_star_total`,
`pole_star_cap`, `pole_star_delta_vs_v01`, `toolchain_present`,
`toolchain_total`, `close_loop_pass`, `close_loop_total`, `v_modules`,
`test_files`, optional `tag`.

**Trend calculation:**
- `newest_avg`: moving average of last `window` entries' `pole_star_total`
- `oldest_avg`: moving average of first `window` entries' `pole_star_total`
- `delta`: `newest_avg - oldest_avg`
- Smart window handling: if `2*window > n_entries`, splits in half instead
  of overlapping

## Known unknowns / honest disclosure

- **History is one JSONL line per record.** No batching, no compression.
  At ~280 bytes per entry, the file grows slowly (~100KB/year at 1
  entry/day). V1362 does NOT auto-rotate; rotation is a manual
  operator decision.
- **Trend is a moving average of `pole_star_total`, which is itself
  already capped.** A small delta in trend reflects changes in the
  components below the cap, NOT movement toward ASI. The V3 守门 text
  in `trend --window N` output makes this explicit.
- **No new dependency.** V1362 reuses V1357 + stdlib only.
- **Window-overlap handling.** When `2*window > n_entries`, the trend
  function splits entries in half instead of letting `early` and
  `recent` windows overlap. This avoids the "delta is always 0" trap.
  Verified by `test_trend_two_entries`.
- **The 3 seed entries in pole_star_history.jsonl** are from V1362
  self-test runs. They are honest (real measurements, not fabricated).
  An operator may delete them with `trash pole_star_history.jsonl` to
  start fresh; V1362 will recreate on next `record`.
