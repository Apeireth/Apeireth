# apeireth-tui — 终端驾驶舱 (P2)

纯 Rust 全屏 TUI 客户端 (重度用户操控台), 连既有 gateway/CLI 后端。与桌面端
共用同一后端数据面 (一套语义两处上屏), 会话/治理/执行语义全部留在后端, 本包
只做呈现与转发 (0 重复实现)。

P2 增量: 右栏遥测面板组 (伙伴的内在遥测) + 渲染层动态效果 (波形走纸 /
呼吸辉光 / 大数字闪烁 / 治理灯渐入) + 重绘纪律 (≤5fps 动画预算, 空闲近零
CPU)。数据诚实纪律: 没数据 = 显式 "—" / 暗格, 未接线数据源显式标注。

## 启动说明

前置: 先起既有后端 (本机回环, 缺省端口 8080):

```
cargo run -p apeireth-cli -- gateway serve
```

一条命令启动全屏驾驶舱 (任选其一):

```
cargo run -p apeireth-tui
cargo run -p apeireth-tui -- --endpoint http://127.0.0.1:8080
cargo install --path crates/adapters/tui && apeireth-tui.exe
```

启动即探活: 后端连不上也第一帧上屏错误卡 (LINK DOWN + 连接失败帧, 不白屏)。

| 环境变量 / 参数 | 含义 | 缺省 |
|---|---|---|
| `APEIRETH_GATEWAY_URL` / `--endpoint` | 后端端点 | `http://127.0.0.1:8080` |
| `APEIRETH_TUI_MOTION` / `--motion` | 动效档 `full` / `reduced` (减少动态档关闭扫描线/呼吸光/跳动数字/转动指示/波形走纸/闪烁/灯渐入) | `full` |
| `--help` | 用法 | — |

- 面板 1 (左/中): 流式 Markdown (代码高亮 + 工具卡片: 工具名 + 状态徽章 + 耗时) + 多会话页签;
- 面板 2 (底): 上下文用量条 / token 计数 / 回合耗时 / 缓存命中率 / 活动指示;
  缓存命中率在既有接口无字段时显示 "—" (诚实占位, 不猜不装);
- 右栏遥测面板组 (P2, 每面板右上角小字副标签语法):
  - `LEDGER · {n} 库` 记忆账本点阵 —— 会话/记忆/保护/教训四行, 点阵格子语法
    每格 = 单位计数 (像内存点阵), 溢出标 `›` + 精确数字照给; `{n}` = 当前有
    真实计数的行数 (共 4 行);
  - `CACHE` 缓存命中率大数字仪表 —— 5 行像素块等宽大字, 新值到达亮度脉冲一帧;
  - `CTX · 128K` 上下文用量波形 —— 滚动 sparkline (`▁▂▃▅▇` 帧循环), 每动画
    帧走纸一格; 窗口未知角标签如实 `CTX · ?` (峰值归一, 只给相对形状);
  - `GOV` 治理事件灯阵 —— 最近 12 个治理判定按时间序点亮: 绿=放行 /
    琥珀=审批 / 红=拒绝, 新灯从暗到亮渐入; 无事件/未知判定 = 暗格 (不猜色);
- 面板 3 (右栏底部): 内部过程频道 —— P1 接口桩保留, 显式「未接线」标注,
  下批消费 events 面只读投影;
- 面板 4: 输入行 + `/` 命令补全浮层 + 会话管理命令 (上表);
- 面板 5: 时间倒带 (双 Esc / `/rewind`) —— 本批接口桩, 显式「未接线」标注;
- 面板 6: `?` 帮助浮层 (键位表 + 命令表), Ctrl+C 两段式退出。

## 动画清单 (效果 / 帧率 / reduced 行为)

全部动态效果都在渲染层逐帧循环, 不承载数据语义; 数据只来自下方接线表。

| 效果 | 节奏 | 触发 | `--motion reduced` 行为 |
|---|---|---|---|
| 波形滚动 (sparkline 走纸) | 每动画帧推进一格 (250ms ≈ 4fps, 落在 200-500ms 带内, 随 MOTION 档控制) | 动画帧 | 不走纸 (波形静止) |
| 呼吸辉光 (面板描边亮度) | 3.8s 正弦循环 (15 动画帧一周期, 亮度 1-15) | 动画帧 | 描边恒定基色 |
| 大数字变化闪烁 | 新值到达当帧亮度脉冲一帧 | 数据变化 | 恒定亮度 (不闪) |
| 治理灯渐入点亮 | 新灯 4 帧从暗到亮 | 数据变化 + 动画帧 | 瞬时点亮 |
| 扫描线 / 跳动数字 / 转动指示 (P1) | 动画帧 | 动画帧 | 全部关闭 |
| 重绘预算 | 动画帧 ≤5fps (`AnimClock` 帧间隔 ≥200ms 断言); 重绘只在数据变化或动画帧到点发生 | — | 无动画帧: 只在数据变化时重绘 (空闲近零 CPU) |
| 遥测数据轮询 | 5s (数据节奏, 不是动画节奏) | 计时 | 照常轮询 (数据拉取不受动效档影响) |

- 动画 tick 预算: `theme::AnimClock` full 档帧间隔 250ms —— 一秒 ≤5 帧,
  跳时不补帧 (防帧风暴); reduced 档 `interval = 0` 永不到点;
- 走纸语义: 波形新格取最近一次**真实采样** (保持式走纸, 如走纸记录仪);
  从未采样 = 显式 "—", **绝不画假曲线**。

## 数据源接线表 (P2)

数据源优先级 (诚实纪律): 网关自述 / 计数端点 → 本地读数据目录计数 → 显式
"—" 占位; 接不通的行/面板留桩并标注「未接线」, **禁止编数**。

| 面板 / 行 | 数据 | 来源 | 接线状态 |
|---|---|---|---|
| LEDGER · 会话 | 会话数 | `GET /v1/panel/sessions` 全量列表计数 | 已接 (计数端点, 真实总数) |
| LEDGER · 记忆 | 记忆件数 | `GET /v1/panel/memory/episodes?limit=500` 页内计数 | 条件接通: 页未满 = 页面全量 = 真实总数; 页满窗口饱和 → 显式 "—" (不冒充总数) |
| LEDGER · 保护 | 保护件数 | 同上 (显式 `protected: true` 计数) | 条件接通: 缺保护标记字段 → 显式 "—" (不猜) |
| LEDGER · 教训 | 教训数 | 自述探测口记忆账本计数 (反思沉淀教训) 未上 HTTP 契约 | 未接线 → "—" + 面板内「未接线」标注 |
| CACHE | 缓存命中率 | 回合计量 `cache_hit_rate` (既有契约暂无此字段) | 未接线 → "—"; 字段就绪即大数字 + 变化闪烁 |
| CTX | 上下文用量波形 | 回合计量 `total_tokens` 真实读数走纸; `context_window` 归一 | 已接; 窗口未知 → 峰值归一 + 角标签 `CTX · ?` |
| GOV | 治理判定灯阵 | `GET /v1/panel/safety/guard/events?limit=12` (`allow`/`require_approval`/`deny` → 绿/琥珀/红) | 已接; 未知判定不上灯 (不猜色); 端点缺 → 全暗格 + 备注 |
| 频道 PROCESS FEED | 内部过程事件流 | — | 未接线 (P1 桩保留, 下批接 events 面只读投影) |

回灌链路: 主循环 5s 轮询 (`Effect::RefreshTelemetry`, 数据节奏独立于动画
节奏) → 后端端口 `fetch_telemetry` (逐节诚实: 能探到的节给真数, 探不到的节
显式 `None` + 备注) → `Input::TelemetryLoaded` → 面板组; 连上后端即首拉,
回合计量 (`usage`) 另走真实读数采样 (缓存大数字 + 波形)。

sparkline 帧循环推进、呼吸辉光帧循环 (reduced 静态)、大数字闪烁一帧、
治理灯阵点亮序与渐入、角标签渲染、无数据诚实占位 (绝不画假曲线)、
动画 tick 预算 (≤5fps 断言)、记忆件计数窗口饱和诚实、治理判定三色映射。
