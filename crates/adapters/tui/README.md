# apeireth-tui — 终端驾驶舱 (P1)

纯 Rust 全屏 TUI 客户端 (重度用户操控台), 连既有 gateway/CLI 后端。与桌面端
共用同一后端数据面 (一套语义两处上屏), 会话/治理/执行语义全部留在后端, 本包
只做呈现与转发 (0 重复实现)。

## 启动说明

前置: 先起既有后端 (本机回环, 缺省端口 8080):

```
cargo run -p apeireth-cli -- gateway serve
```

一条命令启动全屏驾驶舱 (任选其一):

```
cargo run -p apeireth-tui
cargo run -p apeireth-tui -- --endpoint http://127.0.0.1:8080
cargo install --path crates/adapters/tui && apeireth-tui.exe
```

启动即探活: 后端连不上也第一帧上屏错误卡 (LINK DOWN + 连接失败帧, 不白屏)。

| 环境变量 / 参数 | 含义 | 缺省 |
|---|---|---|
| `APEIRETH_GATEWAY_URL` / `--endpoint` | 后端端点 | `http://127.0.0.1:8080` |
| `APEIRETH_TUI_MOTION` / `--motion` | 动效档 `full` / `reduced` (减少动态档关闭扫描线/呼吸光/跳动数字/转动指示) | `full` |
| `--help` | 用法 | — |

## 键位表

| 按键 | 动作 | 说明 |
|---|---|---|
| `/` | 打开命令行 | 带命令补全浮层 |
| `?` | 帮助浮层 | 键位表 + 命令表 |
| `Enter` | 发送 / 执行命令 | |
| `Esc` | 关闭浮层 / 退出命令行 | 命令行内清空输入 |
| `Esc Esc` | 时间倒带 | 回滚上一回合重新输入 (本批接口桩) |
| `Ctrl+C` | 两段式退出 | 第一段断流 (切断本地收流), 第二段退出 |
| `PgUp` / `PgDn` | 对话滚动 | |
| `Tab` | 命令补全 | 命令行内补全命令名 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换会话页签 | |
| `Backspace` | 删除输入 | |

## 命令表 (面板 4 会话管理)

| 命令 | 链路 | 状态 |
|---|---|---|
| `/new` | 新建会话页签 | 已接 |
| `/resume [会话id]` | 会话账本 → 绑定页签会话 | 已接 (账本端点) |
| `/model [模型]` | 模型列表 / 会话级热切换 (走既有会话设置链) | 已接 |
| `/export [路径]` | 会话记录 → Markdown 落盘 | 已接 (本地) |
| `/compact` | 命令链路形状已定 (mock 全程测试) | 既有网关暂无会话压缩端点: 上屏诚实「未接线」提示, 端点就绪即通 |
| `/rewind` | 时间倒带 (面板 5) | 接口桩: 显式「未接线」, 下批接 continuation / 会话 fork 确定性重放 |
| `/motion [full\|reduced]` | 动效档切换 | 已接 |
| `/help` | 帮助浮层 | 已接 |
| `/quit` | 退出驾驶舱 | 已接 |

```
│ └────────────────────────────┘              │  只读投影 (治理判定 /        │
│ ▰ 结果                                      │  工具调用 / 器官活动)        │
│ ▸ 完成                                      │  ░░░░░░░░░░░░░░░░ (扫描线)  │
│   ┌── code · rust                           │  ░░░░░░░░░░░░░░░░           │
│   fn done() { return 1; }                  │                              │
│   └── code ──                               │                              │
│ · 系统注记 (断流 / 连接失败 / 未接线提示)     │                              │
│ ▌ 等宽跳动数字与发光描边为驾驶舱氛围层        │                              │
└─────────────────────────────────────────────┴──────────────────────────────┘
▌ MSG ▸ 输入消息, 或 / 进入命令模式 ▍
LINK OK http://127.0.0.1:8080 │ MODEL demo │ CTX ▰▰▰▱▱▱▱▱ 12.3k/128k │ TOK ↑12.3k ↓4.6k │ TURN 3.2s │ CACHE — │ ◆ IDLE │ FLUX 1A2F │ MOTION FULL
└─ 面板 2 实时状态条 ─────────────────────────────────────────────────────────────────────────────┘
```

- 面板 1 (左/中): 流式 Markdown (代码高亮 + 工具卡片: 工具名 + 状态徽章 + 耗时) + 多会话页签;
- 面板 2 (底): 上下文用量条 / token 计数 / 回合耗时 / 缓存命中率 / 活动指示;
  缓存命中率在既有接口无字段时显示 "—" (诚实占位, 不猜不装);
- 面板 3 (右窄栏): 内部过程频道 —— 本批接口桩, 显式「未接线」标注;
- 面板 4: 输入行 + `/` 命令补全浮层 + 会话管理命令 (上表);
- 面板 5: 时间倒带 (双 Esc / `/rewind`) —— 本批接口桩, 显式「未接线」标注;
- 面板 6: `?` 帮助浮层 (键位表 + 命令表), Ctrl+C 两段式退出。
