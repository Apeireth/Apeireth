# apeireth-tool-fetch

> Apeireth R149 unified fetch engine: HTTP+search+deep+Bilibili+anime. 吸收 7 个 fetch/search plugins (UrlFetch+TavilySearch+AnySearch+VSearch+FlashDeepSearch+BilibiliFetch+AnimeFinder), 上升为 Rust 类型系统 + 多 provider 单 crate.

apeireth-tool-fetch 是 Apeireth 1.0 (AGI 操作系统) 工作区 crate 之一。完整架构见 [docs/](../../docs/README.md)。
