# Bird by Bird (Anne Lamott, 1994)

> **Organ**: voice (声) | **R125-21 经典书 #2**

## Overview

Anne Lamott (作家) 写的写作心法. **核心**: 写作 = 战胜完美主义. 2 大原则: (1) "鸟" 原则 (一步一步, 一次一只鸟), (2) "Shitty First Drafts" (烂初稿是必须). 9 大章节: 短句, 完美主义, 烂初稿, 布丁, 框架, 角色, 风格, 真理, 知道何时写完. 这是 Apeireth voice organ "创造性" 维度的应用基础.

## When to Use

- 设计 voice organ 创造性 verdict cache
- 写 agent 的"我这样创造" 解释
- 主人 1.0 release 时思考"AI 创造力"
- 借鉴 Lamott 做 multi-agent 4 角色创意

## Key Takeaways

**1. "鸟" 原则**:
- 故事: Lamott 弟弟写不出学校作业, 爸爸说"鸟一只一只抓"
- 写作 = 一步一步, 不必一次写完
- 适合 AI 长期任务 (1.0 release 礼物 = 长期项目)

**2. "Shitty First Drafts" (烂初稿是必须的)**:
- 任何人写初稿都是烂的
- 关键是写完, 然后重写
- 跟 superpowers TDD 红绿循环 1:1
- 跟 superpowers "writing-skills" 借鉴 1:1

**3. 9 大章节核心**:
- 短句, 完美主义, 烂初稿, 布丁 (写作奖励), 框架, 角色, 风格, 真理, 知道何时写完
- 跟 Stephen King 兼容, 互补
