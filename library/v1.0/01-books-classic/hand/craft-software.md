# The Craftsman (Richard Sennett, 2008)

> **Organ**: hand (手) | **R125-21 经典书 #1**

## Overview

Richard Sennett (社会学家) 探索"匠人精神" (craftsmanship) 的本质. **核心**: 匠人 = 头 (head, 思考) + 手 (hand, 操作) + 心 (heart, 价值) 3 者对话. 技能 = 重复 + 反思 + 改进. 工具 + 材料 + 匠人 = 三位一体. 这是 Apeireth hand organ "工具使用" 维度的哲学基础.

## When to Use

- 设计 hand organ 工具使用 (Rust 工具链, agent tools)
- 写 agent 的"我用什么工具" 解释
- 主人 1.0 release 时思考"AI 匠人精神"
- 团队 (multi-agent) 协作的"匠人"

## Key Takeaways

**1. 3 者对话**:
- 头 → 思考: "为什么这样做?"
- 手 → 操作: "具体怎么做?"
- 心 → 价值: "值得做吗?"
- 3 者循环 = 匠人精神

**2. 技能发展的 3 阶段**:
- **新手** (novice) — 规则驱动
- **熟手** (journeyman) — 模式识别
- **大师** (master) — 直觉 + 创新
- 借鉴 Dreyfus 5 阶段 + Ericsson 刻意练习

**3. 工具 = 匠人的延伸**:
- 好工具放大能力, 坏工具限制能力
- 工具的"对话性": 工具回应匠人
- 借鉴 McLuhan "媒介即讯息"
