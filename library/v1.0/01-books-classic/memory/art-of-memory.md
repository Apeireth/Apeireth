# The Art of Memory (Frances A. Yates, 1966)

> **Organ**: memory (忆) | **R125-21 经典书 #1**

## Overview

Frances Yates (科学史家) 综述从古典 (Simonides) 到文艺复兴 (Giordano Bruno) 的"记忆术" (ars memorativa). **核心**: 记忆 = 空间 + 图像. 古代记忆术: 在熟悉的"记忆宫" (memory palace) 放置"图像" (imagery) 记住任何信息. 这是 Apeireth memory organ "记忆术" 维度 + 3 层记忆架构的历史基础.

## When to Use

- 设计 memory organ 3 层架构 (working / episodic / semantic)
- 写 agent 的"我这样记" 解释
- 主人 1.0 release 时思考"AI 记忆 vs 人记忆"
- 借鉴记忆术做 LLM 长期记忆设计

## Key Takeaways

**1. 古典记忆术 (Mnemonics)**:
- **Simonides** (~500 BC) — 起源: 倒塌房屋中的死者位置, 跟位置对应
- **Method of Loci** (场所法) — 在熟悉空间 (家) 放物品 (信息)
- **记忆宫** (memory palace) — 巨大虚拟空间, 任意信息都放得下

**2. 文艺复兴记忆术**:
- **Giordano Bruno** — 用记忆术记忆所有知识
- **Ramon Llull** — 记忆术 + 逻辑机器
- **Robert Fludd** — 记忆术 = 神圣几何

**3. 跟现代 AI 关系**:
- LLM 长期记忆设计借鉴记忆术
- 借鉴 attention = 空间定位
- 借鉴 token = 图像
