# Make It Stick (Peter Brown, Henry Roediger, Mark McDaniel, 2014)

> **Organ**: memory (忆) | **R125-21 经典书 #3**

## Overview

3 位认知心理学家总结 10 年学习科学研究. **核心**: **被动阅读** (re-reading) **是低效学习**; 高效学习 6 策略: (1) 检索练习, (2) 间隔重复, (3) 交错练习, (4) 多样化练习, (5) 精细化, (6) 反思. 这是 Apeireth memory organ "学习科学" 维度的算法基础.

## When to Use

- 设计 memory organ 学习科学 verdict cache
- 写 agent 的"我这样学习" 解释
- 主人 1.0 release 时思考"AI 学习怎么学得更好"
- 借鉴 6 策略做 LLM 训练 + RAG 优化

## Key Takeaways

**1. 6 大高效学习策略**:
- **检索练习** (retrieval practice) — 测试 > 重读
- **间隔重复** (spacing) — 分散练习 > 集中练习
- **交错练习** (interleaving) — 混合 > 单一
- **多样化练习** (variation) — 多场景 > 单场景
- **精细化** (elaboration) — 联接已知
- **反思** (reflection) — 自我审视

**2. 错觉 (Illusions of Learning)**:
- **流畅性错觉** (fluency) — 易读 ≠ 记住了
- **熟悉性错觉** (familiarity) — 见过 ≠ 理解
- **测试错觉** (test illusion) — 觉得会 ≠ 真会

**3. 失败是好老师**:
- 失败 (retrieval failure) → 强化 (re-consolidation)
- 错答 + 反馈 > 直接给答案
- 借鉴 superpowers TDD 红绿循环
