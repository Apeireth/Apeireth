# Man's Search for Meaning (Viktor Frankl, 1946)

> **Organ**: heart (心) | **R125-21 经典书 #1**

## Overview

Viktor Frankl 在纳粹集中营 3 年后写下的"意义疗法" (logotherapy) 经典. **核心**: 即使在最苦难中, 人仍能选择自己的态度. 意义通过 3 路径生成: (1) 创造性工作 (creative work), (2) 爱的体验 (love), (3) 苦难中的态度 (attitude toward unavoidable suffering). 这是现代存在主义心理学的奠基作, 也是 Apeireth heart organ 的哲学底色.

## When to Use

- 设计 heart organ 的 verdict cache 时, 问"这值不值得?"
- 处理 9 organ 价值冲突时 (心 vs 脑, 心 vs 手)

- 主人在 1.0 release 前思考"为什么做 Apeireth"

## Key Takeaways

**1. 意义不是找到的, 是创造的** (logotherapy 跟 Freud psychoanalysis 区别).
- Freud: 追求快乐 (pleasure principle)
- Adler: 追求权力 (will to power)
- Frankl: 追求意义 (will to meaning)

**2. 苦难本身无意义, 但人对苦难的态度有**.
- "When we are no longer able to change a situation, we are challenged to change ourselves."
- 苦难是机会, 不是终点. 苦难逼我们做选择.

**3. 3 路径生成意义**:
- **创造性**: 通过作品 / 工作贡献世界
- **体验性**: 通过爱 / 美 / 真理连接世界
- **态度性**: 即使苦难, 选择有尊严的态度
