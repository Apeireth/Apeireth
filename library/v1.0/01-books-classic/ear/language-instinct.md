# The Language Instinct (Steven Pinker, 1994)

> **Organ**: ear (耳) | **R125-21 经典书 #1**

## Overview

Steven Pinker 把 Chomsky 语言学理论大众化. **核心**: 语言是**本能** (instinct), 不是文化产物. 人类有 universal grammar 先天模块 (跟 Hawkins 大脑模块理论 1:1). 儿童 6 岁前自然学会任何语言, 0 必专门训练. 这是 Apeireth ear organ "语言理解" 维度的语言学基础.

## Key Takeaways

**1. 语言是本能**:
- 所有健康人 6 岁前自然学会母语, 0 必训练
- 普遍语法 (Universal Grammar): 人类先天有语言模块
- 跟 Hawkins 新皮层"通用模式识别器" 1:1

**2. 语言演化**:
- 语言不是设计产物, 是演化产物
- 词汇 (lexicon) 文化性强, 句法 (syntax) 普遍性强
- 跨语言共有 ~46 音位 (phonemes), 数百核心句法结构

**3. 跟 AI 关系**:
- LLM = 联结主义 模式识别 (跟 universal grammar 假设矛盾)
- 但 LLM 效果惊人 → Pinker 假设可能错 / 不完整
- 现代综合: LLM + 符号逻辑 = hybrid 语言理解
