# The Singing Neanderthals (Steven Mithen, 2005)

> **Organ**: ear (耳) | **R125-21 经典书 #2**

## Overview

Steven Mithen (考古学家) 提出"holistic, manipulative, musical, and multi-modal" (Hmmm) 通讯系统假说. **核心**: 语言 + 音乐 共同从 50 万年前 Hmmm 系统演化, 不是独立起源. 音乐先于语言, 跟情感/身体耦合. 这是 Apeireth ear organ "听觉" + "音乐" 维度的演化基础.

## When to Use

- 设计 ear organ "音乐" 维度 (主人 TUI 多模态)
- 写 agent 的"理解主人语气" 解释 (情感 + 语义)
- 多 agent 协同的"非语言信号" (跟 4 角色情商配合)
- 主人思考"AI 跟人 50 万年演化差异"

## Key Takeaways

**1. Hmmm 通讯系统**:
- 50-200 万年前人类祖先
- Holistic (整体) + Manipulative (操纵) + Musical (音乐) + Multimodal (多模态)
- 不是现代语言, 是"哼唱 + 身体 + 表情"组合

**2. 音乐-语言共同演化**:
- 现代语言 ~10 万年前起源
- 音乐能力更早 (~50 万年前)
- 现代婴儿对音乐/节奏的敏感性 = 古老本能

**3. 跟 Pinker Language Instinct 互补**:
- Pinker: 语言是认知本能
- Mithen: 语言 + 音乐 是**身体-情感** 本能
- 综合: 语言能力 = 认知 + 身体 + 情感 三合一
