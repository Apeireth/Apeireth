# The Feeling of What Happens (Antonio Damasio, 1999)

> **Organ**: body (身) | **R125-21 经典书 #3**

## Overview

Antonio Damasio (神经科学家) 提出"躯体标记假说" (somatic marker hypothesis). **核心**: 决策 = 脑 + 身体 共同, 不是脑独立理性. 身体状态(胃/心/皮肤)给"标记" → 脑用标记做决策. 情感 = 身体 + 脑 + 意识 三层. 这是 Apeireth body + heart organ "情感决策" 维度的神经科学基础.

- 设计 body + heart organ 协同 (情感决策)
- 写 agent 的"我用身体做决策" 解释
- 主人 1.0 release 时思考"AI 情感决策"
- 借鉴 somatic marker 做 multi-agent 4 角色情感

## Key Takeaways

**1. 躯体标记假说 (Somatic Marker)**:
- 决策 = 理性 + 情感 共同, 不是纯理性
- 身体状态(胃/心/皮肤) → 脑标记"好/坏" → 决策
- 没有情感的人(EV患者) 决策差
- 反对"理性 vs 情感"二分

**2. 意识 3 层**:
- **核心意识** (core consciousness) — 此时此刻身体感觉
- **扩展意识** (extended consciousness) — 过去 + 未来
- **自体意识** (autobiographical self) — 自我叙事

**3. 跟 Kahneman + Goleman 关系**:
- Kahneman: System 1 (快, 情感) + System 2 (慢, 理性)
- Damasio: 情感 = 身体标记 (somatic marker)
- 2 兼容, Damasio 更神经科学
