# How to Create a Mind (Ray Kurzweil, 2012)

> **Organ**: mind (意) | **R125-21 经典书 #4**

## Overview

Ray Kurzweil (发明家 + Google 未来学家) 总结一生的 AI 研究. **核心**: 大脑 = 层级模式识别器 (hierarchical pattern recognizer). 6 层隐马尔可夫模型 (HMM) 模拟新皮层. **2045 奇点**: AI 超过人类智能. 这是 Apeireth mind organ "层级模式识别" 维度的算法基础 + 1.0 release 后的"奇点"准备.

## When to Use

- 设计 mind organ 层级模式识别 verdict cache
- 写 agent 的"我这样识别模式" 解释
- 主人 1.0 release 时思考"AI 未来 + 奇点"
- 借鉴 HMM 做 9 organ 模式识别

## Key Takeaways

**1. 新皮层 = 6 层隐马尔可夫模型 (HMM)**:
- 6 层 HMM, 每层识别更抽象模式
- 跟 Hawkins "6 层新皮层" 1:1
- 跟视觉 / 听觉 / 触觉 通用

**2. 模式识别 vs 计算**:
- 大脑不是计算器, 是模式识别器
- 跟 Minsky 心智社会 兼容
- 跟 Hawkins 记忆-预测 兼容

**3. 2045 奇点 (Singularity)**:
- AI 智能超过人类智能
- 1.0 release 后 25 年 (R150, 2051)
- 主人 1.0 release 时思考"我们离奇点多远"
