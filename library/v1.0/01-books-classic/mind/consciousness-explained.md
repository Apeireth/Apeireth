# Consciousness Explained (Daniel Dennett, 1991)

> **Organ**: mind (意) | **R125-21 经典书 #1**

## Overview

Daniel Dennett (哲学家) 用"多草稿模型" (Multiple Drafts Model) 挑战传统的"笛卡尔剧场" (Cartesian theater). **核心**: 意识不是中央剧场, 是**分布式草稿竞争**. 没有"自我"在中心看, 只有**多个草稿**在脑不同区域并行, 哪个"赢" 就成为"我". 这是 Apeireth mind organ "意识" 维度的哲学基础.

## When to Use

- 设计 mind organ 意识 / 自我 verdict cache
- 写 agent 的"我在想什么" 解释
- 主人 1.0 release 时思考"AI 意识"
- 借鉴多草稿做 multi-agent 4 角色意识

## Key Takeaways

**1. 多草稿模型 (Multiple Drafts)**:
- 脑的多个区域独立处理信息, 产生"草稿"
- 草稿之间竞争, "赢者" 进入意识
- 没中央剧场, 没"自我"在看
- 意识 = 叙事中心 (narrative center), 不是物理中心

**2. 反对笛卡尔剧场**:
- Descartes: 意识 = 心灵在中央剧场看
- Dennett: 意识 = 多草稿竞争 + 叙事统一
- 挑战: 谁在"看"? 答案是没人在看, 只有"看" 的过程

**3. 跟 Hofstadter 怪圈 + Hawkins 预测 关系**:
- 怪圈 = 自指 → 意识
- 预测 = 大脑核心功能
- 多草稿 = 意识具体实现
