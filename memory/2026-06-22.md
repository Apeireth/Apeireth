### Step 1: 修 import 路径

**根因**:`pip install -e .` 装的是 `src` 作为顶级包,所以:
- `import agent_memory` ❌
- `import src.agent_memory` ✅

cli.py 内部用了 `from src.adapters.transparent_background` 这种绝对导入,
而 `agentmemory.exe` 启动时 cwd 不一定是 AgentMemory-master。

**修法**:在 `src/cli.py`(entry_point shim)顶部加:
```python
_HERE = os.path.dirname(os.path.abspath(__file__))
if _HERE not in sys.path:
    sys.path.insert(0, _HERE)
```

### Step 2: 修 transparent_background.main() argparse 冲突

**根因(深挖)**:cli.py 已经 parse 了 `bg`,然后调
`from src.adapters.transparent_background import main as bg_main; bg_main()`,
但 `transparent_background.main()` 又自己 `parser.parse_args()`,而 sys.argv
里 `bg` 已经被 cli 解析过了,这里就成了"unrecognized arguments: bg"。

**修法**:
- `transparent_background.main()` 重构成接受 kwargs,不再自己 parse
- 新增 `_standalone_main()` 留给 `python -m src.adapters.transparent_background` 用
- cli.py 的 `if command == "bg":` 分支改为传已解析的 kwargs:
  ```python
  bg_main(
      agent_id=kwargs.get("agent_id", "default"),
      base_dir=base_dir,
      importance=kwargs.get("importance", 0.6),
      heartbeat_minutes=kwargs.get("interval", 5),
      once=kwargs.get("once", False),
  )
  ```

**调试过程**(诊断脚本已删):

### Step 3: 配 OpenClaw cron(绕开 Windows sh 死结)

## 关键发现:cron 不能解决"自动摄入"

`transparent_background` 的 capture_current_context() 必须**显式喂入**
`user_msg + assistant_msg` 才会存东西。`--once` 只能触发"force summary",
但 pending messages 必须有 hook 喂进去才会被总结。

所以 README 的 cron 配置**实际上是个空架子**——5 分钟跑一次,每次 no_op,
除非有 hook 在每轮对话后 push 消息。

**真正要做的**:写一个 OpenClaw internal hook 或 plugin,在 `message:sent`
事件里调 `agentmemory add "<对话内容>"`(或 POST 到 agentmemory serve)。

## 我今天学到的

- **不要在没读完代码前下结论**。我第一次答"不是 OpenClaw 插件",被打脸
- **argparse 二次 parse 是隐蔽陷阱**。trace_known_args 才能定位子 parser 调度
- **OpenClaw 在 Windows 上 `--command` 是死结**(走 sh -lc),必须 `--command-argv`
- **PowerShell 调 Node CLI 会吃双引号**,跨进程 JSON 参数得用 Node 嵌套
- **review 文档不能当真理**,特别是日期超过 2 周的。代码改过不更新 review 是常态
- **`cmd_add` 不走 `manager.add()`!**CLI 是直调 L4FilesStore + _l3.upsert,manager.add 的 validation 对 CLI 无效
- **`pip install -e .` 是只改 import 路径问题,真正的运行时依赖要 `pip install ulid-py`**——但 ulid-py 1.1.0 API 不兼容,要 `python-ulid` 3.1.0
- **Windows 文件名不允许 `:`**——AgentMemory namespace 含 `:` 会炸。Hook 里要把 `:` 换成 `_`
- **f-string 不能嵌套 conditional `if-else`**——会 SyntaxError。要先拆出来赋值
- **OpenClaw hook 是 fire-and-forget**:`spawn(..., {stdio: "ignore"})`,handler 立刻返回。错误要 `proc.on("error", ...)` 捕获
