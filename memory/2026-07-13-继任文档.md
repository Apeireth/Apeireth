## ✅ 已修复：FileOperator / PowerShellExecutor（2026-07-13 15:33）

### 根因
上次会话的 subagent 用 Python `json.dump()` 重写 manifest 时带入了 **UTF-8 BOM**（`\ufeff`），VCP 的 JSON 解析器无法处理 BOM 前缀，PluginManager 静默跳过了这两个插件。

证据：
- 15:01 之前的启动日志有 `Loaded manifest: VCP服务器文件操作器 (ServerFileOperator)` 和 `Loaded manifest: PowerShell命令执行器 (ServerPowerShellExecutor)`
- 15:01 之后的 4 次重启日志中这两行**全部消失**
- Python `json.load(f, encoding='utf-8')` 报错 `Unexpected UTF-8 BOM`

### 修复方法
```python
# 用 utf-8-sig 读取（自动去 BOM）→ utf-8 写出（不带 BOM）
with open(path, 'r', encoding='utf-8-sig') as f:
    data = json.load(f)
with open(path, 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
```

修复后验证：
- ✅ Python `json.load(f, encoding='utf-8')` 通过
- ✅ 启动日志：`[15:33:08] Loaded manifest: VCP服务器文件操作器 (FileOperator, Type: synchronous)`
- ✅ 启动日志：`[15:33:08] Loaded manifest: PowerShell命令执行器 (PowerShellExecutor, Type: synchronous)`
- ✅ `dynamic_tool_catalog.json` 包含 `local:FileOperator` 和 `local:PowerShellExecutor`
