### V1457 设计要点 (主 13:08 真问真答)
- **5 stages** with weighted scoring: preflight (0.15) + bootstrap (0.25) + healthcheck (0.25) + verify (0.20) + rollback (0.15) = 1.0
- **chain_skip semantics**: preflight failure → all subsequent stages skipped (incl. rollback — no subprocess was started → nothing to clean up). bootstrap failure → healthcheck + verify skipped, but rollback STILL runs (best-effort cleanup of what was started).
- **stage score sources**:
  - preflight: n_checks_passed / n_total
  - bootstrap: 1.0 if subprocess success, 0.7 for PROXY mode (lower because no real OS process)
  - healthcheck: 1.0 if service responds, 0.8 if port listening, 0.5 if HTTP wrong status, 0.3 if no service, 1.0 for non-HTTP modules if bootstrap succeeded
  - verify: matches the module's verify_metric (exit_code_zero / samples_run_count / streamlit_version / http_status_200 / cube_overall_value)
  - rollback: 1.0 if cleanup completed, 0.5 if cleanup partially failed, 1.0 for noop strategy
