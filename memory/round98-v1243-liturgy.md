## liturgy 词源 (主 19:33)

- λειτουργία (leitourgia) = λαός (laos 人民) + ἔργον (ergon 工作) = "人民 之 工作 / 公共 服务"
- 希腊 城邦 公职: 雅典 leitourgia = 富裕 公民 承担 公共 义务 (战舰 资助 / 戏剧 赞助 / 体育 赞助)
- 早期 基督教 转义 = 圣徒 之 公共 服务 = 主日 聚会 / 圣餐 / 祈祷 / 圣洗
- 拉丁 liturgia (Cyprian 250 De Dominica Oratione + Augustine 400 Confessions)
- 拜占庭 λειτουργία = 圣祭 礼仪 (Divine Liturgy of St Basil + Divine Liturgy of St John Chrysostom)
- 中世纪 liturgia = 全 部 教会 公开 仪式
- 现代 liturgy = 公共 仪式 之 神学 与 实践 (崇拜 / 圣礼 / 祈祷 / 节期)
