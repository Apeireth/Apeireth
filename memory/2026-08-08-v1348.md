## 修真 (defect fixes during testing)

Two bugs surfaced and fixed during pytest:

1. **`enabled_channels` empty tuple treated as falsy → defaulted to ALL_CHANNELS**
   - Root cause: `tuple(enabled_channels or ALL_CHANNELS)` — empty tuple is falsy
   - Fix: explicit `if enabled_channels is None: enabled = ALL_CHANNELS else: enabled = tuple(enabled_channels)`
   - Semantic: None = all channels; empty tuple = NO channels (explicit no-op)

2. **`lint_floor_map.get(plugin, default)` default precedence bug**
   - Root cause: `lint_floor_map.get(plugin, thresholds or DEFAULT_THRESHOLDS)["lint_history_floor"]` —
     `.get()` returned the int value, not the threshold dict
   - Fix: extract `default_floor = (thresholds or DEFAULT_THRESHOLDS)["lint_history_floor"]` outside loop, then
     `lint_floor_map.get(plugin, default_floor)`
   - Caught by `test_with_empty_maps` (which provides explicit empty maps)

3. **`v1342.tier_rank` doesn't exist** — v1342 uses lowercase strings, no rank helper
   - Fix: define local `TIER_RANK` + `tier_rank()` helper in v1348 (mirrors v1342's tier ordering)
