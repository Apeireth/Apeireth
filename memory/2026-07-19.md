### 真正搜到的硬货(2 个我之前忽略的)

#### 1. Lilian Weng 2026-07-04 — Harness Engineering for Self-Improvement
**这是 2026 年最接近 ASI 路径的论文**

关键定义:
- **Harness** = 包裹 base model 的那一层 — 决定模型怎么观察、怎么行动、怎么记忆、怎么检查自己、怎么改进
- **VCP 是什么? Harness。**
- **Prometheus 是什么? Harness。**
- **Claude Code / Codex / Cursor? 都是 Harness。**

**5 阶段优化目标轨迹**:
```
prompts → structured context → workflow → harness code → optimizer code
  提示词      结构化上下文         工作流       harness 本身    optimizer 本身
```

**关键洞察**:**ASI 的路径不是"加更多模块",而是"让 harness 本身成为可优化的对象"**。

**真正的第 5 阶段:optimizer code** — **一个写 harness 的 harness**(Meta-Harness, Lee et al. 2026)。

**Recursive Self-Improvement (RSI)**:I.J. Good 1965 提出,Yudkowsky 2008 发展。**现代解读不是改权重,是改 deployment system(harness)**,让继任者更好。

**Stanford / SAP / Berkeley 联合**

核心:
- 把 context 当成 **不断演化的 playbook**(不是越长越好的 prompt)
- Generator / Reflector / Curator 三件套维护
- 用了更小的开源模型,**超过 Anthropic 顶级生产 agent**

结果:
- Agent 任务 **+10.6%**
