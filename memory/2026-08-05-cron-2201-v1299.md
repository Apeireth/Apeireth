## V1299 关键 Parser 修复 (主 17:58 不假装)

### Bug 1: finditer ^...$ 失效
- 错误: `RE_COMPONENT_ITEM = r'^\s*"([^"]+)"\s*,?\s*(?:#.*)?$'` — finditer 第二轮开始 ^ 不匹配
- 修复: 去掉 `^` 和 `$`, 改为 `r'\s*"([^"]+)"\s*,?'`
- 教训: re.finditer 默认不 re.MULTILINE, 在 captured group 内做 multi-match 必须去 anchors

### Bug 2: components 数组空时 raw 不显式记录
- 错误: `components = []` 时 raw = "" (strip 后空)
- 影响: is_present = False 但 raw 被 capture 为 ""
- 修复: 接受 raw="" 表示 "syntax 存在但空", 与 absent 区分 (主 17:43 实事求是)
