## 修真 (defects during testing)

3 bugs surfaced and fixed during development:

1. **`check_substrate_matrix` had garbage placeholder code**
   - Root cause: First edit accidentally inserted `CheckResult(... severity_was_critical_marker_unused=None, message="placeholder") if False else CheckResult(...)`
   - Fix: Removed the dead-code branch; only the valid `CheckResult(...)` remains.

2. **`check_required_modules` failed on real workspace**
   - Root cause: Used `importlib.import_module("v1335_vcp_cross_plugin_invariant_synthesis")` with bare name. The modules live in `apeireth/` package, not at top-level.
   - Diagnosed via: `python -m apeireth.v1353_vcp_doctor run` showed "11 of 11 required modules missing".
   - Fix: Added `_try_import()` helper that tries bare name first, then `apeireth.<name>` fallback. All 11 modules now importable.

3. **`argparse.ArgumentError: conflicting subparser: self-test`**
   - Root cause: Defined `self-test` subparser twice in `_build_argparser()`.
   - Fix: Removed the duplicate; one `self-test` with `--verbose` flag.

4. **`SyntaxError: invalid syntax` in test (walrus operator in default arg)**
   - Root cause: `def _cr(severity, status=STATUS_FAIL_NAME := m.STATUS_FAIL, msg="m"):`
   - Fix: Replaced with normal default + None-check; walrus operator not allowed in default argument.
