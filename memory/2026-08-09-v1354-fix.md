## Honest diagnosis

The test failure was a **floating-point precision issue**, not a
non-determinism bug in V1354 itself. Root cause:

```
_ledger_age_days() uses datetime.now(timezone.utc) which has microsecond
granularity. Two consecutive generate_plan() calls a few μs apart produce
age_days that differ at the 10th decimal place, which propagates to
priority scores through `sev_w * age_f * freq_f`.
```

Values that failed:
- p1: `[5.837104407563349]`
- p2: `[5.837104408611401]`
- Diff: ~10th decimal place (1 μs of age_seconds)

What IS deterministic:
- `item_id` set (matches exactly between calls)
- `n_items`, `n_fix`, `n_manual`, `n_defer`, `n_ignore` (matches)
- Ordering of items (matches)
- Suggested actions (match)

What is NOT (and never was) deterministic:
- Exact float value of `priority` (depends on microsecond time)

The test was overly strict. The fix preserves the deterministic
guarantees that matter (which item gets fixed first) while honestly
acknowledging that exact float comparison across `datetime.now()`
boundaries is impossible without freezing time.

## Fix

Changed `TestDeterminism::test_plan_deterministic_on_items` to use
`pytest.approx` for the priority list comparison:

```python
for a, b in zip(priorities1, priorities2):
    assert a == pytest.approx(b, rel=1e-6, abs=1e-9)
```

Tolerance rationale:
- `rel=1e-6` (0.0001%) catches real divergence (e.g., different items
  being scored)
- `abs=1e-9` handles values near zero (degenerate case)
- Documented in test docstring: "ordering and item_id set are
  deterministic; exact float is not"

## Alternative fixes considered (and rejected)

1. **Freeze time with `freezegun`** — adds dependency; masks the issue
   rather than documenting it. Rejected.
2. **Use day-granularity in `_ledger_age_days`** — would make priority
   a coarse bucket (integer days); would lose information about
   "very recent" issues. Rejected (changes semantics).
3. **Snap microsecond time to second-granularity in `_ledger_age_days`** —
   changes the production API for one test. Rejected.
4. **`pytest.approx` in test** — minimal change, honest about what is
   and isn't deterministic, no new dependency. **Chosen.**
