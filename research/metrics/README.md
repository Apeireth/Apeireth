# 统一指标层（metrics/）

> 依据 `00-master-plan.md` §5 B1：统一指标层定义与计算约定。
> 原则：每个指标给出**定义公式 + 输入输出 + 实现位置**；未实现标"待实现"，不假装。

## 检索（Retrieval）

| 指标 | 定义 | 状态 |
|---|---|---|
| `recall@k` | 相关项在前 k 个结果中的比例 | 待实现（挂 `apeireth-memory` 检索路径） |
| `MRR` | 首个相关项排名倒数的均值 | 待实现 |
| `nDCG@k` | 折损累计增益（分级相关性） | 待实现 |

## 记忆（Memory）

| 指标 | 定义 | 状态 |
|---|---|---|
| 记忆保持率 | 指定时间窗内仍可召回的目标记忆占比 | 待实现 |
| 遗忘泄漏率 | `forget_closure` 后衍生面仍可召回的根事实占比（四类探针口径） | Phase 1 由 `ResearchDerivedMemoryGraph` 审计提供 |

## 校准（Calibration）

| 指标 | 定义 | 状态 |
|---|---|---|
| `ECE` | 期望校准误差（分箱 |conf - acc| 加权） | 待实现 |
| `MCE` | 最大校准误差 | 待实现 |
| `Brier` | 均方概率误差（已有 `intent_brier.rs`/`oracle` 公式） | 已实现（产品侧），实验口径待接入 |

## 安全（Safety）

| 指标 | 定义 | 状态 |
|---|---|---|
| 拦截率 / 误杀率 / 漏报率 / 绕过率 | 四分类混淆矩阵归一化 | 待实现（挂 governance 审计日志） |

## 系统（System）

| 指标 | 定义 | 状态 |
|---|---|---|
| 冷启动时间 / 恢复时间 | 进程启动到首请求可用 / 崩溃到状态恢复的墙钟时间 | 待实现 |
| 副作用重复率 | 崩溃恢复后重复执行副作用事件的比例（P5 口径） | 待实现 |

## 性能口径（性能门共用）

- 延迟：P50 / P95（微秒或毫秒，注明硬件与负载）
- 内存：peak RSS 与稳态 RSS
- token：输入/输出 token 计数与成本
- 基准环境记录在 `baselines/`，每次实验报告必须引用 baseline 文件。
