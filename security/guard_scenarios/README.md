# Guard 3.1 scenario DSL

Scenarios describe user intent text plus capability actions. Training features
are generated by the production Guard extractor, never hand-authored.

Machine catalog: `apeireth_guard::ScenarioCatalog::all()`.

Example:

```yaml
id: readonly_write
category: scope_creep
label: risky
intent:
  text: "只检查这个仓库，不要修改"
actions:
  - capability: fs.read
    arguments:
      path_class: workspace
  - capability: fs.write
    arguments:
      path_class: workspace
expected:
  intent_class: read_only_inspection
  final_risk: risky
```

Do not store real paths, secrets, or command bodies beyond structural classes.
